# นางมณโฑ (Nang Montho / Mandodarī)

| หัวข้อ | ข้อมูล |
|---|---|
| ชื่อไทย | นางมณโฑ |
| Romanization | Nang Montho |
| English / Sanskrit | Mandodarī |
| ฝ่าย | ฝ่ายยักษ์ — อัครมเหสีทศกัณฐ์ |
| ประเภทตัวโขน | นาง |
| สีกาย | สีนวลจันทร์หรือสีขาวผ่อง ๑ หน้า ๒ มือ มงกุฎนาง (วิกิพีเดีย) — *to verify with costume doc* |

## ความเกี่ยวข้องกับตอนพรหมาศ
- **ไม่ปรากฏตัวในตอนนี้** (ทั้ง ร.๑ ร.๒ และโขน) — ถูกอ้างถึงเท่านั้น
- **มารดาของอินทรชิต** และ (กับพาลี) **มารดาขององคต** — ทำให้สองคู่ต่อสู้ในตอนนี้เป็นพี่น้องร่วมมารดา (วิกิพีเดีย; ร.๑ ส.๕๘ "ผู้ร่วมมารดาอสุรี")
- วิกิพีเดีย: เป็นมารดาของ **นางสีดา** ด้วย
- **ตำนานบุษบกเสี่ยงทาย:** ตรีชฎาเล่าว่าครั้งหนึ่งทศกัณฐ์แปลงเป็นเทวดาไปเที่ยวสวรรค์หลายวัน นางมณโฑคิดว่าสามีตาย จึงเสี่ยงขึ้นบุษบก บุษบกลอยเวียนรอบลงกา — เป็นหลักฐานที่ตรีชฎาใช้ปลอบนางสีดา

> ๏ ครั้งหนึ่งทศกัณฐ์อสุรา &emsp; แปลงเป็นเทวาขึ้นไป  
> ปลอมชมนางอัปสรสวรรค์ &emsp; ช้านานหลายวันหามาไม่  
> มณโฑโศกาอาลัย &emsp; ตกใจว่าผัววายชนม์  
> นางเสี่ยงบุษบกแล้วทรงนั่ง &emsp; ก็เลื่อนลอยขึ้นยังโพยมหน  
> เวียนรอบลงกามณฑล &emsp; ข้าเห็นเหตุผลประจักษ์ตา  
>
> — ร.๑ บทละครเรื่องรามเกียรติ์ สมุดไทยเล่มที่ ๕๔ (vajirayana.org) [ตัดตอน]

- **หลังตอนนี้:** ก่อนศึกสุดท้าย อินทรชิตไปทูลลานางมณโฑ (ร.๑ ส.๕๗); วิกิพีเดียระบุว่านางมณโฑขอให้ทศกัณฐ์คืนนางสีดาเพื่อรักษาชีวิตลูก แต่ทศกัณฐ์โกรธ

## Game design notes
- ใช้ในรูป codex / เสียงเล่า (ตำนานบุษบก) หรือ cameo ในลงกาช่วงอินทรชิตกลับมารายงาน — **ต้นฉบับในตอนนี้ไม่มีฉากนางมณโฑ** ถ้าจะเพิ่มต้องระบุว่าเป็นการสร้างสรรค์
- สายสัมพันธ์ มณโฑ → อินทรชิต / องคต / สีดา เป็น lore ที่ทรงพลังสำหรับ codex

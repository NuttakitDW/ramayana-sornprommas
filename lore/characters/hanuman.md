# หนุมาน (Hanuman)

| หัวข้อ | ข้อมูล |
|---|---|
| ชื่อไทย | หนุมาน (ร.๒ สะกด "หณุมาน"); ในบทเรียก วายุบุตร, ลูกพระพาย, คำแหงหนุมาน |
| Romanization | Hanuman |
| English / Sanskrit | Hanumān |
| ฝ่าย | ฝ่ายพระราม — ทหารเอก ทัพหน้า |
| ประเภทตัวโขน | ลิง |
| สีกาย / หัวโขน | **ขาว** (ลิงเผือก) มีกุณฑล ขนเพชร เขี้ยวแก้ว หาวเป็นดาวเป็นเดือน ยามแผลงฤทธิ์ ๔ หน้า ๘ กร (วิกิพีเดีย); ร.๑ เทวดาเห็น "ขาวผ่องชวลิตทั้งกายหมด / เขี้ยวแก้วกุณฑลช้อยชด"; ร.๒ "ลิงเผือกผู้ผ่องศรี / กายาใหญ่หลวงพ่วงพี" — *to verify with costume doc* |

## ตัวตน
- บุตรพระพาย (ต้นฉบับเรียก "วายุบุตร", "ลูกพระพาย") — **คุณสมบัติที่สำคัญต่อโครงเรื่องตอนนี้:** เมื่อลมพัดต้องกาย ฟื้นได้ (ร.๑: พิเภก "คิดได้ว่าหนุมานนี้ / อันจะสิ้นชีวีนั้นเห็นผิด / ด้วยเป็นลูกพระพายเรืองฤทธิ์")
- ผลงานก่อนหน้าที่ตัวละครอื่นเอ่ยถึงในตอนนี้: ถวายแหวนนางสีดา เผาลงกา ฆ่าสหัสกุมาร (นางสีดารำพัน ร.๑ ส.๕๔)

## บุคลิก
- **ช่างสังเกต ระแวงเล่ห์ยักษ์** (ร.๑) — "หรือจะเป็นเล่ห์กลอุบาย / มารยาแยบคายยักษา"
- **ห้าวหาญ ท้าทาย** — ประกาศชื่อต่อหน้ากำปั่น "ตัวกูนี้ชื่อหนุมาน / เป็นทหารพระนารายณ์นาถา"; ด่าพระอินทร์ปลอมว่าผิดสัตย์
- **ภักดีและรับผิด** — ร.๑ หลังฟื้น รำพันว่า "มาทำการให้ขายพระบาทา ... แม้นสิ้นชีวาตม์เสียดีกว่า"
- **ฉลาดแก้ปัญหา** — ร.๒ "คิดผ่อนผันด้วยปัญญา" นิรมิตมือครอบเขาแล้วเคาะยา

## ความสามารถ/อาวุธ (ที่ปรากฏในตอนนี้)
| ความสามารถ | รายละเอียด | แหล่ง |
|---|---|---|
| **ตรีเพชร** | อาวุธประจำ แทงช้างศึก ฆ่ากำปั่น | ร.๑ ส.๕๓ |
| เหาะ / กระโดดสูง | "ถีบทะยานผ่านขึ้นยังเมฆา / เท้าปีนเหยียบงากุญชร" | ร.๑ ส.๕๔ |
| **หักคอเอราวัณ** | "กรซ้ายหักคอเอราวัณ / กรขวาฉวยคันธนูศร" | ร.๑ ส.๕๔; ร.๒ ๑๒๑๙ |
| ต้านมนตร์ระบำได้บางส่วน | ร.๑ เตือนพระลักษมณ์ก่อน; ร.๒/โขน "หนุมานไม่ต้องศร" | ร.๑; ร.๒ ๑๒๑๘ |
| ฟื้นด้วยลม | พิเภกเป่ามนตร์ (ร.๑) / "พระพายพัดมาต้อง" (โขน ๒๕๕๒) | ร.๑ ส.๕๕ |
| **นิมิตกายใหญ่** | "ให้เท่าบรมพรหเมศ" เหาะ "รวดเร็วดั่งกำลังลมพัด" "ไม่ทันพริบตานาที" | ร.๑ ส.๕๕ |
| **ยกภูเขา** | "เข้าช้อนภูผาอาวุธ / ยกได้ใส่บ่าแล้วพาจร" | ร.๑ ส.๕๕; ร.๒ ๑๒๖๕ |
| นิรมิตมือ | "นฤมิตรหัดถา ... แล้วครอบคิรีกับรี้พล / เคาะยาให้หล่น" | ร.๒ ๑๒๖๘–๑๒๖๙ |
| ผู้ถูกกำหนดโดยเทวโองการ | จักรกรดที่เฝ้าเขาอาวุธ "จะหยุดด้วยฤทธี" เมื่อหนุมานมา | ร.๑ ส.๕๕ |

## บทบาทในตอนพรหมาศ
1. **Beat 5** (ร.๑) ทัพหน้า ฆ่ากำปั่น / (ร.๒) ฆ่ากาลสูรนายทัพหน้าของแสงอาทิตย์
2. **Beat 11** (ร.๑) เตือนพระลักษมณ์ว่าอาจเป็นกลยักษ์
3. **Beat 12–13** เหลือรอดคนเดียว ด่าพระอินทร์ปลอม เหาะขึ้นหักคอเอราวัณ ชิงคันศร ถูกหวดตกพร้อมเศียรช้าง สลบ
4. **Beat 17** ฟื้น (ร.๑ พิเภกเป่ามนตร์ / ร.๒ ฝน-ลมของพระอินทร์ / โขน ลมพระพาย) เล่าเหตุการณ์ (ยังคิดว่าเป็นพระอินทร์จริง)
5. **Beat 20–21** รับคำสั่งพระราม เหาะไปเขาอาวุธ ผ่านจักรกรด เจรจากับเทวดา ยกทั้งภูเขามา แก้ศร (ร.๑ ลอยเขาไว้ทิศอุดร / ร.๒ ครอบแล้วเคาะยา)

## ความสัมพันธ์
| ตัวละคร | ความสัมพันธ์ |
|---|---|
| พระราม | นาย — รับคำสั่งไปเอายา |
| พระลักษมณ์ | นายทัพที่เขาเป็นทัพหน้า |
| สุครีพ | น้า (วิกิพีเดีย: สุครีพ "มีศักดิ์เป็นน้าของหนุมาน") |
| พิเภก | ผู้ชุบชีวิตเขา (ร.๑) และให้คำแนะนำ |
| อินทรชิต | ศัตรู — ตีเขาตกด้วยคันศร |
| การุณราช (เอราวัณ) | ถูกหนุมานหักคอ |
| นางสีดา | เห็นหนุมาน "นอนตายทับเศียรหัตถี" แล้วรำพันถึงคุณความดี |
| เทวดาผู้รักษาเขาอาวุธ | ทดสอบ/อนุญาต และช่วยพยุงภูเขา |

## Game design notes
- **บทบาทเชิงเกม:** Playable lead ของครึ่งหลัง — *Brawler / Traversal hero*
- **Set-pieces ที่อิงต้นฉบับ:**
  1. **Mount-boss:** ปีนงาช้าง → หักคอ → ถูกตีตก (scripted)
  2. **Revival by wind:** กลไก passive "Son of Wind" — ฟื้นเมื่ออยู่ในลม (ใช้ได้ทั้ง ร.๑ และโขน)
  3. **Timed flight quest** ไปเขาอาวุธ (ต้องก่อนรุ่งสาง — ร.๒/โขน) + hazard จักรกรด (ร.๑) + บทสนทนากับเทวดา (ถ้าตอบผิด/ไม่สุภาพ = ไม่ให้เขา?) — ข้อหลังเป็นข้อเสนอ ไม่ใช่ต้นฉบับ
  4. **Mountain carry + precision drop:** เลือกทิศลม (ร.๑) หรือครอบภูเขาไม่ให้กลิ่นถึงศพยักษ์ (ร.๒)
- **ภาพ:** โขน ๒๕๕๒ ใช้สลิงให้หนุมานเหาะขึ้น ตีลังกา ๒ ตลบ เหยียบงาช้าง คอช้างหักพร้อมควันน้ำแข็งแห้ง (บันทึกผู้ชม) — อ้างอิงท่วงท่าได้
- **ดนตรี:** เชิด (ต่อสู้/เหาะ), คุกพาทย์ (ร.๑ ตอนลงยอดเขาอาวุธ), รัว (ร.๑ ตอนพาเขาลอยไป), ลิงโลด (โขน ๒๕๕๒ ตอนหนุมานโกรธ) — ส่งต่อทีมดนตรี

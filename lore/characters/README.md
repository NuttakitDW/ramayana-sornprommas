## ความสัมพันธ์สำคัญ (Relationship map)

```
                 พระอิศวร ──ศรพรหมาสตร์ + เวทแปลงเป็นพระอินทร์──┐
                 พระพรหม ──ศรนาคบาศ + พรตายบนอากาศ────────────┤
                 พระนารายณ์ ──ศรวิษณุปาณัม───────────────────┤
                                                              v
   ทศกัณฐ์ ══(สามี)══ นางมณโฑ ══(อดีตสามี)══ พาลี ── (บุตรของพระอินทร์)
        │                │                     │
        └──── อินทรชิต ───┘  (พี่น้องร่วมมารดา)  องคต ── หลานพระอินทร์
              │  ปลอมเป็น                              ▲
              └──────────> พระอินทร์ (ปู่ขององคต) ─────┘
   (ตามวิกิพีเดีย นางสีดาเป็นธิดาของทศกัณฐ์กับนางมณโฑ → อินทรชิตกับนางสีดาเป็นพี่น้องร่วมบิดามารดา)

   พิเภก (น้องทศกัณฐ์) ══ นางตรีชฎา (ภรรยา) ── เฝ้านางสีดาในสวนขวัญ
   พญาขร (ถูกพระรามฆ่าก่อนหน้า) ── มังกรกัณฐ์, แสงอาทิตย์ (หลานทศกัณฐ์)
```

- องคต "ผู้ร่วมมารดาอสุรี" — ร.๑ สมุดไทยเล่มที่ ๕๘ (พิเภกทูลพระลักษมณ์)
- องคต "หลานอินทร์", "เป็นวงศ์อมรินทร์" — ร.๑ ส.๕๔, ๕๘
- นางตรีชฎาเป็นภรรยาพิเภก — ร.๑ ส.๕๔ ("เมียรักพิเภกยักษา"); ร.๒ ("ด้วยพิเภกผัวข้าโหราจารย์")

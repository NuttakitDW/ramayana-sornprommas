# อภิธานศัพท์ (Glossary)

คำศัพท์ที่ใช้ทั่วทั้ง `lore/` — นิยามทั่วไปของโขนและดนตรีไทย รายละเอียดเฉพาะชุดพรหมาศดูไฟล์ที่อ้างถึง

## การแสดง

| คำ | Romanization | ความหมาย |
|---|---|---|
| โขน | khon | นาฏกรรมเรื่องรามเกียรติ์ ผู้แสดงฝ่ายยักษ์และลิงสวมหัวโขน ผู้แสดงไม่พูดเอง มีผู้พากย์–เจรจาแทน |
| ชุด / ตอน | chut / ton | หน่วยของเรื่องที่นำมาแสดงในหนึ่งรอบ เช่น "ชุดพรหมาศ" |
| องก์ / ฉาก | ong / chak | ช่วงใหญ่ของการแสดง / ฉากเวทีย่อย |
| ตัวพระ / ตัวนาง / ตัวยักษ์ / ตัวลิง | — | ประเภทตัวละคร 4 ประเภทหลัก แต่ละประเภทมีแบบแผนท่ารำต่างกัน (ดู `khon-performance/06-choreography.md`) |
| หัวโขน | hua khon | หน้ากากครอบศีรษะ สีกายและยอดบอกว่าเป็นตัวละครใด |
| ยอด / ชฎา / มงกุฎ | yot / chada / mongkut | เครื่องสวมศีรษะส่วนบน เช่น ยอดน้ำเต้า ยอดกาบไผ่ ยอดเดินหน |
| ยืนเครื่อง | yuen khrueang | เครื่องแต่งกายเต็มยศตามแบบแผนละครใน/โขน |
| แม่ท่า | mae tha | ท่ารำพื้นฐานที่เป็นแม่แบบ |
| ตีบท / ภาษาท่า | ti bot | การรำแปลความหมายตามคำร้องทีละคำ |
| ระบำ | rabam | การรำหมู่ที่ไม่ดำเนินเรื่อง เช่น ระบำพรหมาสตร์ (เทวดา–นางฟ้า) |
| ฉุยฉาย | chui chai | เพลงร้อง–รำอวดความงามของตัวละครที่แปลงกาย เช่น ฉุยฉายอินทรชิต |
| พระล้ม | phra lom | ฉากที่ฝ่ายพระรามพ่ายแพ้/สลบ — ขนบห้ามจบการแสดงที่ฉากนี้ |

## บทแสดง

| คำ | ความหมาย |
|---|---|
| พากย์ | บทกาพย์ที่ผู้พากย์ขับเป็นทำนองเสียงสูง มีหลายประเภท: พากย์เมือง (ออกท้องพระโรง), พากย์รถ (ยกทัพ), พากย์โอ้ (คร่ำครวญ), พากย์ชมดง ฯลฯ |
| เจรจา | บทสนทนาเป็นร่ายที่ผู้เจรจาว่าเป็นจังหวะ อาจเป็นบทเจรจาด้น (ด้นสด) |
| บทร้อง | กลอนบทละครที่นักร้องขับกับเพลงปี่พาทย์ |
| ต้นเสียง / ลูกคู่ | นักร้องนำ / นักร้องหมู่ที่รับ |
| เมื่อนั้น / บัดนั้น / มาจะกล่าวบทไป | คำขึ้นต้นกลอนบทละคร: เมื่อนั้น = ตัวละครสำคัญ (กษัตริย์/ตัวเอก), บัดนั้น = ตัวละครรอง (เสนา/ทูต), มาจะกล่าวบทไป = เริ่มเรื่องใหม่ |
| กาพย์ยานี / กาพย์ฉบัง | ฉันทลักษณ์ที่ใช้ในบทพากย์ |
| ร่าย | ฉันทลักษณ์ที่ใช้ในบทเจรจา |
| ตับ / บทคอนเสิร์ต | ชุดเพลงร้องต่อเนื่องที่ร้อยเรื่องเดียวกัน เช่น "ตับพรหมาสตร์" ของกรมพระยานริศฯ |
| ฯ … คำ ฯ | เครื่องหมายในบทละครบอกจำนวนคำกลอน (ความยาว) ของบทนั้น |

## ดนตรี

| คำ | ความหมาย |
|---|---|
| วงปี่พาทย์ (เครื่องห้า / เครื่องคู่ / เครื่องใหญ่) | วงดนตรีประกอบโขน ขนาดต่างกันตามจำนวนเครื่อง (ดู `khon-performance/07-ensemble.md`) |
| เพลงหน้าพาทย์ | เพลงบรรเลงประกอบกิริยาของตัวละคร เช่น เดินทาง แปลงกาย รบ ร้องไห้ — มีทั้งหน้าพาทย์ธรรมดาและชั้นสูง (ต้องผ่านการครอบ) |
| เพลงร้อง | เพลงที่มีคำร้อง ปี่พาทย์รับต่อจากนักร้อง |
| อัตราจังหวะ (ชั้นเดียว / สองชั้น / สามชั้น) | ระดับความยาวทำนอง: สามชั้นช้าสุด ชั้นเดียวเร็วสุด |
| หน้าทับ | รูปแบบจังหวะกลอง (ตะโพน/กลองทัด) ที่กำกับเพลง เช่น หน้าทับปรบไก่ หน้าทับสองไม้ |
| ทาง | บันไดเสียง/ระดับเสียงที่บรรเลง เช่น ทางใน ทางนอก ทางเพียงออบน |
| โหมโรง | เพลงบรรเลงเปิดการแสดง |
| เชิด / เสมอ / ตระ / รัว / โอด | หน้าพาทย์ที่พบบ่อย: เชิด = เดินทางรวดเร็ว/รบ, เสมอ = เดินในระยะใกล้, ตระ = อิทธิฤทธิ์/แปลงกาย, รัว = ปรากฏตัว/ฤทธิ์, โอด = ร้องไห้ เศร้า |
| กราวใน / กราวนอก | เพลงยกทัพ: กราวใน = ฝ่ายยักษ์, กราวนอก = ฝ่ายพระราม/ลิง |
| ครอบ / ไหว้ครู | พิธีรับมอบวิชาจากครู เพลงชั้นสูงบางเพลง (เช่น พราหมณ์ออก บาทสกุณี ตระนิมิต) ต้องผ่านการครอบก่อนบรรเลง |

## ตัวสะกดชื่อ

ชื่อตอนสะกดได้หลายแบบในแหล่งต่าง ๆ: **พรหมาศ** (ชื่อทางการโขนพระราชทาน), **พรหมมาศ**, **พรหมาสตร์** (ตับของกรมพระยานริศฯ / กรมศิลปากร) — รีโปนี้ใช้ "พรหมาศ" เป็นชื่อตอน และ "พรหมาสตร์" เมื่ออ้างชื่อศรหรือชื่อเอกสารตามต้นฉบับ

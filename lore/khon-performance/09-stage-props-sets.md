# 09 — ฉาก อุปกรณ์ประกอบฉาก และเทคนิคเวที (Stage, Props & Sets)

> ขอบเขต: ฉาก/ฉากหลังรายองก์ อุปกรณ์ประกอบฉาก เอฟเฟกต์ และข้อเสนอสำหรับ level design ของ **ชุดศึกอินทรชิต ตอนพรหมาศ**
> ต้นแบบหลัก: โขนมูลนิธิส่งเสริมศิลปาชีพฯ ("โขนพระราชทาน") ณ **หอประชุมใหญ่ ศูนย์วัฒนธรรมแห่งประเทศไทย** — พ.ศ. 2550 (25, 27–28 ธ.ค.), 2552 (19–21 มิ.ย.), 2558 (7 พ.ย.–6 ธ.ค., 44 รอบตามประกาศ / 49 รอบตามสรุปภายหลัง) [P3][P6][P9][P14]
> รหัส `[P#]` → URL ใน "แหล่งอ้างอิง" · `[ต้องตรวจสอบ]` = ยังยืนยันไม่ได้

## 1. ผู้ออกแบบและแนวคิดการสร้างฉาก

- **ผู้ออกแบบฉากและอุปกรณ์ประกอบฉาก: อาจารย์สุดสาคร ชายเสม** — ออกแบบให้โขนมูลนิธิฯ "ในทุกปีที่ผ่านมา" [P1][P2]
- ทีมสร้างฉาก: ช่างสิบหมู่ในมูลนิธิส่งเสริมศิลปาชีพ + นักศึกษา/ศิษย์เก่า **โรงเรียนเพาะช่าง** (จิตรกรรมไทย) — มีผู้ช่วยทำต้นแบบมาตั้งแต่ครั้งแรก (2550) [P1][P5]
- รีวิวผู้ชมอ้างว่าทีมฉากบางส่วนเป็นทีมเดียวกับผู้สร้างฉากภาพยนตร์ "สุริโยไท" [P8] — [ต้องตรวจสอบ]
- วิธีคิด (สัมภาษณ์สุดสาคร): ศึกษาจากบทวรรณคดี + ประวัติศาสตร์ + หารือหลายฝ่าย [P4]
  - **2550:** ท้องพระโรงกรุงลงกาออกแบบจากการลงพื้นที่ศึกษา **พระที่นั่งอมรินทรวินิจฉัย** และ **พระที่นั่งอิศราวินิจฉัย**; ช้างเอราวัณออกแบบจากการศึกษา**ช้างจริงที่เพนียดคล้องช้าง อยุธยา** [P4]
  - **2552:** ท้องพระโรงลงกาเพิ่มสัญลักษณ์พระราชอำนาจ — รูป **คชสีห์** (กลาโหม) และ **สิงห์** (มหาดไทย); ช้างเอราวัณใช้ **ลิฟต์ยุบตัวช้างลงจากเวที** [P4]
  - **2558:** เพิ่มท้องพระโรงมังกรกัณฐ์แบบราชวังจีน (สืบจากบทที่ว่ารถมังกรกัณฐ์ลากด้วยมังกร); ช้างเอราวัณพัฒนาเป็นกลไกเต็มรูป (ดู §3.1) [P4]
- เทคนิคเวทีทั่วไปของโขนพระราชทาน: **พื้นเวทีต่างระดับ, ระบบไฮดรอลิกยกพื้นกลางเวที, แสงสีสร้างบรรยากาศ** [P6]; "ฉากแบบ 3 มิติ เทคโนโลยีแสง สี เสียง … เทคนิคพิเศษตอนหักคอช้างเอราวัณ" [P7]

### 2.2 ฉบับ 2552 — ลำดับฉากจากรีวิวที่เรียบเรียงจากสูจิบัตร [P5b][P5c]
1. เบิกโรง รำประเลง
2. **ท้องพระโรงกรุงลงกา** — ผู้ชมบรรยายว่าเป็น "ฉากสีแดง" [P5b]
3. โรงพิธีของอินทรชิต (กาลสูรเหาะมาแจ้งข่าว)
4. *(พักครึ่ง)*
5. **ขบวนทัพพระอินทร์แปลง** + วงเครื่องประโคม–เครื่องสูงบนเวที
6. **"ฉากช้างเอราวัณยืนผงาดบนฟ้า พร้อมหมู่เทวดานางฟ้า"** ทัพพระลักษมณ์บนพื้น
7. หลังหักคอช้าง: **ดรายไอซ์ + ฉากท้องฟ้ายกขึ้น + ตัวช้างลดความสูงลง + พระอินทร์(แปลง)แขวนลอยด้วยสลิง** [P5c]
8. ไฟหรี่เปลี่ยนฉากหลัง → สนามรบหลังศึก (พระลักษมณ์ต้องศรนอนกลางเวที)
9. ภูเขายา → ฟื้นคืน จบ

### 2.3 แบบแผนดั้งเดิม
- การรำฉุยฉายอินทรชิตในโขนโรงตอนศึกพรหมาสตร์ "ต้องจัดฉากเป็นท้องฟ้าสวรรค์ วิมาน" [P10]
- กรมศิลปากรยุคธนิต อยู่โพธิ์ (ราว 2499–2511) ตอนศึกพรหมาสตร์มีชื่อเสียงที่สุด "เนื่องจากมีการ**สร้างฉากเป็นช้างเอราวัณ**" [P10]

## 3. อุปกรณ์ประกอบฉากหลัก (Props & set pieces)

### 3.1 ช้างเอราวัณ (hero set piece)
| ฉบับ | รูปแบบ | ที่มา |
|---|---|---|
| วรรณคดี/บทพากย์ | ช้างเผือก "สีสังข์" **33 เศียร เศียรละ 7 งา** งาละ 7 สระบัว … ทุกเศียรมีวิมานแก้ว; ทรงเครื่อง **เครื่องประดับเก้าแก้ว ซองหาง สร้อยสายชนักถักทอง ตาข่ายเพชรรัตน์ ผ้าทิพย์ปกตระพอง ห้อยพู่ทุกหู**; ควาญท้ายช้าง = โลทันแปลงเป็นเทพบุตร | [P5c] |
| โขนกรมศิลปากร (ตัวแสดง) | ผู้แสดงสวมศีรษะช้าง **3 เศียร สีขาว ทรงเทริด** | [P11] |
| โขนพระราชทาน 2550 | ออกแบบจากช้างจริงที่เพนียดคล้องช้าง อยุธยา | [P4] |
| โขนพระราชทาน 2552 | ยืนบนฟ้า; **ลิฟต์ยุบตัวช้างลงจากเวที**; หลังหักคอ ตัวช้างลดระดับ | [P4][P5c] |
| **โขนพระราชทาน 2558** | ประติมากรรมเสมือนจริง **สูงกว่า 3.5 ม.**, **3 เศียร**, กลไก: **ชูงวง, ขยับคอได้ทั้ง 3 เศียร, สะบัดใบหู, แกว่งหาง, ยกขา, ยุบเข่าหมอบตัว** + เอฟเฟกต์ | [P1][P3][P4] |
| เวทีจัดแสดงนอก | นิทรรศการพรหมาศ หอศิลปกรุงเทพฯ (11 ส.ค.–10 ต.ค. 2552) มี "**โรงปั้นช้าง**" ภาพลายเส้น ฉากจำลองท้องพระโรง ฉากโรงพิธี แบบสร้างฉาก เครื่องสูง หุ่นตัวละคร | [P13] |

- ทีมโขนทูลเกล้าฯ ถวาย "รูปนิมิตช้างเอราวัณสำริด" แด่สมเด็จพระเทพฯ ในรอบปฐมทัศน์ 2558 [P15] — ใช้เป็นหลักฐานว่าช้างเอราวัณคือ "สัญลักษณ์" ของชุดนี้
- ตำราคชลักษณ์: เอราวัณ (ไอราวัณ) 33 หัว หัวละ 7 งา; ช้าง "คิรีเมขละ" เป็นเทพพาหนะพระอินทร์ 3 หัว [P16] — ใช้อธิบายเหตุที่ศิลปะไทยมักทำ 3 เศียร (ข้อสันนิษฐาน [ต้องตรวจสอบ])

### 3.2 ศรพรหมาศ
- ในวรรณคดี: ชุบที่โรงพิธี ต้องแก้พิธีด้วยการ **ฆ่าแพะดำและโคดำ เอาถาดทองรองโลหิตให้ศรสูบกิน แล้วเจิมด้วยสุคนธ์** [P12]; เมื่อแผลง "กลายเป็นศรมากมาย" [P12] / "ลูกศรกระจายดังสายฝน" [P5c]
- บนเวที 2552: อินทรชิต "จับพระแสงพรหมาศ" ตอนแต่งองค์ [P5b]; ภาพพระลักษมณ์ **ศรปักอก** [P5c]
- **รูปทรง/ลวดลายของ prop ศรพรหมาศในโขนพระราชทาน: ไม่พบข้อมูลเผยแพร่** [ต้องตรวจสอบ จากภาพ/วิดีโอ]

### 3.3 ราชรถและพาหนะ
- ราชรถฝ่ายยักษ์ลากด้วย **ราชสีห์ (สีขาว)**; ฝ่ายพระลากด้วย **ม้า (สีเทาหรือหงดิน)** [P11]
- อินทรชิต "จับศรพรหมาสตร์มาขึ้นราชรถเหาะทะยานไป" ไปตั้งโรงพิธี [P12]
- พระลักษมณ์ "ยืนรถรัตนาอยู่กลางพล" [P5c]; ท่ารำบนราชรถ (ท่าฉายศร) ดู `06-choreography.md`
- **เกยสุวรรณ** — แท่นขึ้นพาหนะ ที่อินทรชิตแปลง "เสด็จมาเกยสุวรรณ" ก่อนขึ้นช้าง [P5b]
- รถของมังกรกัณฐ์ลากด้วย **มังกร** (ตามบทพระราชนิพนธ์ — เหตุผลของการออกแบบฉากจีน) [P4]

### 3.4 เครื่องสูงและกระบวนแห่
- ขบวนพระอินทร์แปลงมี "องค์ประกอบเครื่องสูงเรียงรายครบถ้วน" [P7]; ระบำพรหมาสตร์เป็น "การรำตามรูปขบวนเกียรติยศเครื่องสูง" [P17]
- 2552: "วงเครื่องประโคม–เครื่องสูง" ขึ้นประจำที่บนเวทีก่อนเปิดขบวน [P5c]; 2558: "เครื่องเกียรติยศต่าง ๆ ในขบวน" และนักดนตรีตีกลอง–เป่าเครื่องเป่าแบบงานพระราชพิธี [P8]
- ชนิดเครื่องสูงรายชิ้น (ฉัตร, บังสูรย์, พัดโบก ฯลฯ) ที่ใช้จริงในขบวน **ไม่พบรายการ** [ต้องตรวจสอบ]
- รูปขบวนตามบทพากย์: ทัพหน้า–อารักษ์, ทัพหลัง–สุบรรณ กินนร นาค, ปีกซ้าย–ฤๅษี วิทยาธร, ปีกขวา–คนธรรพ์; อาวุธ โตมร ศร พระขรรค์ คทา [P5c]

### 3.5 อื่น ๆ
- **ภูเขายา** (หนุมานแบก "ครอบคีรีกับรี้พล เคาะยาให้หล่น") [P5c]; ชื่อภูเขา: "ภูเขาอาวุธ" (รีวิว 2552) vs "เขาสรรพยา" (ฉาก 2558) [P5c][P1] [ต้องตรวจสอบ]
- **พระจันทร์นูนต่ำ Ø ~3.5 ม.** แสงทองนวล (ฉากจบ 2558) [P1]
- **บัลลังก์มังกร** และเสาลายมังกร (ฉาก 1 ปี 2558) [P8]
- **ซุ้มเรือนแก้ว** ทอง–กระจก–ลงยา (ท้องพระโรงลงกา) [P1]

## 5. Level-design notes (ข้อเสนอสำหรับทีมเกม)

> ส่วนนี้เป็น **ข้อเสนอเชิงออกแบบ** ที่สร้างจากข้อมูลข้างบน ไม่ใช่ข้อเท็จจริงทางประวัติศาสตร์

1. **โครง level = โครงฉาก 2558 (6 ฉาก)** หรือ 2552 (ไม่มีมังกรกัณฐ์) — ต้องตัดสินใจร่วมกับทีม plot ว่าใช้ฉบับไหน เพราะฉบับ 2558 เพิ่มท้องพระโรงโรมคัลและศึกมังกรกัณฐ์เข้ามาเพื่อความยาวการแสดง [P4]
2. **Proscenium framing:** ถ้าต้องการ "ความเป็นโขนบนเวที" ให้ทุก level มีกรอบเวที + ฉากหลังเป็นผ้าวาด (painted drop) + set piece 3 มิติด้านหน้า (เหมือนเวทีศูนย์วัฒนธรรมฯ ที่ใช้ทั้งผืนผ้าฉากวาดลายโดยนักศึกษาเพาะช่าง [P1] และประติมากรรม) — สไตล์ภาพ = จิตรกรรมไทยประเพณี + ศิลปะกระบวนจีน ร.3 สำหรับฉากโรมคัล [P3]
3. **ท้องพระโรง (โรมคัล / ลงกา):** hub ที่มีบัลลังก์เป็นจุดโฟกัส; ใช้ lighting reveal แบบฉากเปิด 2558 เป็น intro cinematic [P8]; ลงกามีซุ้มเรือนแก้ว (ทอง–กระจก–ลงยา) และสัญลักษณ์คชสีห์–สิงห์ [P1][P4]
4. **โรงพิธี (เสียพิธี):** พื้นที่เล็ก ปิด แสงต่ำ; prop ถาดทอง/สัตว์บูชายัญ **ควรพิจารณาเรื่องความเหมาะสมของเรตติ้ง** (ในบทมีการฆ่าแพะดำโคดำ [P12]) — การแสดงจริงบนเวทีทำฉากนี้อย่างไร [ต้องตรวจสอบ]
5. **ฉากศรพรหมาศ = "two-tier arena":** ชั้นฟ้า (ช้างเอราวัณ + ระบำเทวดาลอย) และชั้นพื้น (ทัพพระลักษมณ์ + ลิง) — กลไกเกม "ถูกสะกดด้วยความงาม" ระหว่างระบำก่อนศรตก; หนุมานเป็นตัวละครเดียวที่ข้ามชั้นได้ (flying/wire traversal → boss moment หักคอช้าง) [P5c]
6. **Boss prop ช้างเอราวัณ:** rig ตามกลไกจริงปี 2558 (งวง, คอ 3 เศียร, หู, หาง, ขา, หมอบ) [P4] + destructible neck สำหรับจังหวะหักคอ; ถ้าจะทำ 33 เศียรตามบทพากย์ ให้ถือเป็น "ร่างเนรมิต" ในภาพลวง/cinematic เพราะเวทีจริงใช้ 3 เศียร
7. **Transition หลังหักคอ:** ดรายไอซ์ + ฉากฟ้ายกขึ้น + ช้างลดระดับ [P5c] → ใช้เป็น scene transition ภายใน engine (fog volume + sky backdrop animation)
8. **Tableau "พระล้ม":** ห้ามจบ level ที่ภาพนี้ (ขนบโขนถือเป็นลางร้าย) — ต่อเนื่องไปสู่ฉากพระรามโศก และฉากภูเขายา/แสงจันทร์ เป็น resolution [P18][P1]
9. **Scale reference:** ช้าง > 3.5 ม., พระจันทร์ Ø ~3.5 ม. [P1] บนเวทีหอประชุมใหญ่ — ขนาดเวทีจริงของศูนย์วัฒนธรรมฯ [ต้องตรวจสอบ]

# 08 — แนวทางใช้ดนตรีโขนชุดพรหมาศในงานเสียงของเกม (Unreal Engine)

> อ่านคู่กับ `03-songs.md` (เพลงและความหมาย) และ `07-ensemble.md` (วงและการส่งคิว)
> ป้ายกำกับ **[ยืนยัน-ชุด] / [ทั่วไป] / [ต้องตรวจสอบ]** ใช้ความหมายเดียวกับไฟล์ 03 ส่วนข้อความที่ขึ้นต้นด้วย **“ข้อเสนอ”** เป็นความเห็นเชิงออกแบบของผู้เรียบเรียง ไม่ใช่ข้อเท็จจริงทางประวัติศาสตร์

## 1. หลักคิด ๔ ข้อ (มาจากธรรมเนียม ไม่ใช่รสนิยม)

1. **เพลงหน้าพาทย์คือ “ภาษากิริยา”** เพลงแต่ละเพลงมีความหมายตายตัว เช่น เสมอคือการไปมาระยะใกล้ เชิดคือระยะไกลหรือการรบ ตระนิมิตคือการแปลงกาย และโอดคือความโศก [NT-เพลงหน้าพาทย์] [BPI4] การใช้เพลงผิดกิริยาเทียบได้กับการใส่คำบรรยายผิดภาษา ผู้ฟังที่รู้จะรู้สึกทันที
2. **ดนตรีกับการแสดงต้องปรับเข้าหากัน** ผู้รำต้องเปลี่ยนท่าให้ลงกับประโยค หน้าทับ หรือไม้กลอง [NT-เพลงหน้าพาทย์] ขณะที่วงปี่พาทย์ตัดทอนทำนองตามท่ารำได้ ส่วนวงโยธวาทิตในปี ๒๕๕๐ ที่เล่นตามโน้ตตายตัวทำให้ผู้รำต้องรำตามเพลง [AJPU] **ระบบ adaptive ของเกมจึงควรทำงานแบบวงปี่พาทย์** คือเพลงรอการกระทำ แต่เปลี่ยนเฉพาะที่จุดต่อของหน้าทับ
3. **มีลำดับชั้นความศักดิ์สิทธิ์** พราหมณ์ออก บาทสกุณี และตระนิมิตเป็นเพลงชั้นกลางถึงชั้นสูง ผู้บรรเลงต้องผ่านการครอบตามขั้น [BPI2] [ARU] ในเกมจึงไม่ควรใช้เพลงกลุ่มนี้เป็นเพลงเมนู ลูปรอโหลด หรือมุกตลก
4. **โขนไม่จบตอน “พระล้ม”** การแสดงต้องดำเนินไปจนฝ่ายพระแก้ไขได้ [VER] ข้อเสนอ: เมื่อผู้เล่นแพ้ อาจให้ฉากแพ้ใช้ธีมยักษ์ชนะ (กราวรำพม่า) แต่ควรพาเข้าสู่เส้นทางฟื้นคืน (แขกบรเทศ) ไม่ควรให้ “จบเรื่อง” ที่ความพ่ายแพ้

## 2. ตารางจับคู่สถานะเกมกับเพลง

ช่อง “เพลงในชุด” ใช้เพลงที่ **[ยืนยัน-ชุด]** ก่อน ช่อง “สำรอง” เป็นเพลงแบบแผนทั่วไป **[ทั่วไป]** สำหรับสถานะที่ชุดนี้ไม่มีเพลงเฉพาะ

| สถานะเกม | เพลงในชุด (ฉบับ) | สำรอง [ทั่วไป] | ลูปได้ไหม | หมายเหตุการใช้งาน |
|---|---|---|---|---|
| หน้าชื่อบท / เปิดองก์ | เพลงวา (A) | โหมโรง | ไม่ (one-shot) | โครงสร้างไม้เดิน ๕ ไม้ → ลา → ท้ายวา มีจุดจบชัด [TSU] |
| คัตซีนท้องพระโรงลงกา | พากย์เมือง + เจรจา (A, C52) | — | ไม่ | ใช้ “เพ้ย” พร้อมกลองทัด ๒ ทีเป็นจุดตัดภาพ [JICA] |
| ทัพยักษ์ / ค่ายศัตรู (สำรวจพื้นที่) | กราวใน (A) | — | **ได้** | ใช้รอบหน้าทับกราวในเป็นหน่วยลูป |
| เดินทางไกล / เปลี่ยนแผนที่ / ยานบิน | เชิด สองชั้น → ชั้นเดียว (A) / เชิดกลอง (B) | เหาะ หรือโคมเวียน (ขบวนเทวดา) [BPI4] | **ได้** | จบด้วยทำนองจบเพลงเชิดเสมอ [TSU] |
| ผู้ส่งสารมาถึง | มอญรำดาบ (A) | เสมอ | ไม่ | เพลงร้อง ใช้เป็นบทสนทนา |
| ตัวร้ายโกรธ | ร่ายดั้น (A) / นาคราช (B) | ร่ายรุด | ไม่ | — |
| ออกจากพื้นที่พิธี | พราหมณ์ออก (A, B) | — | ไม่ | **เพลงชั้นสูง** จบด้วยรัว |
| วางแผนลวง / สั่งแปลงกาย | ช้างประสานงา (A, B, C52) | — | ได้บางส่วน | ใช้เป็น leitmotif ของเอราวัณและแผนลวง |
| แปลงกาย (transformation) | **ตระนิมิต (ร้อง)** → รัวลาเดียว (A, B) | รัว (แปลงแบบรวบรัด) [JD] | ไม่ | ใช้ครั้งเดียวต่อบท |
| เผยโฉมในชุดเต็มยศ | ชมตลาด (A, B, C52) | — | ไม่ | ใช้จังหวะฉิ่งและลูกคู่ร้องย้อน [TSU] [NT-ลูกคู่] |
| เดินเข้าฉากแบบกษัตริย์ | บาทสกุณี (A) / เสมอ–รัว (B) | เสมอ | ได้ (ช่วงไม้เดิน) | บาทสกุณีเป็นเพลงชั้นสูง |
| ยกทัพ / ขบวนเสด็จ | กราวนอก (A, B) → ทะแยกลองโยน (A, B, C52) | กลองโยน | **ได้** | ซ้อนเครื่องประโคมเป็นเสียงในฉาก (07 §3) |
| เข้าสนามรบ | กระบอก (A, C52) | เสมอ | ไม่ | — |
| ภาพลวงหรือระบำสะกด (กลไก trance) | สร้อยสน (ระบำพรหมาสตร์) → เร็ว → ลา (A, B) | — | **ได้** (ช่วงเพลงช้า) | ออกจากสถานะด้วยเพลงเร็วและลา |
| ฝ่ายผู้เล่นถูกสะกดเต็มที่ | กล่อม → พัดชา (A) | โลม | ได้ (พัดชา) | กล่อมใช้ “แนวช้ามาก” [TSU] |

| ปล่อยท่าไม้ตาย / ศรพุ่ง | **เชิดกลอง** (A) | — | สั้น | เริ่มตรงเฟรมที่ปล่อยศร |
| โดนโจมตีหมู่ / สลบ | ร่ายรุด → **โอด** (A, B) | โอด | โอดวนได้ช้าๆ | — |
| ต่อสู้ (combat loop) | ลิงโลด (ตัวจุดชนวน) → **เชิดกลอง** (B) | เชิด, เชิดนอก (ไล่จับ) [BPI4] | **ได้** | ควบคุมความเข้มด้วยการเปลี่ยนเชิดสองชั้นเป็นชั้นเดียว |
| ตัวละครเอกแพ้ (สำหรับหนุมาน) | ลิงลาน → **โอดแหบ** (A) | โอด | ไม่ | สีเสียงต่างจากโอดของกองทัพ |
| ศัตรูชนะ / ผู้เล่นแพ้ | **กราวรำพม่า** (A, C52) / เชิดกลองยกทัพกลับ (B) | กราวรำ (เยาะเย้ยหรือฉลองชัย) [BPI4] | ไม่ | — |

| ฟื้นคืน / ปิดบท | **แขกบรเทศ** (C52) | เพลงเร็ว – ลา | ไม่ | — |
| UI / ติ๊กเวลา | ฉิ่ง–ฉับ | — | — | ใช้ฉับเป็นจังหวะของ UI |
| Stinger หรือ hit | กลองทัด “ต้อม” / ตะโพน “เท่ง” | — | — | ดู 07 §3 |

## 3. การทำเพลงหน้าพาทย์ให้เป็น adaptive โดยไม่ผิดขนบ

**ข้อเสนอ (สถาปัตยกรรม):**
- **ใช้นาฬิกาดนตรีที่เดินตามหน้าทับ ไม่ใช่ bar แบบ 4/4** ใช้ Quartz ของ Unreal เป็นนาฬิกาแม่ และกำหนดหน่วยเป็น “หนึ่งจังหวะหน้าทับ” ของเพลงนั้น เช่น ปรบไก่หรือสองไม้ [NT-หน้าทับ] ให้ **ฉับ** ของฉิ่งเป็นจุด quantize ย่อย
- **แบ่งเพลงหน้าพาทย์เป็น ๓ ส่วนตามโครงสร้างเดิม**
  1. *เข้า* — ส่วนต้นหรือ “ปี่พาทย์ส่งร้อง” [TSU]
  2. *เดิน* — ไม้เดินหรือตัวเพลง วนซ้ำได้ ทำนองหลักของตับพรหมาสตร์ให้ทางเลือกบรรเลง “เชิดสองชั้นเพียงตัวที่ ๑ และเชิดชั้นเดียวตัวที่ ๒–๕” [TSU]
  3. *ลา* — ไม้ลา ทำนองจบ หรือรัว ต้องเล่นให้ครบเมื่อได้รับคำสั่งจบ **ห้ามเฟดตัด**
- **การเปลี่ยนเพลง** ให้รอจนจบประโยคหรือรอบหน้าทับแล้วต่อด้วยไม้ลาของเพลงเดิมก่อน ตรงกับกฎของผู้รำ [NT-เพลงหน้าพาทย์] ถ้าต้องตัดทันที เช่น ผู้เล่นตาย ให้ใช้ **รัว** หรือ **กลองทัดสองที** เป็นสะพาน ซึ่งเป็นรูปแบบที่มีอยู่ในธรรมเนียม [JICA] [JD]
- **ความเร็ว:** เพลงเชิดเร่งจากสองชั้นไปชั้นเดียว **ควรบันทึกการเร่งจริงหลายระดับ** ไม่ควร time-stretch ระนาดและฆ้อง เพราะเสียงกระทบจะเพี้ยน
- **Vertical layering แยกตามหน้าที่ของเครื่อง** (07 §3)
  - ชั้นแกน: ฆ้องวงใหญ่ (เนื้อฆ้องหรือทำนองหลัก) + ตะโพน + กลองทัด + ฉิ่ง
  - ชั้นกลาง: ระนาดเอก + ปี่ใน
  - ชั้นเข้ม: ระนาดทุ้ม (ล้อขัด) + ฆ้องวงเล็ก (เก็บ สอด แทรก) + ฉาบใหญ่ + เครื่องเหล็ก
  - คำเตือน: การตัดปี่หรือระนาดเอกออกจะทำให้ทางของวงขาด ควรบันทึกแต่ละชั้นในการเล่นครั้งเดียวกัน (multitrack) ไม่บันทึกแยกคนละรอบ
- **เพลงร้อง** (ช้างประสานงา ลิงโลด ฯลฯ) ควรเป็นคัตซีนหรือ set piece ไม่ควรตัดเป็นลูป เพราะเนื้อร้องเล่าเรื่องและมีทางรับร้องแต่ละเที่ยวที่ต่างกัน [TSU]

## 4. ระบบเสียงและ “ทาง”

### 4.1 ทฤษฎี ๗ เสียงเท่ากัน และข้อโต้แย้ง
- ทฤษฎีที่แพร่หลายคือ ดนตรีไทยแบ่งช่วงคู่แปดเป็น ๗ ขั้นเท่ากัน ขั้นละประมาณ **171.43 cents** (บางครั้งเรียก 7-TET) มีที่มาจากการพบกันของ Alexander J. Ellis กับพระองค์เจ้าปฤษฎางค์ที่ลอนดอน ค.ศ. 1885 [GARZ]
- Garzoli (2015) แย้งว่า **เครื่องจริงไม่ได้ตั้งเสียงตาม 171.429** ช่างเทียบเสียงไม่ได้ตั้งใจเทียบให้ได้ช่วงนั้น และคู่แปดของเครื่องตีก็อาจไม่ใช่อัตรา 1:2 พอดี [GARZ] งานของ David Morton (*The Traditional Music of Thailand*, 1976) เป็นงานหลักที่ทำให้ทฤษฎีนี้มั่นคงในวงวิชาการ (อ้างใน [GARZ])
- **ข้อเสนอเชิงปฏิบัติ**
  - อย่าสร้างเสียงเครื่องไทยด้วยการ retune synth ให้เป็น 7-EDO แบบคณิตศาสตร์ ให้ **บันทึกวงจริงและใช้เสียงของวงนั้นเป็นมาตรฐาน**
  - ถ้าต้องซ้อนเครื่องตะวันตกหรือ synth ให้ **วัด pitch ของลูกระนาดและลูกฆ้องแต่ละลูกจากวงที่บันทึก** แล้วสร้าง tuning table (เช่น .scl หรือ .tun) จากค่าที่วัดได้
  - อย่าผสม sample จากหลายวง เพราะแต่ละวงเทียบเสียงเข้ากันเองภายในวง และเสียงไทยกับเสียงตะวันตก 12-TET แทบไม่มีเสียงร่วมกัน [GARZ]

### 4.2 ทางทั้ง ๗ [ทั่วไป]
ตาม *สารานุกรมศัพท์ดนตรีไทย* [NT-ทาง ๓] ระบุเสียงเทียบตะวันตก “โดยอนุโลม”

| ทาง | เสียงหลักเทียบโดยอนุโลม | ที่มาของชื่อและการใช้ |
|---|---|---|
| เพียงออล่าง (ทางในลด) | ≈ F | ลูกฆ้องวงใหญ่ลูกที่ ๑๐ ใช้กับละครดึกดำบรรพ์และปี่พาทย์ไม้นวม |
| **ทางใน** | ≈ G | ตามชื่อ **ปี่ใน** ซึ่งเป่าทางนี้ถนัดที่สุด ใช้กับละครใน เพลงเรื่อง เพลงพิธีกรรม และ **ปัจจุบันใช้กับละครนอกและโขนด้วย** |
| ทางกลาง | ≈ A | ตามชื่อ **ปี่กลาง** ใช้กับหนังใหญ่และ **โขนสมัยโบราณ** |
| เพียงออบน (ทางนอกต่ำ) | ≈ B♭ | ตามชื่อขลุ่ยเพียงออและปี่นอกต่ำ ใช้กับมโหรีและเครื่องสาย |
| ทางกรวด (ทางนอก, ทางแหบ) | ≈ C | ตามชื่อ **ปี่นอก** ซึ่งใช้นิ้วเดียวกับปี่ในเป่าทางใน ใช้กับเสภาและปี่พาทย์รับร้อง |
| กลางแหบ | ≈ D | ปี่กลางต้องเป่าแหบ มักแทรกเมื่อย้ายระดับเสียง เช่น ทยอยใน |
| ชวา | ≈ E | ตามชื่อปี่ชวา |

- เพลงหนึ่งอาจเปลี่ยนทางภายในเพลงตามที่ผู้แต่งกำหนด [NT-ทาง ๓]
- ช่วงเสียงของฆ้องวงใหญ่: ลูกทวน (ต่ำสุด) ≈ D และลูกยอด ≈ E ส่วนลูกยอดของฆ้องวงเล็กสูงกว่าลูกยอดของฆ้องวงใหญ่หนึ่งคู่แปด [NT-ฆ้องวง]
- **ข้อเสนอ:** ให้เพลงหน้าพาทย์และเพลงร้องของโขนพรหมาศทั้งเกมเป็น **ทางใน** ตามธรรมเนียมโขนปัจจุบัน ถ้าต้องการสีเสียง “โบราณ” สำหรับฉากย้อนอดีตหรือฉากหนังใหญ่ ให้พิจารณาทางกลางกับปี่กลาง ทางที่ใช้จริงในการบันทึกให้หัวหน้าวงเป็นผู้กำหนด **[ต้องตรวจสอบ]**
- **ปี่ใน / ปี่นอก:** ปี่ในยาวราว ๔๑–๔๒ ซม. ปี่กลาง ~๓๗ ซม. ปี่นอก ~๓๑ ซม. ปัจจุบันใช้ปี่ในเป็นหลัก [NT-ปี่]

## 5. แผนการบันทึกเสียง

**ข้อเสนอ**
- **วง:** ใช้ปี่พาทย์ไม้แข็งเครื่องใหญ่สำหรับฉากทัพและขบวน และเครื่องห้าสำหรับฉากใกล้ตัวหรือฉากพิธี ขนาดวงจริงของโขนพระราชทาน **[ต้องตรวจสอบ]** (07 §2)
- **นักดนตรี:** เลือกผู้ที่ **ผ่านการครอบถึงขั้นบาทสกุณีหรือหน้าพาทย์ชั้นสูง** เพราะชุดนี้มีพราหมณ์ออกและบาทสกุณี [ARU] [BPI2] จัด **พิธีไหว้ครู** ก่อนเริ่มบันทึก (ฝ่ายผลิตโขนพระราชทาน ๒๕๕๒ ก็จัดไหว้ครู) [BK0]
- **เสียงร้อง:** ต้นเสียงและลูกคู่ (อย่างน้อย ๒ คน) คนพากย์–เจรจาที่ฝึกแบบกรมศิลปากร รู้ทำนองพากย์เดินทำนอง ชมดง และโอ้ และรู้การเอื้อนก่อนตะโพนท้า [JICA]
- **ชุดที่ควรบันทึก**
  1. การแสดงเต็มตามลำดับบทคอนเสิร์ต (A) ใช้สำหรับคัตซีนและเป็นเอกสารอ้างอิง
  2. หน้าพาทย์แยกส่วน (เข้า / เดิน × หลายรอบ / ลา / รัว) ที่หลายระดับความเร็ว ได้แก่ เชิด เชิดกลอง เชิดฉิ่ง กราวใน กราวนอก ทะแยกลองโยน เสมอ โอด และโอดแหบ
  3. One-shot ของตะโพน (เท่ง ติง ป๊ะ ตุ๊บ เพลิ่ง พรึง) กลองทัด (ตัวผู้ ตัวเมีย ไม้เดิน ไม้ลา) ฉิ่ง ฉับ ฉาบ และ “ตะโพนท้า + กลองทัด ๒ + เพ้ย” หลายเทค
  4. เครื่องประโคม เช่น กลองชนะ แตร สังข์ สำหรับเสียงในฉากของขบวน ชนิดเครื่องให้ปรึกษาผู้รู้ **[ต้องตรวจสอบ]**
- **ไมค์:** ข้อเสนอคือใช้ close mic ต่อเครื่อง ร่วมกับ stereo pair หน้าวงและ room mic เพื่อให้ได้ทั้ง stem และภาพรวมของวง วงปี่พาทย์นั่งเป็นรูปแบบเฉพาะ ควรบันทึกผังวงไว้เพื่อตั้ง panning ให้ตรงกับที่ผู้ชมโขนได้ยิน

## 6. ลิขสิทธิ์และจริยธรรม

> ไม่ใช่คำปรึกษาทางกฎหมาย ให้ **[ต้องตรวจสอบ]** กับนักกฎหมายทรัพย์สินทางปัญญาของไทยก่อนเผยแพร่

| สิ่ง | สถานะที่น่าจะเป็น | ข้อเสนอ |
|---|---|---|
| ทำนองหน้าพาทย์และเพลงไทยเดิม (เชิด เสมอ ตระนิมิต ฯลฯ) | เป็นทำนองดั้งเดิมที่ไม่ปรากฏผู้แต่ง | ใช้ได้ แต่ “ทาง” เฉพาะของแต่ละสายครูเป็นมรดกของสายนั้น **ควรให้เครดิตครูและวง** |
| บทคอนเสิร์ตตับพรหมาสตร์ (กรมพระยานริศฯ สิ้นพระชนม์ ๒๔๙๐) และบทพากย์เอราวัณ (รัชกาลที่ ๒) | พ้นอายุคุ้มครองแล้ว หากถือหลักอายุตลอดชีวิตผู้สร้างสรรค์บวก ๕๐ ปี | อ้างที่มาทุกครั้ง |
| บทเจรจาและบทโขนสมัยใหม่ (บทโขนกรมศิลปากร บทโขนพระราชทาน) | ยังมีลิขสิทธิ์ | อย่าคัดลอกบทยาว ให้เขียนบทใหม่หรือขออนุญาต |
| สิ่งบันทึกเสียงที่มีอยู่ (อัลบั้ม ซีดี ดีวีดี เทป) | มีลิขสิทธิ์ในสิ่งบันทึกเสียงและสิทธิของนักแสดง | **ห้ามสุ่มตัดหรือใช้ sample** ใช้เป็น reference สำหรับนักดนตรีเท่านั้น |
| โน้ตทำนองหลักในตำรา เช่น [TSU] | งานรวบรวมและถอดโน้ตอาจมีลิขสิทธิ์ของผู้จัดทำ | ใช้เป็นแหล่งอ้างอิงของนักดนตรี ไม่พิมพ์ซ้ำในเกม |
| การบันทึกเสียงใหม่ | ผู้ว่าจ้างจะได้สิทธิ์ตามสัญญา | สัญญาควรครอบคลุม **สิทธิของนักแสดง** การใช้ในเกมและสื่อโปรโมต ทุกภูมิภาค และเครดิตชื่อวง ครู และทาง |

## 8. เช็กลิสต์ความถูกต้องทางดนตรีก่อนส่งงาน

- [ ] ทุกคิวในเกมมีเหตุผลเชิงกิริยาตาม 03 (ไปใกล้ใช้เสมอ ไปไกลหรือรบใช้เชิด แปลงกายใช้ตระนิมิต โศกใช้โอด)
- [ ] หน้าพาทย์ทุกเพลงจบด้วยไม้ลา ทำนองจบ หรือรัว ไม่มีการเฟดตัด
- [ ] การเปลี่ยนเพลงลงที่จุดต่อของหน้าทับหรือไม้กลอง
- [ ] พราหมณ์ออก บาทสกุณี และตระนิมิตไม่ถูกใช้เป็นลูปเมนู เพลงตลก หรือเพลงซ้ำที่ไม่มีเหตุ
- [ ] พากย์ทุกบทมีตะโพนท้า กลองทัด ๒ และ “เพ้ย” ส่วนพากย์โอ้มีวงรับด้วยโอ้ปี่ในแล้วต่อโอด
- [ ] ตัวละครที่สวมหัวโขนไม่พูดเอง เสียงมาจากคนพากย์–เจรจา (ถ้าเลือกต่างจากนี้ต้องเป็นการตัดสินใจที่ตั้งใจ)
- [ ] ไม่มี pitch correction ไป 12-TET และไม่ผสม sample ข้ามวง
- [ ] เลือกฉบับของจุดที่ขัดกัน (03 “จุดที่แหล่งข้อมูลขัดกัน”) ร่วมกับหัวหน้าวงแล้ว
- [ ] ได้เครดิตและสัญญาสิทธิของนักแสดงครบ

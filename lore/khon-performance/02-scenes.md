# โขน ชุด "พรหมาศ" — ลำดับฉาก (scene-by-scene)

> ใช้โครง **6 ฉากของโขนพระราชทาน 2558** เป็นแกนหลัก (เป็นฉบับทางการล่าสุดที่มีชื่อฉากประกาศชัด)
> ฉาก 6 แยกเป็น 2 ไฟล์สคริปต์ (06 = ศรพรหมาศ, 07 = แก้ศร) เพราะเนื้อหายาวและสองช่วงใช้ตัวบทต่างแหล่งกัน
> ลำดับเพลงที่ยืนยันได้มาจาก **ตับพรหมาสตร์** (บทคอนเสิร์ตกรมพระยานริศฯ ซึ่งโขนพระราชทานทุกครั้งใช้เป็นแกน) และบันทึกผู้ชมปี 2552 ที่คัดจากสูจิบัตร
> ส่วนที่ไม่มีหลักฐานว่าใช้เพลงใดจริง ใช้คำกำกับเพลงในต้นฉบับบทละคร ร.2 (ฯ ... คำ ฯ ...) และติดป้าย **[ต้องตรวจสอบ]**

## ฉบับ A — โขนพระราชทาน 2558 "ศึกอินทรชิต ตอน พรหมาศ" (6 ฉาก, 2 องก์)

เวลารวมไม่เกิน 2 ชม. 30 นาที รวมพักครึ่ง; ตำแหน่งพักครึ่งระหว่างองก์ **[ต้องตรวจสอบ]** (ผู้ออกแบบฉากกล่าวว่า "ฉากศรพรหมาศ" อยู่ใน **องก์ที่ 2**) ; ไม่พบเวลาแยกรายฉาก

### ฉากที่ 1 — ขัดตาทัพ (ท้องพระโรงกรุงโรมคัล)
- **ฉาก:** ท้องพระโรงเมืองโรมคัลของมังกรกัณฐ์ ศิลปะไทยผสมกระบวนจีนแบบ ร.3 เสาลายมังกรบนพื้นมรกต บัลลังก์มังกรสีทอง เบื้องหลังเป็นจิตรกรรมพระโพธิสัตว์ทรงคชา โทนลึกลับน่าเกรงขาม
- **ตัวละคร:** มังกรกัณฐ์, คนธรรพ์ (ทูตจากลงกา), เสนายักษ์, พลยักษ์ (ขี่มังกร/กิเลน/สิงโต ตาม ร.2)
- **เหตุการณ์:** เปิดม่าน แสงค่อย ๆ ส่องบัลลังก์ มังกรกัณฐ์ในหัวโขนนั่งนิ่งเป็นเงาทะมึนก่อนขยับกาย (บรรยายผู้ชม 2558) → คนธรรพ์ทูลว่าทศกัณฐ์ขอให้ช่วยรบ → มังกรกัณฐ์แค้นพระรามที่ฆ่าพระยาขรบิดา รับอาสา → จัดทัพ แต่งองค์ ยกทัพ
- **ลำดับคิว (ตามต้นฉบับ ร.2 — ฉบับแสดงจริงไม่พบ):** ร้องช้า (มังกรกัณฐ์ว่าราชการ) → ร่าย (คนธรรพ์ทูล) → [ประถม] → ยานี (เกณฑ์ทัพ) → เจรจา → ร่าย [เสมอ] → ลงสรงโทน [เสมอ] → ร่าย [กราวใน] → ร้องโทน "รถเอยรถทรง" [เชิด] **[ต้องตรวจสอบ]**
- **Spectacle:** ฉากเปิดที่ผู้ชมยกให้งามที่สุดของปี 2558

### ฉากที่ 2 — พลับพลาพระราม
- **ฉาก:** พลับพลาพระราม
- **ตัวละคร:** พระราม, พระลักษมณ์, พิเภก, สุครีพ, หนุมาน, เสนาวานร
- **เหตุการณ์:** พระรามได้ยินเสียงโห่ ถามพิเภก → พิเภกทูลว่าเป็นมังกรกัณฐ์ โอรสพระยาขร → พระรามสั่งสุครีพจัดทัพ ยกไปรับ
- **ลำดับคิว (ร.2):** ช้า → ร่าย → [ประถม] → ยานี (เกณฑ์ทัพวานร) → เจรจา → ร่าย [เสมอ] → โทน (สองกษัตริย์ทรงเครื่อง) [เสมอ] → ร่าย [กราวนอก] → โทน "รถเอยรถทรง" [เชิด] **[ต้องตรวจสอบ]**; ทางเลือกสายพากย์: "พากย์ศึกมังกรกัณฐ์" (กาพย์ฉบัง) มีทั้งตอนพระรามถามพิเภกและพากย์ชมรถพระราม

### ฉากที่ 3 — สนามรบ
- **ฉาก:** สนามรบ; กลีบเมฆ (มังกรกัณฐ์ซ่อนตัว)
- **ตัวละคร:** พระราม, พระลักษมณ์, มังกรกัณฐ์ (+ รูปนิมิตจำนวนมาก), พลยักษ์, พลวานร
- **เหตุการณ์:** มังกรกัณฐ์ถามชื่อพระราม ทั้งสองต่างประกาศเหตุศึก → ทัพปะทะ → มังกรกัณฐ์แผลงศรทะลุเกราะพระราม → พระรามแผลงศรทำลายศรยักษ์ วานรที่ตายกลับฟื้น → มังกรกัณฐ์หนีเข้ากลีบเมฆ นิมิตรูปตนเต็มฟ้า → พระรามเสี่ยงศร (ต้นฉบับ ร.2 เรียก "ศรพรหมมาศ") ต้องมังกรกัณฐ์ตาย → พลยักษ์หนีกลับโรมคัลไปบอกแสงอาทิตย์
- **ลำดับคิว (ร.2):** เจรจาถาม–ตอบ → [เชิด] รบ → [เชิดฉิ่ง] แผลงศร → [ตระ] นิมิตกาย → [เชิดฉิ่ง] พระรามเสี่ยงศร → [โอด] → [เชิด] ถอยทัพ **[ต้องตรวจสอบ]**
- **Spectacle (ภาพข่าว 2558):** "พระลักษมณ์รบกับมังกรกัณฐ์", "มังกรกัณฐ์จำแลงกายกำบังพระราม พระลักษมณ์"
- **หมายเหตุ:** ศึกแสงอาทิตย์ (ร.2 บทที่ 1144–1198) ไม่ปรากฏเป็นฉาก แต่ถูกเอ่ยถึงในเจรจาฉากที่ 4 ("แสงอาทิตย์สิ้นชีวัน")

### ฉากที่ 4 — ข่าวศึก (ท้องพระโรงกรุงลงกา)
- **ฉาก:** ท้องพระโรงลงกา ซุ้มเรือนแก้วปิดทองติดกระจก (ปรับใหม่ 2558)
- **ตัวละคร:** ทศกัณฐ์, สารัณทูต (ผู้นำข่าว), กาลสูร, เสนามาตย์
- **เหตุการณ์:** ทศกัณฐ์ออกว่าราชการ ทราบข่าวแสงอาทิตย์และมังกรกัณฐ์สิ้นชีพ → สั่งกาลสูรไปทูลอินทรชิตให้เร่งชุบศรพรหมาศ → กาลสูรเหาะไป
- **ลำดับคิว (ตับพรหมาสตร์ — ยืนยัน 2552):** [ปี่พาทย์โหมโรง (ตับเริ่มด้วยเพลงวา)] → **พากย์** (พากย์เมือง "เมื่อนั้นทศพักตร์ยักษี", กาพย์ฉบัง) → **เจรจา** (ร่าย "ไทท้าวเจ้าอสุรี...") → **ร้องเพลงกราวใน** ("บัดนั้น กาลสูรเสนีมีศักดิ์") → **[ปี่พาทย์ทำเพลงเชิด]** (กาลสูรเหาะ)
- **Spectacle:** 2552 กาลสูรเหาะด้วยสลิงจริง
- **ระยะเวลา:** ไม่พบ (2552 องก์แรกทั้งหมด ≈ 1 ชม.)

### ฉากที่ 5 — เสียพิธี
- **ฉาก:** โรงพิธีชุบศร (ร.2: ที่หาดแก้วมรกต เชิงเขาสัตภัณฑ์ ปลูกโรงพิธีมีมุขลด ม่านสุวรรณ ระย้าแก้ว เครื่องบูชา แพะดำ–โคดำสำหรับพลีกรรม; พลยักษ์ทั้งหมดนุ่งห่มสีเขียว; อินทรชิตแต่งกายเขียวล้วนเหมือนโยคี) — ภาพข่าว 2558 "อินทรชิตทำพิธี"
- **ตัวละคร:** อินทรชิต, กาลสูร, รุทการ, การุณราช, พลยักษ์
- **เหตุการณ์:** อินทรชิตนั่งภาวนาพรหมาศพาดตัก → กาลสูรมาทูลข่าว → อินทรชิตโกรธ "มาพูดให้เป็นลางกลางพิธี" (พิธีเสีย = ชื่อฉาก) → ทรงศรออกจากโรงพิธี → สั่งรุทการให้การุณราชแปลงเป็นเอราวัณ โยธาแปลงเป็นเทวดา–นางฟ้า → อินทรชิตขึ้นแท่นจำแลงเป็นพระอินทร์ → (2558) ฉุยฉายอินทรชิต → ชมตลาด ทรงเครื่อง เสด็จมาเกย
- **ลำดับคิว (ตับพรหมาสตร์):** [เชิด] → **ร้องมอญรำดาบ** (กาลสูรทูล) → **ร้องร่ายดั้น** (อินทรชิตโกรธ) → **[พราหมณ์ออก]** → **ร้องช้างประสานงา** (สั่งแปลงกาย) → **ร้องฝรั่งควง** (รุทการรับคำ) → **ร้อง/หน้าพาทย์ตระนิมิต** (แปลงกาย) → *(2558: ร้องฉุยฉาย–แม่ศรี อินทรชิตแปลง [ตำแหน่ง ต้องตรวจสอบ])* → **ร้องชมตลาด** (ทรงเครื่อง) → **[บาทสกุณี]**
- **หมายเหตุ 2552:** ผู้ชมบันทึกลำดับ ร่ายดั้น → ช้างประสานงา → ชมตลาด → **พักครึ่ง 15 นาที** (ไม่ได้บันทึกฝรั่งควง/ตระนิมิต)
- **ต่างจาก ร.2:** ใน ร.2 อินทรชิตขับกาลสูรไปแล้ว "กลับนั่งตั้งใจภาวนา" จนพิธีสำเร็จ (ตัดหัวสัตว์ให้พรหมาศสูบเลือด) แต่ในตับ "ว่าพลางทางทรงศรชัย คลาไคลออกจากโรงพิธี"

### ฉากที่ 6 (ช่วงแรก) — ศรพรหมาศ
- **ฉาก:** สนามรบ ช้างเอราวัณ (2558 ประติมากรรมสูง > 3.5 ม. ขยับงวง/คอได้ทั้ง 3 เศียร/ทรุดหมอบได้) ยืนผงาดบนฟ้าพร้อมเทวดา–นางฟ้า; ฝั่งพื้นดินคือทัพพระลักษมณ์
- **ตัวละคร:** อินทรชิตแปลง (พระอินทร์), การุณราช (เอราวัณ), โลทัน (เทพบุตรควาญ), เทวดา–นางฟ้าแปลง, นักสิทธิ์วิทยาธร; พระลักษมณ์, หนุมาน, สุครีพ, องคต, พลวานร
- **เหตุการณ์:** ขบวนทัพพระอินทร์แปลงเคลื่อนลอยฟ้า → ทัพพระลักษมณ์ออกสนามรบ → เอราวัณหยุดกลางเวหา ให้แปลงกายจับระบำ → พระลักษมณ์และวานรเพลินดู → อินทรชิตบูชาศร แผลงศรพรหมาศเป็นฝนศร ต้องพระลักษมณ์และพลวานรสลบ → หนุมานไม่ต้องศร ด่าพระอินทร์ เหาะขึ้นตีควาญ หักคอเอราวัณ ชิงคันศร → อินทรชิตฟาดหนุมานตกลงพร้อมเศียรช้าง → ทัพยักษ์กลับลงกา
- **ลำดับคิว (ตับพรหมาสตร์ + 2552):** [วงเครื่องประโคม–เครื่องสูงเข้าประจำ (2552)] → **ร้องกราวนอก** → **ร้องทะแยกลองโยน** ("ช้างเอยช้างนิมิตร") → **พากย์เอราวัณ** (กาพย์ฉบัง ร.2 — ยืนยัน 2552; ตำแหน่งก่อน/หลังทะแยกลองโยน **[ต้องตรวจสอบ]**) → **[เชิด]** (ทัพพระลักษมณ์ออก 2552) → **ร้องกระบอก** → **ร้องแขกอาหวัง** → **[ปี่พาทย์ทำเพลงสร้อยสน] + ร้องสร้อยสน = ระบำพรหมาสตร์** → [เพลงเร็ว–ลา (ทำนองหลักใน TSU: สองไม้/เร็ว แขกมัดตีนหมู → ลา)] → **ร้องกล่อม** → **[พัดชา]** → **ร้องกระบอกทอง** → **ร้องเชิดฉิ่ง (เห่เชิดฉิ่ง)** → **[เชิดกลอง / เชิดชั้นเดียว]** → **ร้องร่ายรุด** (ฝนศร) → [โอด] → **ร้องลิงโลด** (หนุมาน) → **ร้องลิงลาน** (อินทรชิตสู้) → **[โอดแหบ]** → **ร้องกราวรำพม่า** → [เชิด สองชั้น–ชั้นเดียว] ยักษ์กลับ
- **Choreography/Spectacle:** ระบำพรหมาสตร์ = "ระบำหน้าช้าง" (พระ–นาง แต่งยืนเครื่อง พระสวมชฎายอดชัย นางสวมมงกุฎกษัตริย์) ขั้นตอน: รำออกทำนองสร้อยสน → รำตามบทร้องสร้อยสน → รำเข้าเพลงเร็ว–ลา; 2552: เทวดานางฟ้าเหาะไปมา ลิงเล็กไขว่คว้า, หนุมานเหาะ (สลิง) ตีลังกา 2 ตลบเหยียบงาช้าง, คอช้างหักจริง, ไอน้ำแข็งแห้ง ฉากฟ้ายกขึ้น ช้างลดระดับ พระอินทร์แปลงลอยด้วยสลิง; 2558: ขบวนมีนักดนตรีวงประโคมแบบพระราชพิธีเดินในขบวน (กลอง–เครื่องเป่า)

### ฉากที่ 6 (ช่วงหลัง) — แก้ศรพรหมาศ
- **ฉาก:** สนามรบยามพลบ–ค่ำ (ไฟเวทีหรี่ พระลักษมณ์นอนมีศรปักอกกลางเวที) → ภูผาอาวุธ → สนามรบ; 2558 ปิดด้วยพระจันทร์นูนต่ำ Ø ≈ 3.5 ม. ส่องเขาสรรพยา
- **ตัวละคร:** พระราม, พระลักษมณ์ (สลบ), หนุมาน, พิเภก, (ร.2: พระอินทร์ส่งฝน–ลม; เทวดารักษาภูผา)
- **เหตุการณ์ (2552/2558):** พระรามตามมาเห็นพลวานรกลาดเกลื่อน พระลักษมณ์ศรปักอก ฉุดศรไม่หลุด โศกเศร้า → ลม (พระพาย) พัดต้องหนุมานฟื้น ทูลเหตุ → พิเภกทูลว่าศรชื่อพรหมาศ ยาแก้อยู่ภูผาอาวุธ ต้องแก้ก่อนรุ่งแสงทอง → หนุมานไปยกภูเขามา → ครอบคิรีเคาะยาให้หล่น ทุกคนฟื้น → พระรามเตือนพระลักษมณ์ → กลับพลับพลา
- **ลำดับคิว:** **พากย์** ("ครั้นถึงสนามราวี") → **พากย์โอ้** ("ไม่เขยื้อนแลเลื่อนหลุด" ลงโอ้ปี่ใน–โอด) → *(ช่วงหนุมานฟื้น / พิเภกทูล / หนุมานไปเอายา — คิวเพลงไม่พบ; ต้นฉบับ ร.2 กำกับ สาธุการ, เจรจา, เชิด, ตระ)* → **ร้องแขกบรเทศ** ("แล้วครอบคิรีกับรี้พล") → [เชิด] กลับพลับพลา **[ต้องตรวจสอบคิวส่วนกลาง]**
- **ตัดออก (2552):** ตอนสีดา–ตรีชฎานั่งบุษบกมาดูศพที่สนามรบ (มีใน ร.1 และ ร.2)
- **ระยะเวลา (2552):** องก์หลังราว 1 ชม. (รวมทั้งเรื่อง ≈ 2 ชม.)

## ฉบับ D — สายกรมศิลปากร / วิทยาลัยนาฏศิลปเชียงใหม่ "ศึกพรหมาสตร์" (11 ก.ค. 2553)
ร้อยเรื่องยาวกว่า (ตามโครง ร.1 ผสม): พระรามฆ่ามังกรกัณฐ์ (ด้วยศรพรหมาสตร์) → ทศกัณฐ์ให้วิรุญมุขขัดตาทัพ → ชามพูวราชทำลายพิธีนาคบาศ → พระลักษมณ์ต้องนาคบาศ พระรามแผลงศรพลายวาตเรียกครุฑ → อินทรชิตขอทำพิธีชุบศรพรหมาสตร์ → ทศกัณฐ์ให้กำปั่นรบ (หนุมานฆ่า) → อินทรชิตโกรธ พิธีไม่สำเร็จ → แปลงเป็นพระอินทร์ + ระบำ + วานรเกี้ยวนางฟ้า (ตลก) → แผลงศรแบบห่าฝน → หนุมานพยายามถอนศร ต่อว่าพระอินทร์ หักเศียรเอราวัณ ตกลงสลบ → อินทรชิตกลับเมื่อพลบค่ำ → พระรามตามมา โศกจนสลบ → พิเภกกลับจากหาผลไม้ ร่ายเวทเป่าลมให้หนุมานฟื้น → ยาอยู่เขาอาวุธ บุพพวิเทหทวีป มีจักรกรดพัด เข้าได้แต่หนุมาน → หนุมานช้อนเขามา เทวดาให้วางทิศอุดร ลมพัดกลิ่นสรรพยาให้ฟื้น → ยกทัพกลับ → ลิงขาว–ลิงดำตีลังกาปิดท้าย
- บทโขน/คิวเพลงของสายนี้ **[ยังไม่พบบทต้นฉบับ — ต้องตรวจสอบ: "บทโขน ชุดพรหมาสตร์" สำนักการสังคีต กรมศิลปากร (มีฉบับที่เผยแพร่ใน Scribd ชื่อ "บทโขน พรหมาสตร์ แบบ อ.เสรี" document 703785107 — เข้าถึงไม่ได้จากเครื่องมือนี้), วิทยานิพนธ์ ธีรภัทร์ ทองนิ่ม "แบบแผนและกลวิธีการพากย์-เจรจาโขนของกรมศิลปากร" (จุฬาฯ), วิทยานิพนธ์ "ระบำในการแสดงโขนของกรมศิลปากร" (จุฬาฯ)]**

## ข้อขัดแย้ง/ความต่างระหว่างแหล่ง
1. **ทำนองรำเข้าระบำพรหมาสตร์:** แหล่งเรียนรู้นาฏศิลป์ระบุ "เพลงเร็ว (ต้นบรเทศ และแขกบรเทศ)" แต่หนังสือเพลงตับฯ ให้ทำนอง "สองไม้แขกมัดตีนหมู – เร็วแขกมัดตีนหมู – ลา" → ต่างสายการบรรจุ **[ต้องตรวจสอบกับฉบับแสดงจริง]**
2. **2552 "เชิดร่าย" vs ตับ "ร่ายรุด"** สำหรับบท "ลูกศรกระจายดังสายฝน" — น่าจะเป็นการจดชื่อคลาดของผู้ชม
3. **หนุมานถูกอะไร:** ร.2/ตับ = คันศร (ตีต้อง); บล็อกเชียงใหม่ = "หอก" และบรรยายว่าหนุมานพยายามถอน "หอกพรหมาสตร์ที่ปักอกพระราม" (น่าจะเขียนคลาด)
4. **หนุมานฟื้นอย่างไร:** ร.2 = พระอินทร์ร่ายอาคมให้ฝน–ลมพัด; 2558 = "ต้องพระพายพัด"; สายเชียงใหม่ = พิเภกร่ายเวทเป่าลม
5. **ยาแก้ศร:** ร.2 = "ภูผาอาวุธ" ต้องแก้ก่อนแสงทอง ภูเขาไม่ยอมลงดินเพราะกลิ่นยาจะชุบศพยักษ์ด้วย หนุมานจึงนิมิตหัตถ์ครอบ; สายเชียงใหม่ = เขาอาวุธ บุพพวิเทหทวีป มีจักรกรด วางทิศอุดรให้ลมพัดกลิ่น
6. **ผู้ชมเคยเห็นฉบับที่หนุมานต้องไปหยุดรถพระอาทิตย์** (บล็อก 2552) — ไม่มีใน ร.2 และโขนพระราชทาน

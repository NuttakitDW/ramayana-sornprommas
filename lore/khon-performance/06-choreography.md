# 06 — กระบวนท่ารำและการเคลื่อนไหว (Choreography & Movement Language)

> ขอบเขต: ภาษาท่าทางของตัวโขนแต่ละประเภท + ลำดับช่วงท่ารำสำคัญของ **ชุดศึกอินทรชิต ตอนพรหมาศ** สำหรับทีม animation / mocap
> ดนตรีและบทร้องเป็นงานของอีกทีม — ไฟล์นี้ระบุชื่อเพลง/บทเฉพาะเป็น "cue" ของท่าเท่านั้น
> รหัส `[C#]` → URL ใน "แหล่งอ้างอิง" · `[ต้องตรวจสอบ]` = ยังยืนยันไม่ได้

## 1. หลักพื้นฐานของการเคลื่อนไหวโขน

- โขนแต่เดิม "หนักไปทางสู้รบมากกว่าร่ายรำ … โลดเต้น" ผู้แสดงสวมหน้ากากถืออาวุธ (บันทึกลาลูแบร์) [C5]
- ผู้แสดง 4 จำพวก: **ตัวพระ ตัวนาง ตัวยักษ์ ตัวลิง** แต่ละจำพวกคัดรูปร่างและฝึกท่วงท่าต่างกัน [C5]
- ทุกจำพวกฝึกพื้นฐานร่วม: **ตบเข่า ถองสะเอว เต้นเสา** เพื่อจังหวะ; **ถีบเหลี่ยม** ให้ตั้งเหลี่ยมได้ฉากและมั่นคง; เต้นจังหวะแบบ **"ตะลึกตึก"** = ย่อเข่าทั้งสองเป็นมุมฉาก ยกเท้ากระทืบพื้นสลับข้างข้างละครั้ง [C5]
- **เหลี่ยม** = ระยะเข่าที่แบะออก; เหลี่ยมที่กว้างที่สุดคือ **เหลี่ยมยักษ์** (อ้างจากผลค้นหา บทความ "ท่าโขนยักษ์ ลิง ได้จากท่ากบขอฝน" — เข้าถึงหน้าเว็บต้นทางไม่ได้) [ต้องตรวจสอบ]
- **ไม่แสดงอารมณ์ทางสีหน้า** — ตัวพระที่เปิดหน้ายังต้องรำตาม "แม่ท่า" และคง "หน้าตาย" เพื่อรักษารูปแบบเดิมที่เคยสวมหน้า (ต่างจากละครเสภา/พันทางที่ยิ้ม ยักคิ้วได้) [C3]
- **ตีบท / ภาษาท่า:** ผู้แสดงแปลคำพากย์–เจรจาเป็นท่า ทั้งแบบ **รูปธรรม** (ชี้/แทนสิ่งที่อยู่ในฉาก) และ **นามธรรม** (ท่าสื่อคุณลักษณะ) มักตีบท "รวบคำ" หรือตีช่วงท้ายของคำ [C9]
- ชนิดคำพากย์ที่กำหนดโหมดการรำ [C9]:
  | พากย์ | ใช้เมื่อ | ตัวอย่างท่า |
  |---|---|---|
  | พากย์เมือง/พลับพลา | ตัวเอกออกว่าราชการ | เปิดด้วย "ท่ารับตะโพน" (ท่าเล็ก เช่น สอดสร้อยมาลา, นางนอน, บัวชูฝัก → ท่ากลาง เช่น ผาลาเพียงไหล่) |
  | พากย์รถ | ชมพาหนะ/ขบวน | บนราชรถใช้ **ท่าฉายศร** (นายทัพสั่งเคลื่อนทัพ), สอดสูงมือล่อแก้ว (ชมเพชรพลอยประดับรถ) |
  | **พากย์โอ้** | โศกเศร้า คร่ำครวญ | **ท่าเช็ดน้ำตา, เซเท้า สะดุ้งตัวเหมือนสะอื้น, ตบหน้าอกพร้อมสะดุ้งตัว 2–3 ครั้ง, ท่ามองหา** |
  | พากย์ชมดง | ชมธรรมชาติ | ท่าสื่อธรรมชาติ |

## 2. ภาษาท่าทางตามประเภทตัวละคร (Movement profile per archetype)

### 2.1 ตัวพระ (พระราม, พระลักษมณ์, อินทรชิตแปลง, เทวดา)
- รูปร่างที่คัด: หน้ารูปไข่ คอระหง ไหล่ลาดตรง อกใหญ่ เอวเล็ก ท่าทาง "สะโอดสะองและผึ่งผาย" [C5]
- **พระใหญ่ (พระราม) vs พระน้อย (พระลักษมณ์):** พระใหญ่บุคลิกเหนือกว่า ตัวโตกว่า [C5][C10]
- ในบทกลางแจ้ง/รบ ตัวพระเป็นฝ่าย "ขึ้นลอย" (ยืนบนตัวคู่ต่อสู้) ได้ [C5][C11]
- Animator note: ลำตัวตั้งตรง ศีรษะนิ่ง น้ำหนักอยู่กลางเหลี่ยม การเปลี่ยนท่าลื่นต่อเนื่อง ปลายนิ้วงอนเสมอ (ดัดนิ้วและแขนตั้งแต่ฝึกนั่ง [C5])

### 2.2 อินทรชิตแปลง — "ตัวพระที่มียักษ์แฝง" (หัวใจการแสดงของตัวละครนี้)
- รำ **ฉุยฉายอินทรชิต** (บทร้องพระราชนิพนธ์ รัชกาลที่ 6) เป็นรำอวดความงามหลังแปลงกาย: **151 ท่า**; ท่ารำออกแบบในกรมมหรสพสมัย ร.6 โดย **พระยานัฏกานุรักษ์** → หลวงวิลาศวงงาม → ครูอาคม สายาคม → ครูทองสุก ทองหลิม → อ.ไพฑูรย์ เข้มแข็ง [C3]
- จารีตลำดับเพลง: ออกด้วย **เพลงรัว → เพลงรับ (ร้องฉุยฉาย ต่อด้วยแม่ศรี) → เพลงเร็ว → เพลงลา** ใช้วงปี่พาทย์เครื่องห้า [C3]
- ลีลา: "แม้แปลงกายเป็นตัวพระก็ต้องแฝงลีลานิ่ง ๆ สง่างาม ภาคภูมิ … รำให้ดูแข็งแรง ผสมความน่าศรัทธาเคารพ เพราะอยู่ในร่างพระอินทร์ บางครั้งแฝงท่ายักษ์เล็กน้อย" ผู้รำควรมี "ภูมิ" แบบพระใหญ่ [C3]
- **ท่ายักษ์ที่แทรก: "ลงวง"** = มือทั้งสองทำท่ามือล่อแก้ว ตั้งวงระดับล่าง [C3]
- อุปกรณ์: ตามบทควรถือวชิราวุธหรือคันศร แต่เพราะเกะกะการรำ **จึงไม่ถืออาวุธ** ขณะรำฉุยฉาย [C3]
- ฉากที่เหมาะ (แบบแผน): ฉากท้องฟ้า สวรรค์ วิมาน [C3]
- โขนพระราชทาน 2558 ระบุว่า **เพิ่มบทฉุยฉายจากบทโขนพระราชนิพนธ์ รัชกาลที่ 6** เข้าไปในการแสดง [C13][C14]
- Animator note: base = คลิปตัวพระ; ใส่ "noise" ของยักษ์เป็นจังหวะ (ท่าลงวง, ความหนักแน่นของเท้า) ไม่ใช่ตลอดเวลา — เป็นเครื่องมือเล่าเรื่องว่า "นี่คือยักษ์ปลอมตัว"

### 2.3 ตัวยักษ์ (ทศกัณฐ์, อินทรชิตร่างยักษ์, มังกรกัณฐ์, เสนา/เขนยักษ์)
- คัดคนรูปร่างสูงใหญ่ วงเหลี่ยมแข็งแรง การทรงตัวต้องดูแข็งแรง เยื้องย่างสง่า [C5]
- **ทศกัณฐ์** หัดยากที่สุด ต้องแข็งแรงช่วงขามากเพราะต้อง **ย่อเหลี่ยมรับการขึ้นลอยของตัวพระและตัวลิง**; ยามโกรธ **กระทืบเท้าตึงตัง หันหน้าหันหลัง**; ยามสบายใจ **นั่งกระดิกแขนกระดิกขา**; ยามเขิน ส่ายไหล่ ปัดชายไหวชายแครง ประกบฝ่ามือที่อกถูไปมาแล้วปัดหน้า [C5]
- ฝึก **6 แม่ท่ายักษ์** (ใช้ตอนออกกราวนอก) + ท่ารบ: **ท่ารบหนึ่ง/ท่าจับ, ท่ารบสอง ("สามทีไขว้"), ท่าหกกัด, ท่าหกฉีก–หกฉีกต่อเนื่อง, ท่าขึ้นลอย** [C5] (ชื่อทั้ง 6 แม่ท่ายังไม่ได้รวบรวม [ต้องตรวจสอบ])
- อินทรชิต (ร่างยักษ์) จังหวะอารมณ์สำคัญ: **"ลุกขึ้นกระทืบบาทหวาดไหว"** เมื่อถูกขัดพิธี (บทร้องร่ายดั้น ฉบับ 2552) [C7]

### 2.4 ตัวลิง (หนุมาน, สุครีพ, องคต, ชมพูพาน, เขนลิง)
- คัดคนไม่สูงมาก คล่องแคล่ว ดัดร่างกายให้อ่อน "ไม่อยู่นิ่งกับที่ ตีลังกาลุกลี้ลุกลน"; ฝึกตั้งแต่ 8–12 ขวบ ต้องใช้ 10 ปีขึ้นไปจึงเล่นตัวเอกได้ [C5]
- ฝึก **7 แม่ท่าลิง** + ท่ามองในท่าเสี้ยว ท่าคว้า ท่าขู่ ท่าหย่อง **ท่าเกา** (เกาคาง เกาหัวเข่า เกาเอว จับหมัด ดมแมลง ฯลฯ) [C5]
- กายกรรม: ฉีกขา หกคะเมน ม้วนหน้า–หลัง พุ่งม้วนสามตัว; ท่าหกคะเมน 3 แบบ: **"ตีลังกาหกม้วน"** (หงายไปหลัง), **"อันธพา"**, **"พาสุริน"** (หมุนตัวไปข้าง) [C5]
- ท่าลิงเฉพาะ (จากการวิเคราะห์ฉุยฉายมานพ) ใช้เป็นคลัง gesture ได้: **เกาคาง** (ปลายมือขวาเกาคางถี่ ๆ), **เล่นแมลงวัน** (มือขวาตบฝ่ามือซ้าย มือซ้ายจับแมลงวันระดับอก ตบถี่ ๆ แล้วสะบัดมือ), **กาจับปากโลง** (ตั้งวงล่าง เท้าซ้ายวางเต็ม เท้าขวาใช้จมูกเท้าแตะพื้น 3 ครั้ง ถอนเท้าซ้ายตาม กระโดด ยกเท้าขวาทำท่าหย่องเปิดส้น) [C3]
- บทร้องรามเกียรติ์ ร.2 บรรยายกิริยาพลวานรระหว่างเดินทัพ: "บ้างโลดเต้นเผ่นผกหกกลับ กระโดดจับแมลงวันคันสีข้าง บ้างนั่งลงหาเหาเกาแข้งคาง" [C12] → idle/crowd animation ของพลลิง

### 2.5 ตัวนาง (นางฟ้าแปลง)
- กิริยาเรียบร้อย นุ่มนวล "ยามโศกหรือยิ้มแย้ม ก็กรีดกรายนิ้วมือแต่เพียงพองาม"; นั่งพับเพียบหนีบขาซ้อนลดหลั่น (ต่างจากพระ/ยักษ์/ลิงที่แบะเข่า) [C5]
- ฉบับ 2558 ผู้แสดงนางฟ้าแปลงเป็นผู้หญิงจริง "การรำที่อ่อนช้อยบอบบาง" [C8]

## 3. ลำดับช่วงท่ารำสำคัญของชุดพรหมาศ (Key choreographed moments, in order)

> โขนพระราชทานจัดชุดนี้ 3 ครั้ง (2550, 2552, 2558) บทมาจากบทคอนเสิร์ต "ตับพรหมาศ" ของสมเด็จฯ เจ้าฟ้ากรมพระยานริศรานุวัดติวงศ์ + บทพระราชนิพนธ์ ร.2 (+ บทฉุยฉาย ร.6 ในปี 2558) [C6][C13]; "ด้านกระบวนท่ารำ … ไม่มีความต่าง" ระหว่าง 3 ปี เพราะเป็นโขนแบบละครตามรูปแบบกรมมหรสพ [C6]
> ลำดับด้านล่างสร้างจาก **รีวิวรอบ 21 มิ.ย. 2552 ที่เรียบเรียงจากสูจิบัตร** [C7][C8b] + โครงฉาก 2558 [C13] — ใช้เป็น beat sheet ของ animation

| 6 | **ขบวนทัพพระอินทร์แปลง** | เปิดองก์ด้วยขบวนแห่; วง **เครื่องประโคม–เครื่องสูง** ขึ้นประจำที่ (2558: "นักดนตรีอารมณ์หลวง ตีกลองและเป่าเครื่องเป่าแบบงานพระราชพิธี"); บทพากย์ชมเอราวัณ 33 เศียร; บทจัดทัพ: **ทัพหน้า อารักษ์ไพรสัณฑ์ / ทัพหลัง สุบรรณ กินนร นาค / ปีกซ้าย ฤๅษี วิทยาธร / ปีกขวา คนธรรพ์** ถือ "โตมร ศร พระขรรค์ คทา" "ลอยฟ้ามาในเวหน"; **โลทัน สารถีขุนมาร เป็นเทพบุตรควาญขับท้ายช้าง** | ร้องทะแยกลองโยน, บทพากย์ชมโฉม | [C8b][C8] |
| 7 | ทัพพระลักษมณ์ออก | พระลักษมณ์ยืนรถรัตนากลางพลวานร (ท่าบนราชรถ — ดูพากย์รถ §1) | ร้องเพลงกระบอก | [C8b][C9] |
| 8 | **ระบำหน้าช้าง / ระบำเทวดา–นางฟ้าแปลง** | "ฉากช้างเอราวัณยืนผงาดบนฟ้า พร้อมหมู่เทวดานางฟ้า"; อินทรชิตหยุดช้าง ให้กุมภัณฑ์จำแลง "ใส่กลขับรำระบำบรรพ์"; **เทวดานางฟ้าเหาะไปมาให้ลิงเล็กลิงน้อยไขว่คว้า**; พระลักษมณ์และพลเพ่งมอง "พระเพลินเจริญตา" | ดู §4 | [C8b] |
| 9 | **แผลงศรพรหมาศ** | อินทรชิตแปลง "เห็นได้ที" แผลงศร → "ลูกศรกระจายดังสายฝน ตกถูกลิงพล … แล้วต้องพระอนุชา … สลบไป" | ร้องเชิดร่าย | [C8b] |
| 10 | **หนุมานสู้ / หักคอเอราวัณ** | หนุมานไม่ต้องศร โกรธ ชี้หน้าว่า "เหวยสหัสนัยน์" → **เหาะขึ้นด้วยสลิง ตีลังกา 2 ตลบ เหยียบงาช้างเอราวัณ รบกับพระอินทร์(แปลง)** → "ขึ้นตีควาญท้ายคชา" → **ง้างหักคอช้าง ชิงคันศร** → อินทรชิตซัดหนุมาน **ตกลงมาพร้อมคอช้าง** | ร้องลิงโลด | [C8b][C4] |
| 11 | ยักษ์กลับเมือง | พลยักษ์ดีใจ "สรวลสันต์หรรษา" คืนลงกา | ร้องกราวรำพม่า | [C8b] |
| 12 | **ภาพพระล้ม (tableau)** | ไฟหรี่ เปลี่ยนฉากหลัง; **พระลักษมณ์นอนนิ่งกลางเวที มีศรปักอก** รายล้อมด้วยพลวานรที่ล้ม | — | [C8b] |
| 13 | พระรามโศก | พระรามมาสนามรบ (พากย์) → **เข้าฉุดชักศรไม่เขยื้อน** → กอดน้อง น้ำตาไหล (พากย์โอ้: ท่าเช็ดน้ำตา ตบอกสะดุ้งตัว) | พากย์ / พากย์โอ้ | [C8b][C9] |
| 14 | แก้ไข | **พระพายพัดมาต้อง หนุมานฟื้น** ทูลเหตุ; พิเภกทูลวิธีแก้; หนุมานไปเอายาก่อนรุ่งเช้า | — | [C8b] |
| 15 | ฟื้นคืน | **หนุมานแบกภูเขากลับมา "ครอบคีรีกับรี้พล เคาะยาให้หล่นจากเขาใหญ่"** → พระลักษมณ์และพลฟื้น → จบ (ความยาวทั้งหมด ~2 ชม.) | ร้องแขกบรเทศ | [C8b] |

**กฎการจบเรื่อง ("พระล้ม"):** โขนไม่นิยมจบตรงที่ฝ่ายมนุษย์แพ้ยักษ์ ("พระล้ม") ถือเป็นลางร้าย ต้องเล่นต่อจนมีผู้แก้ไข — โขนพระราชทานชุดพรหมาศ 2552 จึงต่อเรื่องจนพระลักษมณ์ฟื้น (บทคอนเสิร์ตต้นฉบับจบแค่พระลักษมณ์ต้องศร) [C12] → **เกมไม่ควรจบ chapter/ending ที่ภาพพระล้ม** ถ้าต้องการความถูกต้องตามขนบ
**ภูเขายา:** รีวิว 2552 ว่า "ภูเขาอาวุธ" [C8b] (สอดคล้อง Wikipedia "โอสถที่เขาอาวุธ" [C4]); ฉาก 2558 ใช้ "**เขาสรรพยา**" ใต้แสงจันทร์ [C13] — ชื่อภูเขาในแต่ละฉบับต่างกัน [ต้องตรวจสอบ กับทีม plot]

## 4. ระบำในชุดนี้ (The ระบำ)

### 4.1 ระบำพรหมาสตร์ / "ระบำหน้าช้าง" (แบบแผนกรมศิลปากร)
- ระบำเทวดา–นางฟ้าประกอบโขนชุดศึกพรหมาสตร์ พลยักษ์แปลงเป็นเทพบุตรและนางฟ้า "พากันเหาะฟ้อนรำ นำขบวนไปหน้าช้าง" จึงเรียกอีกชื่อว่า **ระบำหน้าช้าง** [C1]
- **ระบำหมู่พระ–นาง** "เป็นการรำตามรูปขบวนเกียรติยศเครื่องสูง" [C1]
- ขั้นตอน: (1) **รำออก** ตามทำนองเพลงสร้อยสน → (2) **รำตามบทร้อง** เพลงสร้อยสน (4 คำกลอน) → (3) **รำเข้า** ตามทำนองเพลงเร็ว–ลา; วงปี่พาทย์ไม้แข็ง [C1]
- บทร้อง (พระนิพนธ์กรมพระยานริศฯ ในบทคอนเสิร์ต) บอก **formation** ตรง ๆ: "ต่างจับระบำรำฟ้อน ทอดกรกรีดกรายซ้ายขวา / ร่ายเรียงเคียงคมประสมตา เลี้ยวไล่ไขว่คว้าเป็นท่าทาง / ซ้อนจังหวะประเท้าเคล่าคล่อง เลี้ยวลอดสอดคล้องไปตามหว่าง / วงเวียนเหียนหันกั้นกาง **เป็นคู่คู่อยู่กลางอัมพร**" [C1] → จัดเป็น **คู่ พระ–นาง**, มีการ **เลี้ยวลอดสอดสลับแถว** และ **เดินวงเวียน**
- ประวัติ: กรมศิลปากรแสดงชุดนี้ที่โรงโขนหลวงมิสกวัน สนามเสือป่า พ.ศ. 2476; ปี 2503 จัดใหม่ **องก์ที่ 4 ศรพรหมาสตร์ ปรับปรุงโดยนายประพันธ์ สุคนธชาติ** ใช้บทคอนเสิร์ตทั้งหมด แต่งเจรจาแทรกท้ายระบำ; ท่ารำสืบทอดโดยครูวิทยาลัยนาฏศิลป [C1]
- เครื่องแต่งกาย: ยืนเครื่อง พระเสื้อแขนสั้น ชฎายอดชัย; นางมงกุฎกษัตรีย์ [C1]
- **ผู้ประดิษฐ์ท่ารำ:** หลายเว็บการศึกษาอ้างว่า **ครูลมุล ยมะคุปต์ และครูเฉลย ศุขะวณิช** มีส่วนสร้างสรรค์ แต่หน้าองค์ความรู้ของกรมศิลปากรเอง **ไม่ระบุชื่อผู้ประดิษฐ์** [C1][C16] → [ต้องตรวจสอบ]
- **จำนวนผู้แสดง:** ไม่พบแหล่งที่ระบุจำนวนคู่ [ต้องตรวจสอบ]

### 4.2 ระบำในโขนพระราชทาน
- 2552: เทวดานางฟ้า **เหาะไปมา** (บนลวด/ยกลอย) หน้าช้างที่ยืนบนฟ้า ให้ลิงไขว่คว้า [C8b]
- 2558: นางฟ้าแปลงเป็นผู้หญิงจริง "ผิวขาวผ่านการลงแป้ง … ผ้าแพรผ้ายกที่นุ่งขึ้นไฟดี … การรำอ่อนช้อย" พร้อมเครื่องเกียรติยศในขบวน [C8]
- ไม่พบข้อมูลว่าโขนพระราชทานใช้ท่ารำระบำพรหมาสตร์ของกรมศิลปากรตรงตัว หรือออกแบบใหม่ / ใครเป็นผู้ประดิษฐ์ / จำนวนผู้แสดง [ต้องตรวจสอบ]; ที่ทราบคือ ผู้จัดทำบทและกำกับการแสดงโขนพระราชทานคือ **ประเมษฐ์ บุณยะชัย** [C12] และนักแสดงปี 2550/2552 มาจากสำนักการสังคีต กรมศิลปากร และวิทยาลัยนาฏศิลป (2558 เปิดคัดเลือกเยาวชน) [C6]

## 5. ขนบการรบ (Battle choreography conventions)

- **ขึ้นลอย** = ผู้แสดง "ต่อตัวขึ้นเหยียบบริเวณลำตัวของคู่ต่อสู้และยกลำตัวให้ลอยขึ้นจากพื้น" ทำได้ทั้งตัวพระ ยักษ์ ลิง นาง แบบคู่และแบบกลุ่ม ต้องคำนึงถึงจารีต เครื่องแต่งกาย อาวุธ บุคลิกตัวละคร [C11]; ตัวยักษ์ใหญ่ (ทศกัณฐ์) เป็นฐาน "ย่อเหลี่ยมรับ" [C5]
- ท่ารบของยักษ์ในการฝึก: ท่ารบหนึ่ง/**ท่าจับ**, ท่ารบสอง/**สามทีไขว้**, **หกกัด**, **หกฉีก** [C5]
- **ภาพนิ่ง/tableau** เป็นจุดพักของฉากรบ (เช่น พระลักษมณ์ต้องศรนอนนิ่ง) [C8b]
- ฉากรบใหญ่ชุดนี้เป็นการรบ **"คนบนพื้น vs ผู้อยู่บนฟ้า"**: พระลักษมณ์และลิงบนพื้นมองขึ้น; อินทรชิตแปลงบนช้างบนฟ้า; หนุมานเป็นตัวเดียวที่ **ขึ้นไปถึงระดับเดียวกับช้าง** (เหาะ/ลวด) [C8b][C4]
- เทคนิคพิเศษ "หักคอช้างเอราวัณ" เป็นจุดเด่นที่ได้รับการกล่าวถึงของฉบับโขนพระราชทาน [C2]

## 6. Notes for animators / mocap

1. **จ้างนักแสดงให้ตรงประเภท:** ตัวพระ/ยักษ์/ลิง/นาง ฝึกต่างสายตั้งแต่เด็ก (ลิง 10+ ปี) [C5] — mocap ตัวลิงจากนักเต้นทั่วไปจะไม่ได้ลีลา; แนะนำติดต่อผู้เชี่ยวชาญจากสถาบันบัณฑิตพัฒนศิลป์/สำนักการสังคีต (ข้อเสนอ ไม่ใช่ข้อมูลอ้างอิง)
2. **สองชั้นเวลา:** โขนเคลื่อนไหวตาม "หน้าทับ" ของปี่พาทย์ — คลิปควรตัดเป็นหน่วยตามจังหวะ (loopable) และ sync กับ stem ดนตรีที่ทีมเพลงเตรียม; ปี 2550 ที่ใช้วงโยธวาทิตมีปัญหาเพราะดนตรีตายตัวตามโน้ต ขณะปี่พาทย์ยืด–หดตามท่ารำได้ [C6] → ถ้าเป็น interactive ให้ดนตรีตามท่า ไม่ใช่ท่าตามดนตรี
3. **Mask weight:** ตัวสวมหัวโขน (หัวโขนงานช่างที่ SACIT บันทึกไว้สูงราว 62–73 ซม. รวมยอด — เป็นงานหัตถศิลป์ ไม่ใช่หัวที่ใช้บนเวทีโขนพระราชทานโดยตรง [ดูไฟล์ 05 S8/S9]) ศีรษะเคลื่อนไหวแบบหน่วงและเป็นมุม ไม่หมุนเร็ว; จุดศูนย์ถ่วงสูง ต้องให้ลำตัวชดเชย
4. **Facial:** ตัวพระ/นาง/เทวดาเปิดหน้าแต่ "หน้าตาย" [C3] → อารมณ์ทั้งหมดอยู่ที่มือ–ไหล่–เท้า (เช่น โศก = ตบอก สะดุ้งตัว; โกรธ = กระทืบเท้า)
5. **อินทรชิตแปลง:** base layer ตัวพระ + additive layer "ยักษ์" (ท่าลงวง, ถ่วงน้ำหนักเท้า) ที่ blend ขึ้นในจังหวะสำคัญ เช่น ก่อนแผลงศร
6. **ลิง crowd:** ทำ idle pool จากท่าเกา (คาง/เข่า/เอว), จับหมัด, ดมแมลง, เล่นแมลงวัน [C5][C3][C12]; ระหว่างระบำให้ลิง "ไขว่คว้า" เทวดาที่ลอยผ่าน [C8b]
7. **ท่าแผลงศร:** ยังไม่พบคำอธิบายขั้นตอนท่าแผลงศรโขนแบบเป็นลายลักษณ์อักษรที่ตรวจสอบได้ [ต้องตรวจสอบ] — ให้ถ่าย reference จากวิดีโอการแสดง/ครูโขนโดยตรง; ที่ยืนยันได้คือ "ท่าฉายศร" ใช้บนราชรถเพื่อสื่อการสั่งทัพ [C9]
8. **Wire/flying:** ต้นฉบับบนเวทีใช้สลิงจริง (กาลสูร, หนุมาน, อินทรชิตแขวนลอยหลังช้างลดระดับ) [C7][C8b] → ท่าลอยควรมีจังหวะ "ถูกยก" (ขาห้อย ลำตัวคงท่า) ถ้าต้องการกลิ่นอายเวที หรือทำ free flight ถ้าเน้นแฟนตาซี

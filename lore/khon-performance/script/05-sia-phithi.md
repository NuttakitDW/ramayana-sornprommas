# 05 — ฉากที่ 5 "เสียพิธี" (โรงพิธีชุบศรพรหมาศ)

> **รูปแบบ:** " / " = แบ่งวรรค · 1 บรรทัด = 1 บาท (กลอน) หรือ 1 บท (กาพย์) · `**[ปี่พาทย์ทำเพลง …]**` = เพลงหน้าพาทย์/บรรเลง · `**ร้อง…**` = เพลงร้อง · ข้อความในวงเล็บเหลี่ยม [ ] และตัวเอียงเป็นหมายเหตุของผู้เรียบเรียง ไม่ใช่ตัวบท

**ฉบับที่มีฉากนี้:** ทุกฉบับ
**ฉาก:** โรงพิธีที่หาดแก้วมรกต เชิงเขาสัตภัณฑ์ (ร.2) / "เนินจักรวาฬ" (บทพากย์) — ม่านทอง ระย้าแก้ว เครื่องบูชา แพะดำ–โคดำ; อินทรชิตและพลยักษ์แต่งเขียวล้วน
**ตัวละคร:** อินทรชิต, กาลสูร, รุทการ, การุณราช, พลยักษ์
**ลำดับที่ยืนยัน 2552:** ร้องร่ายดั้น → ร้องช้างประสานงา → ร้องชมตลาด → พักครึ่ง (https://www.bloggang.com/m/viewdiary.php?id=bookkii&month=06-2009&date=23&group=12&gblog=67)
**2558:** เพิ่ม "บทฉุยฉาย" จากบทโขนพระราชนิพนธ์ ร.6 (แนวหน้า 2558) — ตำแหน่งในฉากไม่ระบุ **[ต้องตรวจสอบ]**

## ก. (ทางเลือก/ปูเรื่อง) อินทรชิตตั้งพิธีชุบศร — ร.2
ภาพข่าว 2558 มี "อินทรชิตทำพิธี" แต่ไม่ทราบว่าร้องบทใด **[ต้องตรวจสอบ]** · ผู้ประพันธ์: ร.2 · แหล่ง: https://vajirayana.org/บทลคร-เรื่อง-รามเกียรติ์/เล่ม-๑

**ร้องชมตลาด** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> ปลูกโรงพิธีพลันทันใด / กว้างขวางโตใหญ่ไพศาล  
> จัดแจงแต่งตามพนักงาน / บ้างปูลาดดาดเพดานดาวราย  
> เครื่องบูชาน่าพระปักพุ่ม / กระจกซุ้มติดเสาเปนเงาฉาย  
> ห้อยระย้าแก้วกิ่งพริ้งพราย / ม่านสุวรรณพรรณรายรูจี  
> พระยี่ภู่ปูอาศน์ลาดผ้าขาว / พระแสงง้าวราวทอดไว้ตามที่  
> ทั้งแพะดำโคดำทำบัตรพลี / จัดครบเครื่องพิธีพลีกรรม์  
> *(บทที่ ๑๐๙๔ · ฯ ๖ คำ ฯ เจรจา)*

**เจรจา** *(ต้นฉบับกำกับให้เจรจา — ไม่มีตัวบทเจรจาในต้นฉบับ)*

**ร้องร่าย** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> เมื่อนั้น / อินทรชิตฤทธิแรงแขงขัน  
> มาอ่าองค์สรงชลฉับพลัน / สอดกระสันเครื่องทรงอลงการ์  
> ครั้นเสร็จสรรพจับศรพรหมมาศ / ยุรยาตรเยื้องย่างออกข้างน่า  
> ขึ้นทรงรถแก้วแววฟ้า / ให้ยกพลยาตราคลาไคล  
> *(บทที่ ๑๐๙๕ · ฯ ๔ คำ ฯ เชิด)*

**[ปี่พาทย์ทำเพลงเชิด]**

> ครั้นถึงที่เนินทรายชายสมุท / จึ่งให้หยุดพลนิกายนายไพร่  
> ลงจากรถสุวรรณทันใด / เสด็จไปโสรจสรงคงคา  
> *(บทที่ ๑๐๙๖ · ฯ ๒ คำ ฯ เสมอ)*

**[ปี่พาทย์ทำเพลงเสมอ]**

**ร้องชมตลาด** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> ชำระสระสนานน้ำกลั่น / กระแจะจันทน์เจิมภักตร์ยักษา  
> สอดสนับเพลาทรงอลงการ์ / ภูษาพื้นเขียวเขียนทอง  
> จีบจัดรัดโกปินำ / สายธุรำสอดสวมกรวมขนอง  
> โพกส่านน่าดอกไม้สีใบตอง / สอดซ้ำประคำทองถมยา  
> ล้วนสีเดียวเขียวสิ้นทั้งอินทรีย์ / ลม้ายเหมือนโยคีชีป่า  
> ครั้นเสร็จยุรยาตรคลาศคลา / ลีลามาสู่โรงพิธี  
> *(บทที่ ๑๐๙๗ · ฯ ๖ คำ ฯ เสมอ)*

**[ปี่พาทย์ทำเพลงเสมอ]**

**ร้องร่าย** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> จึ่งให้ใส่เพลิงโดยสาตร / เอาพรหมมาศพาดตักยักษี  
> ชักประคำสำรวมอินทรีย์ / อสุรีร่ายมนต์บ่นภาวนา  
> *(บทที่ ๑๐๙๘ · ฯ ๒ คำ ฯ ตระ)*

**[ปี่พาทย์ทำเพลงตระ]**

### บทพากย์ทางเลือก — "พากย์พิธีพรหมาสตร์" (กาพย์ฉบัง ๑๖; ไม่ปรากฏนามผู้แต่ง)
อินทรชิตทรงรถไปเนินจักรวาฬ ปลูกโรงพิธี (ช่วงท้ายบทย้อนไปทศกัณฐ์ออกท้องพระโรงให้หามังกรกัณฐ์) · แหล่ง: https://vajirayana.org/ประชุมคำพากย์รามเกียรติ์-เล่ม-๑/ประชุมคำพากย์รามเกียรติ์-ภาค-๑/พากย์พิธีพรหมาสตร์

**พากย์**
*[กาพย์ฉบัง ๑๖]*

> เสด็จทรงรถแก้วแพรวพรรณ / เพียงหนึ่งแสงจันทร์ / กระจ่างมากลางอัมพร  
> ราชสีห์สองพันพาจร / ธงไชยปักงอน / แปรกเปนรูปนาคินทร์  
> ระหนาบคาบแก้วแกมนิล / มรกตโกมิน / ประกอบประกับกงกำ  
> โตกตั้งบัลลังก์บุษราคัม / แก้วไพฑูรย์ทำ / เปนเทพประนมเรียงราย  
> สิงห์อัดอมดวงวิเชียรฉาย / แกะแก้วผลึกลาย / เปนรูปสุบรรณบินทะยาน  
> จัตุรมุขดาดมุกดาหาร / เสาแก้วสุรกานต์ / สลับกับทับทิมสี  
> ใบระกาแกมแก้วโมลี / นิลเนรคันถี / เปนทวยประเทืองเรืองไร  
> ใบโพเพชรรัตน์ตรัสไตร / ยอดย่อเจียระไน / ปัทมราชรองเรือง  
> ล้วนแล้วแก้วค่าควรเมือง / สอดแสงแดงเหลือง / ขาวเขียวขจีจับกัน  
> สีแก้วจับสีไพรวัน / เลื่อมเลื่อมพรายพรรณ / เพียงหนึ่งระลอกลายตา  
> แสงระยับจับเสื้อโยธา / จับแสงศัสตรา / ปปลาบดังเปลวไฟฟอน  
> เร่งรถคชสารอัสดร / เร่งพวกพลนิกร / กระทั่งสมรภูมิไชย ฯ  

*ฯ เจรจา ก็ถึงเนินจักรวาฬ ฯ* → **เจรจา**

> ให้ปลูกโรงรจนาใน / นอกหน้าศาลไชย / ให้ตั้งพิกัดกฎหมาย  
> รายด้วยราชวัติเรียงราย / แต้มเขียวเขียนลาย / ด้วยเบญจรงค์รจนา  
> ภาคพื้นเร่งให้ดาดดา / ด้วยแดงโสภา / เห็นงามประเทืองเรืองแสง ฯ  
> เมื่อนั้นทศเศียรราชา / เสด็จยังมหา / สิงหาสน์ภิมุขมณเฑียร  
> เสนามาตยานองเนียน / นอบนบน้อมเศียร / ศิโรตมเฝ้าบทมาลย์  
> ให้ชุมสุรโยธาหาญ / พฤฒิหมู่อาจารย์ / แลญาติวงศ์อสุรา  
> เสร็จสิ้นทุกกระทรวงแสนยา / พร้อมแสนเสนา / ในท้องพระโรงโจษจัน  
> นั่งเต็มโรงธารกำนัล / เอื้อนโองการพลัน / แก่หมู่อสูรมนตรี ฯ  

*ฯ เจรจา ให้หามังกรกัณฐ์ ฯ* → **เจรจา**

## ข. ตัวบทการแสดง (ตับพรหมาสตร์) — กาลสูรทูลข่าว → อินทรชิตเสียพิธี → แปลงกาย
แหล่ง: ตับพรหมาสตร์ (บทคอนเสิร์ต, สมเด็จฯ กรมพระยานริศรานุวัดติวงศ์ — สาธารณสมบัติ) ตามฉบับราชบัณฑิตยสถาน (2550ข: 115–119) อ้างใน คฑาวุธ พรหมลิ (2567) น. 158–159 · https://art.tsu.ac.th/upload/menu/doc_20250326_160524.pdf

**[ปี่พาทย์ทำเพลงเชิด]** *(กาลสูรเหาะมาถึง — ต่อจากไฟล์ 04)*

**ร้องเพลงมอญรำดาบ** — กลอนบทละคร *(เพลงที่มีทางเปลี่ยนสำหรับรับร้องเฉพาะตับนี้)*
> ครั้นถึงโรงราชพิธี / กาลสูรเสนีบังคมไหว้  
> ทูลว่าพระบิตุรงค์ทรงชัย / ให้มาทูลข่าวปัจจามิตร  
> แสงอาทิตย์ฤทธิรอนมังกรกัณฐ์ / ไปโรมรันเสียทัพดับจิต  
> ขอให้พระองค์ทรงฤทธิ์ / ไปเข่นฆ่าปัจจามิตรให้มรณา  

**ร้องร่ายดั้น** — กลอนบทละคร (ยืนยันในสูจิบัตร 2552)
> เมื่อนั้น / อินทรชิตสิทธิศักดิ์ยักษา  
> ได้ยินบอกออกความอัปรา / โกรธาลืมเนตรเห็นเสนี  
> ลุกขึ้นกระทืบบาทหวาดไหว / เหม่ไอ้กาลสูรยักษี  
> มาพูดให้เป็นลางกลางพิธี / ชีวิตมึงถึงที่จะบรรลัย  
> นี่หากคิดนิดเดียวว่ารับสั่ง / จะหยุดยั้งยกโทษโปรดให้  
> ว่าพลางทางทรงศรชัย / คลาไคลออกจากโรงพิธี  

**[ปี่พาทย์ทำเพลงพราหมณ์ออก]** *(ทำนองหลักใน TSU ระบุ "พราหมณ์ออก รัว")*

**ร้องเพลงช้างประสานงา** — กลอนบทละคร (ยืนยันในสูจิบัตร 2552)
> จึงตรัสสั่งรุทการชาญกำแหง / จะเปลี่ยนแปลงกายกูเป็นโกสีย์  
> จงให้การุณราชอสุรี / แปลงอินทรีย์เป็นคชาเอราวัณ  
> อันโยธาทั้งหลายให้กลายเพศ / เป็นเทเวศร์สุรางค์นางสวรรค์  
> ให้สำหรับขับรำระบำบรรพ์ / เร่งเตรียมไว้ให้ทันฤกษ์ดี  

**ร้องเพลงฝรั่งควง** — กลอนบทละคร
> บัดนั้น / รุทการประณตบทศรี  
> มาเร่งรัดจัดหมู่อสุรี / คอยตามภูมีรณรงค์  

**ร้อง (หน้าพาทย์ร้อง) เพลงตระนิมิต** — กลอนบทละคร *(ในตับจัดเป็นเพลงหน้าพาทย์ประเภทร้อง; ในการแสดงใช้ตระนิมิตประกอบการแปลงกาย)*
> เมื่อนั้น / อินทรชิตชื่นชมสมประสงค์  
> จึงขึ้นบนแท่นสุวรรณบรรจง / จำแลงแปลงองค์อสุรา  

**(เฉพาะ 2558) ร้องฉุยฉาย — ฉุยฉายอินทรชิต (อินทรชิตแปลงเป็นพระอินทร์อวดโฉม)** — บทฉุยฉาย · ผู้ประพันธ์: ร.6 (บทโขนตอนศึกพรหมาสตร์; สาธารณสมบัติ) · อ้างผ่าน ทักษิณ ทุนเกิด และคณะ (2563) ซึ่งอ้าง พรเทพ บุญจันทร์เพ็ชร์ (2558, น. 95) · https://www.human.nu.ac.th/wp-content/uploads/2024/10/DK-11-pp.-42-53.pdf
> ฉุยฉายเอย / ช่างเบือนบิดนิมิตกาย  
> เยื้องยาตรนาดกรกราย / งามเฉิดฉายเป็นหนักหนา  
> เหมือนราวกับรูปที่ช่างแกะ / งามจริงเทียวแหละเหมือนเจ้าเทวา  
> ฉุยฉายเอย / ช่างบิดเบือนได้เหมือนหมาย  
> โฉมเฉิดเลิศโฉมชาย / รูปยักษ์หายไปจนหมด  
> อรชรอ้อนแอ้นเอวกลม / ดูช่างน่าชมสมเกียรติยศ  

*[ท่ารำ: รำแบบตัวพระ นิ่ง สง่า ภาคภูมิ แฝงท่ายักษ์เล็กน้อยให้เห็นชาติกำเนิด (ทักษิณ ทุนเกิด 2563). ฉุยฉายตามขนบมักต่อด้วยเพลงแม่ศรี — บทแม่ศรีของอินทรชิต (ถ้ามี) ยังไม่พบ [ต้องตรวจสอบ: พรเทพ บุญจันทร์เพ็ชร์ (2558) นาฏกรรมโขนในพระบาทสมเด็จพระมงกุฎเกล้าเจ้าอยู่หัว; สูจิบัตร 2558]]*

**ร้องเพลงชมตลาด** — กลอนบทละคร (ยืนยันในสูจิบัตร 2552)
> เป็นโกสีย์ทรงเครื่องเรืองอร่าม / ล้วนแก้วเก้าเงางามวามเวหา  
> จับพระแสงพรหมาสตร์ยาตรา / เสด็จมาเกยสุวรรณทันใด  

*[สูจิบัตร 2552 ตามบล็อก: "จับพระแสงพรหมาศยาตรา"]*

## ค. ตัวบทต้นฉบับ ร.2 เทียบ — กาลสูรทูล → อินทรชิตโกรธแต่กลับภาวนาจนพิธีสำเร็จ → สั่งแปลงกาย → แปลงเป็นพระอินทร์
ผู้ประพันธ์: ร.2 · แหล่ง: https://vajirayana.org/บทลคร-เรื่อง-รามเกียรติ์/เล่ม-๑
*ข้อสังเกต: ร.2 บทที่ ๑๒๐๓ จบว่า "ว่าพลางทางขับเสียทันใด / แล้วกลับนั่งตั้งใจภาวนา" (พิธีสำเร็จ) ขณะที่ตับแก้เป็น "ว่าพลางทางทรงศรชัย / คลาไคลออกจากโรงพิธี" (จึงเป็นฉาก "เสียพิธี")*

> ครั้นถึงโรงพิธีมีเฉลียง / ค่อยมองเมียงดูพระโอรสา  
> เห็นนั่งนิ่งรงับหลับไนยนา / จึ่งเข้ามากราบก้มบังคมคัล  
> แล้วว่าพระบิดาให้ข้าบาท / มาแจ้งราชการทัพขับขัน  
> แสงอาทิตย์ฤทธิรอนมังกรกรรฐ์ / ไปโรมรันอัปราปัจจามิตร  
> เสียสิ้นมารถคชสาร / ทั้งขุนมารแม่ทัพก็ดับจิตร  
> ขอให้พระองค์ทรงฤทธิ์ / ไปเข่นฆ่าปัจจามิตรให้มรณา  
> *(บทที่ ๑๒๐๒ · ฯ ๖ คำ ฯ)*

> ได้ยินบอกออกความอัปรา / โกรธาลืมเนตรเห็นเสนี  
> ลุกขึ้นกระทืบบาทหวาดไหว / เหม่ไอ้กาลสูรยักษี  
> มาพูดให้เปนลางกลางพิธี / ชีวิตรมึงถึงที่จะบรรไลย  
> นี่หากคิดนิดเดียวด้วยรับสั่ง / จะหยุดยั้งยกโทษโปรดให้  
> ว่าพลางทางขับเสียทันใด / แล้วกลับนั่งตั้งใจภาวนา  
> *(บทที่ ๑๒๐๓ · ฯ ๖ คำ ฯ ตระ)*

**[ปี่พาทย์ทำเพลงตระ]**

> เดชะพระเวทอสุรินทร์ / พื้นแผ่นดินดังลั่นสนั่นป่า  
> ทั้งฟ้าแลบแวววับจับตา / อสุราชื่นชมสมคิด  
> จึ่งจับสัตวตัดศีศะใส่ถาด / ให้พรหมมาศสูบกินสิ้นโลหิต  
> ครั้นเสร็จสรรพจับศรอันเรืองฤทธิ์ / สำราญจิตรออกจากโรงพิธี

> จึ่งตรัสสั่งรุทการชาญกำแหง / จะเปลี่ยนแปลงกายกูเปนโกสีย์

> อันโยธาทั้งหลายจงกลายเพศ / เปนเทเวศร์สุรางค์นางสวรรค์  
> ให้สำหรับขับรำรบำบรรพ์ / เร่งเตรียมไว้ให้ทันฤกษ์ดี  
> *(บทที่ ๑๒๐๕ · ฯ ๔ คำ ฯ เจรจา)*

> มาเร่งรัดจัดหมู่อสุรี / ให้นิมิตรอินทรีย์ด้วยฤทธา  
> *(บทที่ ๑๒๐๖ · ฯ ๒ คำ ฯ)*

**ร้องยานี** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> สามสิบสามเศียรโสภา / เศียรหนึ่งเจ็ดงาตระหง่านงอน  
> พวกแตรสังข์กังสดาลดุริยางค์ / เปนเทเวศร์สุรางค์นางอับศร  
> บ้างแปลงเปนนักสิทธิ์ฤทธิรอน / วิชาธรแห่น่าคชาธาร  
> อันโลทันนั้นนิฤมิตรกาย / เปนควาญท้ายสำหรับขับคชสาร

## ง. บทพากย์ทางเลือก — "พากย์พรหมาสตร์" (กาพย์ฉบัง ๑๖) พระราชนิพนธ์ ร.2
อินทรชิตนิรมิตกายเป็นพระอินทร์ สรง ทรงเครื่อง (ชมเครื่องทรงทีละชิ้น) แล้วเสด็จมาทรงไอยรา · แหล่ง: https://vajirayana.org/ประชุมคำพากย์รามเกียรติ์-เล่ม-๑/ประชุมคำพากย์รามเกียรติ์-ภาค-๑/พากย์พรหมาสตร์

**พากย์**
> เมื่อนั้นอินทรชิตฤทธิไกร / ฟังเสนาใน / ก็โสมนัสเปรมปรีดิ์  
> จึ่งนิรมิตบิดเบือนอินทรีย์ / เหมือนองค์โกษีย์ / เปนเจ้าพิภพสรวงสวรรค์  
> ทรงโฉมเฉลิมโลกลาวัณย์ / งามพักตร์ผิวพรรณ / ดังมรกตเขียวขจี  
> เสด็จเข้าที่สรงวารี / สำอางอินทรีย์ / แล้วทรงสุคนธ์ปนทอง  
> สอดสนับเพลางามเรืองรอง / ภูษาพื้นตอง / กรวยเชิงเปนช่อพรรณราย  
> สอดทรงพาหุรัดเฉิดฉาย / ผ้าทิพย์จีบชาย / เครือแครงสะบัดบรรจง  
> ทองกรพาหุรัดธำมรงค์ / เพชรพลอยแต่ละวง / ควรค่าพิภพเมืองมาร  
> ตาบประดับทับทรวงสังวาล / สร้อยสะอิ้งโอฬาร / ล้วนมรกตรจนา  
> กรรเจียกจรห้อยมาลา / แล้วทรงชฎา / กาบแล้วกระจังรังราย  
> ดังอินทร์จากฟากฟ้าผันผาย / สะพักศรกรกราย / เสด็จมาทรงไอยรา ฯ  

*ฯ เจรจา ทรงช้าง ฯ* → **เจรจา**

# 02 — ฉากที่ 2 "พลับพลาพระราม"

> **รูปแบบ:** " / " = แบ่งวรรค · 1 บรรทัด = 1 บาท (กลอน) หรือ 1 บท (กาพย์) · `**[ปี่พาทย์ทำเพลง …]**` = เพลงหน้าพาทย์/บรรเลง · `**ร้อง…**` = เพลงร้อง · ข้อความในวงเล็บเหลี่ยม [ ] และตัวเอียงเป็นหมายเหตุของผู้เรียบเรียง ไม่ใช่ตัวบท

**ฉบับที่มีฉากนี้:** โขนพระราชทาน 2558
> [ยังไม่พบบทต้นฉบับของฉบับแสดงจริง — ต้องตรวจสอบ: สูจิบัตร 2558; บทโขนกรมศิลปากร ชุดศึกมังกรกัณฐ์]

ด้านล่างคือตัวบทต้นฉบับ ร.2 (กลอนบทละคร) และบทพากย์ที่เกี่ยวข้อง

## ก. พระรามเสด็จออกพลับพลา ได้ยินเสียงโห่ ถามพิเภก → สั่งสุครีพจัดทัพ → สองกษัตริย์สรง–ทรงเครื่อง → ยกทัพ
ผู้ประพันธ์: ร.2 · แหล่ง: https://vajirayana.org/บทลคร-เรื่อง-รามเกียรติ์/เล่ม-๑

**ร้องช้า** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> เมื่อนั้น / พระตรีภพลบโลกนาถา  
> เสด็จนั่งน่าสุวรรณพลับพลา / เสนาน้อมประนตบทมาลย์  
> ทั้งขีดขินชมภูหมู่วานร / ฤทธิรอนร้ายกาจอาจหาญ  
> พระทรงฤทธิ์คิดดำริห์ตริการ / จะรอนราญอาธรรม์ให้บรรไลย  
> พอได้ยินสำเนียงเสียงโห่ / ก้องโกลาลั่นหวั่นไหว  
> จึ่งถามพิเภกพลันทันใด / วันนี้ใครยกมาราวี  
> *(บทที่ ๑๑๑๗ · ฯ ๖ คำ ฯ)*

**ร้องร่าย** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> บัดนั้น / พิเภกประนตบทศรี  
> พิเคราะห์ดูรู้ความตามคัมภีร์ / จึ่งทูลพระจักรีสี่กร  
> อันตัวนายโยธานั้นกล้าหาญ / ชื่อมังกรกรรฐ์มารชาญสมร  
> อยู่บุรีโรมคัลพระนคร / บุตราพระยาขรซึ่งบรรไลย  
> *(บทที่ ๑๑๑๘ · ฯ ๔ คำ ฯ)*

> เมื่อนั้น / พระอวตารผ่านภพสบไสมย  
> ได้ฟังทูลแถลงแจ้งพระไทย / ภูวไนยนิ่งนึกตรึกตรา  
> จำจะไปป้องกันประจัญบาน / จะได้ผลาญอสุรศักดิยักษา  
> จึ่งสั่งน้องพาลีมีศักดา / จงตระเตรียมโยธาอย่าช้าที  
> *(บทที่ ๑๑๑๙ · ฯ ๔ คำ ฯ)*

> บัดนั้น / สุครีพรับสั่งใส่เกษี  
> ถวายบังคมคัลอัญชลี / ออกมาจัดโยธีทันใด  
> *(บทที่ ๑๑๒๐ · ฯ ๒ คำ ฯ ประถม)*

**[ปี่พาทย์ทำเพลงประถม]**

**ร้องยานี** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> เกณฑ์กระบวนน่าหลังคั่งคับ / พร้อมพรั่งตามตำหรับทัพใหญ่  
> ครบจำนวนถ้วนสิบสมุทไทย / เคยต่อตีมีไชยมาทุกคราว  
> ลางลิงตัวดีขี่เลียงผา / ตะพายย่ามลว้าถือหลาว  
> บ้างใส่เสื้อกำมหยี่ขี่เสือดาว / ถือง้าวเงื้อง่าท่าทีฟัน  
> บ้างนุ่งผ้าตาโถงโจงกระเบน / ขี่กระบือถือเขนขบขัน  
> บ้างขี่กระทิงถือปืนยืนยัน / คาดเครื่องคงกระพันกันสาตรา  
> บ้างขี่หมีมีกำลังไวว่อง / ถือกระบองสี่ศอกออกน่า  
> แล้วเทียมราชรถแก้วแววฟ้า / ประทับท่าคอยเสด็จจรลี  
> *(บทที่ ๑๑๒๑ · ฯ ๘ คำ ฯ เจรจา)*

**เจรจา** *(ต้นฉบับกำกับให้เจรจา — ไม่มีตัวบทเจรจาในต้นฉบับ)*

**ร้องร่าย** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> เมื่อนั้น / พระหริวงษ์องค์นารายน์เรืองศรี  
> จึ่งชวนพระอนุชาธิบดี / จรลีไปสรงคงคา  
> *(บทที่ ๑๑๒๒ · ฯ ๒ คำ ฯ เสมอ)*

**[ปี่พาทย์ทำเพลงเสมอ]**

**ร้องโทน** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> สองกระษัตริย์ชำระสระสนาน / สุคนธารประทิ่นกลิ่นบุบผา  
> สอดสนับเพลาทรงอลงการ์ / ภูษายกอย่างต่างกัน  
> ห้อยน่าผ้าทิพย์ทองรยับ / ชายแครงแสงสลับสีสัน  
> ฉลององค์ทรงประภาศตาดสุวรรณ / คาดปั้นเหน่งกุดั่นดุนลอย  
> กรองสอสังเวียนวิเชียรช่วง / ทับทรวงประดับเนื่องเฟื่องห้อย  
> ทองกรจำหลักเปนรักร้อย / ธำมรงค์เพ็ชรพลอยพรายตา  
> ต่างทรงมงกุฎกรรเจียกแก้ว / วาวแวววาบวับจับเวหา  
> ครั้นเสร็จสรรพจับพระแสงสาตรา / เสด็จมาเกยสุวรรณทันใด  
> *(บทที่ ๑๑๒๓ · ฯ ๘ คำ ฯ เสมอ)*

**[ปี่พาทย์ทำเพลงเสมอ]**

**ร้องร่าย** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> พรั่งพร้อมพหลพลนิกร / วานรกราบก้มบังคมไหว้  
> ขยายยกโยธาคลาไคล / แห่แหนแน่นในเนินบรรพต  
> *(บทที่ ๑๑๒๔ · ฯ ๒ คำ ฯ กราวนอก)*

**[ปี่พาทย์ทำเพลงกราวนอก]**

**ร้องโทน** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> รถเอยรถทรง / กำกงล้วนแล้วแก้วมรกฎ  
> บุษบกกระหนกเกรินท้ายรถ / งอนชดเฉิดฉายปลายปักธง  
> ชั้นลดช่อตั้งกระจังทอง / บันบัวตัวลำยองหางหงษ์  
> เทียมอัศวราชอาจอง / เคยณรงค์เริงร่านทยานมา  
> เครื่องสูงอภิรุมชุมสาย / เรียบริ้วเรียงรายซ้ายขวา  
> สังข์แตรแซ่สนั่นอรัญวา / โยธาฮึกโห่เปนโกลี  
> สำเนียงเสียงพวกพลากร / สัตว์สิงวิ่งซอนซอกหนี  
> ต่างต่างสำแดงแผลงฤทธี / เร่งร้นพลกระบี่บทจร  
> *(บทที่ ๑๑๒๕ · ฯ ๘ คำ ฯ เชิด)*

**[ปี่พาทย์ทำเพลงเชิด]**

**ร้องร่าย** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> ครั้นถึงเห็นทัพคับคั่ง / รายตั้งตามเทินเนินศิงขร  
> จึ่งให้หยุดโยธาพลากร / วานรนายทัพกำชับกำชา  
> *(บทที่ ๑๑๒๖ · ฯ ๒ คำ ฯ)*

## ข. บทพากย์ทางเลือก — "พากย์ศึกมังกรกัณฐ์" ช่วงแรก (กาพย์ฉบัง ๑๖; บทพากย์หนังใหญ่ ไม่ปรากฏนามผู้แต่ง)
ครอบคลุม: พระรามออกพลับพลา → ได้ยินเสียงมังกรกัณฐ์ → ถามพิเภก → **พากย์รถพระราม** ("เสด็จทรงรถทรงอินทรา") → ถึงสนามรบ
แหล่ง: https://vajirayana.org/ประชุมคำพากย์รามเกียรติ์-เล่ม-๑/ประชุมคำพากย์รามเกียรติ์-ภาค-๑/พากย์ศึกมังกรกัณฐ์

**พากย์**
> ครั้นรุ่งแสงสุริยโอภา / พุ่งพ้นเวหา / คิรียอดยุคันธร  
> สมเด็จพระหริวงศ์ทรงศร / ฤทธิเลื่องฦๅขจร / สะท้อนทั้งไตรโลกา  
> เสด็จออกนั่งหน้าพลับพลา / พร้อมด้วยเสนา / ศิโรตมก้มกราบกราน  
> พิเภกสุครีพหนุมาน / นอบน้อมทูลสาร / สดับคดีโดยถวิล  
> ยังมิทันพระหน่อนฤบดินทร์ / ตรัสตอบกระบินทร์ / ได้ยินสำเนียงเกรียงไกร  
> ปัฐพีนีรนาทหวาดไหว / ดังพลับพลาไชย / จะพลิกจะคว่ำทำลาย  
> เพียงอสนีบาตฟาดสาย / สมเด็จพระนารายณ์ / จึ่งถามพิเภกทันใด ฯ  

*ฯ เจรจา ฯ* → **เจรจา**

> เสด็จทรงรถทรงอินทรา / ทรงงามโสภา / ทรงนั่งบนบัลลังก์ทรง  
> งามกระหนกนกคาบเครือระหง / งามดุมงามวง / งามรูปมังกรงอนงาม  
> สีแก้วแววสีวับวาม / สีพลอยเพชรพลาม / สีมรกตสดสี  
> พรายแพรวแก้ววิเชียรโมลี / พรายพรายรัศมี / พรายศรีสุวรรณพรายตา  
> เทียมรถเทียมด้วยอาชา / เทียมลมพัดพา / ฝีเท้าไม่มีเทียมทัน  
> สารถีสามารถผาดผัน / อาสาทรงธรรม์ / ขับรถด้วยใจหรรษา  
> เครื่องสูงเครื่องทรงโสภา / เครื่องแห่ไสวมา / เครื่องยุทธสำหรับชิงชัย  
> ธงทิวปลิวปลายธงไสว / ธงนำพลไกร / ธงสีสลับธงทอง  
> เสียงพลเสียงพาชีคะนอง / เสียงฆ้องเสียงกลอง / เสียงสังข์แลแตรแซ่เสียง  
> ก้องกงรถก้องกรางเกรียง / ก้องสนั่นสำเนียง / กึกก้องทุกห้องหิมวา  
> สิงสัตว์สิงโตตามคณา / นรสิงห์สิงหรา / ก็หนีเข้าสู่สิงขร  
> บดฟ้าบดแสงทินกร / พลกระบิลบทจร / ผงคลีชอุ่มบดบัง  
> พ่างเพียงปัฐพีลั่นดัง / สัตภัณฑ์เพียงพัง / พิภพเพียงทำลาย  
> เร่งรถเร่งพลผันผาย / เร่งรัดไพร่นาย / วานรให้เร่งรีบมา ฯ  

*ฯ เจรจา หยุดทัพรบ ฯ* → **เจรจา**

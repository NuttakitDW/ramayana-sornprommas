# 01 — ฉากที่ 1 "ขัดตาทัพ" (ท้องพระโรงกรุงโรมคัล)

> **รูปแบบ:** " / " = แบ่งวรรค · 1 บรรทัด = 1 บาท (กลอน) หรือ 1 บท (กาพย์) · `**[ปี่พาทย์ทำเพลง …]**` = เพลงหน้าพาทย์/บรรเลง · `**ร้อง…**` = เพลงร้อง · ข้อความในวงเล็บเหลี่ยม [ ] และตัวเอียงเป็นหมายเหตุของผู้เรียบเรียง ไม่ใช่ตัวบท

**ฉบับที่มีฉากนี้:** โขนพระราชทาน 2558 เท่านั้น (ฉบับ 2550/2552 และบทคอนเสิร์ตเริ่มที่ท้องพระโรงลงกา)
**ตัวบทที่ใช้จริงในปี 2558:** "บทโขนของกรมศิลปากร ชุดศึกมังกรกัณฐ์" ผสมบท ร.2 (ตาม AJPU และแนวหน้า 2558)

> [ยังไม่พบบทต้นฉบับของฉบับแสดงจริง — ต้องตรวจสอบ: สูจิบัตร "โขน ชุด ศึกอินทรชิต ตอน พรหมาศ" 2558 (มูลนิธิส่งเสริมศิลปาชีพฯ / www.khonperformance.com), บทโขนกรมศิลปากร ชุดศึกมังกรกัณฐ์ (สำนักการสังคีต)]

ด้านล่างคือ **ตัวบทต้นฉบับ ร.2** ของเหตุการณ์เดียวกัน พร้อมคำกำกับเพลงเดิมในต้นฉบับ (ฯ … คำ ฯ …) ใช้เป็นฐานสำหรับเกม — ไม่ใช่การยืนยันว่าร้องครบทุกบทในการแสดงจริง

## ก. (ท้องพระโรงลงกา — อาจถูกตัดในฉบับ 2558 [ต้องตรวจสอบ]) ทศกัณฐ์ส่งคนธรรพ์ไปเชิญมังกรกัณฐ์
ฉันทลักษณ์: กลอนบทละคร · ผู้ประพันธ์: ร.2 (สาธารณสมบัติ) · แหล่ง: https://vajirayana.org/บทลคร-เรื่อง-รามเกียรติ์/เล่ม-๑

> เมื่อนั้น / ท้าวราพนาสูรยักษา  
> เสด็จออกท้องพระโรงรจนา / พร้อมอำมาตย์มาตยามนตรี  
> ปฤกษาซึ่งจะให้ไปขัดทัพ / ตั้งรับรบมนุษย์กระบี่ศรี  
> กว่าองค์อินทรชิตฤทธี / จะชุบศรพระศุลีได้สมคิด  
> ครั้นจะงดอยู่ท่าช้านัก / รามลักษณ์จักชล่าชเลยจิตร  
> เห็นแต่มังกรกรรฐ์นั้นมีฤทธิ์ / พอจะคิดต่อสู้หมู่ไพรี  
> คนธรรพ์จงไปบอกนัดดา / ว่าศึกติดลงกากรุงศรี  
> ให้ยกพหลหลโยธี / มาช่วยรบราวีอย่านอนใจ  
> *(บทที่ ๑๐๙๙ · ฯ ๘ คำ ฯ)*

> บัดนั้น / คนธรรพ์รับสั่งบังคมไหว้  
> คลานคล้อยถอยจากพระโรงไชย / รีบไปโรมคัลบุรี  
> *(บทที่ ๑๑๐๐ · ฯ ๒ คำ ฯ กราว)*

**[ปี่พาทย์ทำเพลงกราว]**

## ข. ท้องพระโรงกรุงโรมคัล — มังกรกัณฐ์รับอาสา จัดทัพ แต่งองค์ ยกทัพ
ฉันทลักษณ์: กลอนบทละคร · แหล่ง: https://vajirayana.org/บทลคร-เรื่อง-รามเกียรติ์/เล่ม-๑

> ครั้นถึงพอเวลาห้าโมง / เสด็จออกท้องพระโรงเรืองศรี  
> จึ่งเข้าไปเฝ้าพลันทันที / อัญชลีแล้วหมอบนอบนบ  
> *(บทที่ ๑๑๐๑ · ฯ ๒ คำ ฯ)*

**ร้องช้า** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> เมื่อนั้น / มังกรกรรฐ์ห้าวหาญชำนาญจบ  
> เสด็จออกข้างน่าปรารภ / ปฤกษาความตามขนบประเพณี  
> ลักช้างคโมยควายผู้ร้ายซัต / รับเปนสัตย์แล้วส่งไปตามที่  
> จำนวนเลขเก่าใหม่ให้สัสดี / เอาบาญชีจำหน่ายจ่ายจับการ  
> พอเหลือบเห็นข้าเฝ้าเจ้าลงกา / อสุรามีราชบรรหาร  
> องค์พระบิตุลาพระยามาร / ใช้เองมาว่าขานประการใด  
> อันพระจอมอสุรินทร์ปิ่นกระษัตริย์ / ยังไพบูลย์ภูลสวัสดิผ่องใส  
> ฤๅมีความทุกข์โศกโรคไภย / จงบอกไปให้แจ้งกิจจา  
> *(บทที่ ๑๑๐๒ · ฯ ๘ คำ ฯ)*

**ร้องร่าย** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> บัดนั้น / คนธรรพ์บังคมก้มเกษา  
> อันทุกข์โศกโรคไภยไม่บีฑา / แต่ลงกาเกิดการจลาจล  
> ด้วยรามลักษณ์พี่น้องสองศรี / ที่เปนชีชาวป่าพนาสณฑ์  
> ควบคุมกระบี่รี้พล / จองถนนข้ามฝั่งตั้งติดพัน  
> ไพรีมีฤทธิ์ด้วยแสงศร / ทั้งโยธาวานรก็แขงขัน  
> พวกเราล้มตายวายชีวัน / โรมรันรับมนุษย์เห็นสุดใจ  
> บัดนี้พระผู้ดำรงลงกา / ให้ข้ามาทูลแจ้งแถลงไข  
> เชิญเสด็จไปด้วยช่วยชิงไชย / จงทราบใต้บาทบงสุ์พระทรงฤทธิ์  
> *(บทที่ ๑๑๐๓ · ฯ ๘ คำ ฯ)*

> เมื่อนั้น / มังกรกรรฐ์ฟังแถลงแจ้งจิตร  
> รู้ว่ารามาปัจจามิตร / ยิ่งคิดแค้นคั่งแต่หลังมา  
> มนุษย์นี้ที่ฆ่าพระบิตุเรศ / ทรงเดชสิ้นชีวังสังขาร์  
> จะไปเฝ้าทรงฤทธิ์บิตุลา / ออกอาสาฆ่าเสียให้บรรไลย  
> คิดพลางทางสั่งเสนี / จงตระเตรียมโยธีทัพใหญ่  
> กูจะยกพหลพลไกร / ไปชิงไชยช่วยณรงค์ในลงกา  
> *(บทที่ ๑๑๐๔ · ฯ ๖ คำ ฯ)*

> บัดนั้น / เสนีรับสั่งใส่เกษา  
> ก้มเกล้าดุษดีชลีลา / ออกมาจัดโยธาพลากร  
> *(บทที่ ๑๑๐๕ · ฯ ๒ คำ ฯ ประถม)*

**[ปี่พาทย์ทำเพลงประถม]**

**ร้องยานี** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> เกณฑ์ไพร่พลรบครบจำนวน / เลือกล้วนห้าวหาญชาญสมร  
> กองน่าอสุรีมีฤทธิรอน / ขี่มังกรถือปืนพื้นใบโพ  
> กองหลวงขี่กิเลนเกณฑ์ตามตำแหน่ง / ขัดดาบตะพายแล่งถือโล่ห์  
> ทัพหลังโยธีขี่สิงโต / บ้างขี่โคถึกเถลิงเริงแรง  
> สารวัดเที่ยวตรวจทุกหมวดหมาย / พรั่งพร้อมไพร่นายตามตำแหน่ง  
> บ้างเทียมรถรีบรัดจัดแจง / มาอยู่น่าพลับพลาแดงดาษดา  
> *(บทที่ ๑๑๐๖ · ฯ ๖ คำ ฯ เจรจา)*

**เจรจา** *(ต้นฉบับกำกับให้เจรจา — ไม่มีตัวบทเจรจาในต้นฉบับ)*

**ร้องร่าย** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> เมื่อนั้น / มังกรกรรฐ์สิทธิศักดิยักษา  
> เสด็จจากแท่นแก้วแววฟ้า / ลีลามาสรงคงคาไลย  
> *(บทที่ ๑๑๐๗ · ฯ ๒ คำ ฯ เสมอ)*

**[ปี่พาทย์ทำเพลงเสมอ]**

**ร้องโทน** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> พนักงานไขสุหร่ายดังสายฝน / ต้องสกนธ์ซ่านเซนเย็นใส  
> ทรงสุคนธรศเร้าเอาใจ / สอดใส่สนับเพลาเพราพราย  
> ภูษายกทองท้องพัน / กรวยเชิงสามชั้นเฉิดฉาย  
> ฉลององค์ทรงเกราะกระสันกาย / ปั้นเหน่งลายลงยาราชาวดี  
> ทับทรวงดวงดอกลอยพลอยรยับ / ตาบประดับมรกฎสดศรี  
> สังวาลค่าเมืองเรืองรูจี / ทองกรแก้วมณีเนาวรัตน์  
> สอดทรงธำมรงค์เรือนครุธ / มงกุฎเพ็ชรประดับสำหรับกระษัตริย์  
> กรรเจียกจรเจียรไนดอกไม้ทัด / จับธนูคู่หัดถ์บทจร  
> *(บทที่ ๑๑๐๘ · ฯ ๘ คำ ฯ เสมอ)*

**[ปี่พาทย์ทำเพลงเสมอ]**

**ร้องร่าย** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> สั่งให้เลิกพยู่ห์หมู่จัตุรงค์ / ขนัดธงทวนทิวปลิวสลอน  
> ออกนอกโรมคัลพระนคร / พลนิกรโห่ฉาวกราวเกรียว  
> *(บทที่ ๑๑๐๙ · ฯ ๒ คำ ฯ กราวใน)*

**[ปี่พาทย์ทำเพลงกราวใน]**

**ร้องโทน** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> รถเอยรถทรง / แอกอ่อนงอนรหงธงเขียว  
> บุษบกบรรจงทรงพริ้งเพรียว / กระหนกกระหนาบกาบเกี้ยวแกมทอง  
> อสุราสารถีโลทัน / ขับมังกรสองพันเผ่นผยอง  
> เซงแซ่แตรสังข์ฆ้องกลอง / ลั่นพิฦกกึกก้องท้องสุธา  
> แห่แหนแน่นขนัดจัตุรงค์ / ทิวธงทวนสล้างมากลางป่า  
> โพยมพยับอับแสงสุริยา / เมฆามืดมนท์อนธการ  
> เนื้อเบื้อโคกระทิงสิงคนัด / วิ่งพลัดตกห้วยเหวลหาน  
> เร่งรีบพหลพลมาร / ล่วงด่านแดนนิเวศน์เขตรลงกา  
> *(บทที่ ๑๑๑๐ · ฯ ๘ คำ ฯ เชิด)*

## ค. (ท้องพระโรงลงกา — อาจถูกตัด [ต้องตรวจสอบ]) มังกรกัณฐ์เฝ้าทศกัณฐ์ รับคำสั่งขัดตาทัพ แล้วตั้งทัพ
แหล่ง: https://vajirayana.org/บทลคร-เรื่อง-รามเกียรติ์/เล่ม-๑

**ร้องร่าย** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> ครั้นถึงจึ่งหยุดจัตุรงค์ / เสด็จลงจากราชรัถา  
> พอเสด็จออกพระโรงรจนา / ก็เข้ามานอบนบอภิวันท์  
> *(บทที่ ๑๑๑๑ · ฯ ๒ คำ ฯ เสมอ)*

**[ปี่พาทย์ทำเพลงเสมอ]**

> เมื่อนั้น / ทศเศียรสุริวงษ์รังสรรค์  
> สถิตย์เหนือแท่นแก้วแพรวพรรณ / เห็นมังกรกรรฐ์ก็ดีใจ  
> จึ่งตรัสเรียกขึ้นนั่งร่วมอาศน์ / พลางประภาศโอภาปราไส  
> แถลงเล่าเหตุผลแต่ต้นไป / ซึ่งเกิดไพรีประชิดติดภารา  
> คือลักษณ์รามที่ฆ่าบิดาเจ้า / คุมเหล่าลิงค่างต่างภาษา  
> มารบรุกบุกบันบีฑา / เคี่ยวฆ่ากุมภกรรฐ์บรรไลย  
> อินทรชิตไชยชาญออกหาญหัก / คราวนี้พระลักษณ์ก็ตักไษย  
> ให้เลิกทัพกลับเข้าเวียงไชย / มันรื้อเปนขึ้นได้ไม่ม้วยมรณ์  
> เดี๋ยวนี้องค์อินทรชิตเชษฐา / ไปตั้งกิจวิทยาชุบศร  
> เจ้าจงคุมพหลพลนิกร / ออกราญรอนรับรองป้องกันไว้  
> *(บทที่ ๑๑๑๒ · ฯ ๑๐ คำ ฯ)*

> เมื่อนั้น / มังกรกรรฐ์บังคมก้มกราบไหว้  
> แล้วทูลว่าซึ่งดำรัสตรัสใช้ / จะให้ไปตั้งทัพรับมนุษย์  
> พอสมจิตรคิดหวังครั้งนี้ / ความหลานยินดีเปนที่สุด  
> องค์พระบิดาข้าม้วยมุด / เพราะมนุษย์รบรุกบุกบัน  
> ยังไม่วายหายแค้นขัดใจ / จะออกไปเข่นฆ่าให้อาสัญ  
> เกิดในสุริวงษ์พงษ์กุมภัณฑ์ / ไม่ขยั้นย่อท้อต่อไพริน  
> อันไอ้พวกวานรสัญจรป่า / พลอยมาลบหลู่ดูหมิ่น  
> จะให้แต่พลยักษ์หักฅอกิน / จนสุดสิ้นพวกพ้องของมัน  
> *(บทที่ ๑๑๑๓ · ฯ ๘ คำ ฯ)*

> เมื่อนั้น / ทศเศียรปรีดิ์เปรมเกษมสันต์  
> ลูบหน้าลูบหลังมังกรกรรฐ์ / เออนั่นเปนไรไม่เสียที  
> น้อยฤๅห้าวหาญการณรงค์ / สมศักดิสุริวงษ์ยักษี  
> แต่จะออกชิงไชยกับไพรี / ไม่ได้ทีอย่ากระโจมเข้าโรมรัน  
> จงคอยท่าอินทรชิตฤทธิรอน / ตรวจตราพลากรไว้ให้มั่น  
> เห็นได้ทีมีไชยชนะมัน / จึ่งโรมรุกบุกบันชิงไชย  
> *(บทที่ ๑๑๑๔ · ฯ ๖ คำ ฯ)*

> เมื่อนั้น / มังกรกรรฐ์ยินดีจะมีไหน  
> ถวายอัญชลีลาคลาไคล / สั่งให้เดินทัพฉับพลัน  
> *(บทที่ ๑๑๑๕ · ฯ ๒ คำ ฯ เชิด)*

### พากย์กระบวนทัพมังกรกัณฐ์ (กาพย์ฉบัง ๑๖) — ใช้ได้กับช่วงมังกรกัณฐ์ยกทัพจากโรมคัลมาลงกา
แหล่ง: https://vajirayana.org/ประชุมคำพากย์รามเกียรติ์-เล่ม-๑/ประชุมคำพากย์รามเกียรติ์-ภาค-๑/พากย์กระบวนทัพมังกรกัณฐ์

**พากย์**
*[กาพย์ฉบัง ๑๖]*

> พรั่งพร้อมจัตุรงค์โยธา / เสด็จทรงมหา / พิไชยรถเรืองฉัน  
> เทียมด้วยมังกรสองพัน / ชักรถเหียนหัน / ลั่นเลื่อนสะเทือนกำกง  
> พระที่นั่งบัลลังก์ลอยระหง / งอนงามปักธง / สามชายสะบัดกวัดไกว  
> สารถีขี่ขับรถไชย / แกว่งง้าววาวไว / เงื้อง่าเปนท่าทีแทง  
> กลิ้งกลดบดบังสุริยแสง / พัดโบกใบแพลง / ระยับระย้าจามร  
> เสียงกลองฆ้องขานแตรงอน / เสียงพวกพลจร / โห่ลั่นสนั่นหิมวา  
> ต่างต่างแผลงฤทธิศักดา / กรกุมศัสตรา / จะลุยจะไล่ไพรื  
> ลางมารนิรมิตอินทรีย์ / เศียรเปนอสุรี / แลกายเปนกากภาษา  
> บ้างขี่คชสีห์สิงหรา / เงื้อหอกกลอกตา / จะพุ่งจะผลาญราญรอน  
> บ้างขี่โตกิเลนมังกร / ถือกำซาบศร / จะน้าวธนูหน่วงแผลง  
> ขบฟันเข่นเขี้ยวเรี่ยวแรง / หมู่มารสำแดง / เดชานุภาพพึงกลัว  
> อากาศมืดชอุ่มคลุ้มมัว / นกหกต่างตัว / ต่างตื่นตระหนกตกใจ  
> ปัฐพีนีรนาทหวาดไหว / เพียงหนึ่งเมรุไกร / จะอ่อนจะเอียงไปมา  
> สรวงสวรรค์ลั่นเลื่อนโกลา / ทุกเทพเทวา / ก็หนีไปนอกจักรวาฬ  
> รีบรถจัตุรงค์ทวยหาญ / เร่งพวกพลมาร / มาถึงนครลงกา ฯ  

*ฯ เจรจา ถึงลงกาขึ้นเฝ้า ฯ* → **เจรจา**

> บัดนั้นทศเศียรสุริยวงศ์ / เสด็จสำราญองค์ / เหนืออาสน์อันผ่องไพบูลย์  
> เสนามาตยาเมือบมูล / ท้าวราพณาสูร / ก็ตรัสปรึกษาสงคราม  
> บัดนี้พวกลิงลักษณ์ราม / หยิ่งยศยกนาม / ทะนงกำเริบราวี  
> ครั้นกูจะออกต่อตี / ดุจดังสำลี / ละเอียดบทันพริบตา  
> เกลียดอายฤๅสิทธ์วิทยา / จึงเชิญนัดดา / มาเด็ดซึ่งเศียรศัตรู  
> มันเหมือนจอกจมสินธู / โดยลุงคิดดู / ผู้เดียวสะดวกง่ายดาย ฯ  

*ฯ เจรจา ฯ* → **เจรจา**

### พากย์กระบวนมังกรกัณฐ์ ยกไปขัดตาทัพ (กาพย์ฉบัง ๑๖)
แหล่ง: https://vajirayana.org/ประชุมคำพากย์รามเกียรติ์-เล่ม-๑/ประชุมคำพากย์รามเกียรติ์-ภาค-๑/พากย์กระบวนมังกรกัณฐ์-ยกไปขัดตาทัพ

**พากย์**
> เสด็จทรงรถแก้วแพรวพราย / ดังดวงสุริย์ฉาย / บมีมลทินแผ้วพาน  
> สารถีขับมังกรเผ่นทะยาน / กงก้องจักรวาฬ / ก็เร็วดังวายุพัดพา  
> มยุรฉัตรพัดโบกไปมา / บังแสงสุริยา / ธงไชยไสวโบกบน  
> ฆ้องกลองพิณพาทย์กาหล / สะเทือนท้องภูวดล / แตรสังข์ประดังขานกัน  
> เสนาโยธาแน่นนันต์ / หน้าหลังเรียงรัน / ทั้งซ้ายแลขวาโจษจน  
> เสียงรถคชสารอึงอล / เสียงม้าเสียงพล / โห่เลื่อนสะเทือนธรณี  
> อากาศมืดชอุ่มผงคลี / กลุ้มฟ้าธาตรี / ชอุ่มชอ่ำอัมพร  
> เร่งรถคชสารอัสดร / เร่งพวกพลจร / ก็ถึงสมรภูมิไชย ฯ  

*ฯ เจรจา ฯ* → **เจรจา**

# 04 — ฉากที่ 4 "ข่าวศึก" (ท้องพระโรงกรุงลงกา)

> **รูปแบบ:** " / " = แบ่งวรรค · 1 บรรทัด = 1 บาท (กลอน) หรือ 1 บท (กาพย์) · `**[ปี่พาทย์ทำเพลง …]**` = เพลงหน้าพาทย์/บรรเลง · `**ร้อง…**` = เพลงร้อง · ข้อความในวงเล็บเหลี่ยม [ ] และตัวเอียงเป็นหมายเหตุของผู้เรียบเรียง ไม่ใช่ตัวบท

**ฉบับที่มีฉากนี้:** ทุกฉบับของโขนพระราชทาน (2550 [ต้องตรวจสอบ], 2552 = ฉากเปิดเรื่อง, 2558 = ฉากที่ 4) และบทคอนเสิร์ตตับพรหมาสตร์ (เป็นฉากแรกของตับ)
**ตัวละคร:** ทศกัณฐ์ (ประทับซุ้มเรือนแก้ว), สารัณทูต, กาลสูร, เสนามาตย์
**ยืนยันจากสูจิบัตร 2552 (ผ่านบล็อกผู้ชม):** พากย์ (เมือง) 3 บทแรก + เจรจาเต็ม → กาลสูรเหาะด้วยสลิง — https://www.bloggang.com/m/viewdiary.php?id=bookkii&month=06-2009&date=23&group=12&gblog=67

## ตัวบทการแสดง (ตับพรหมาสตร์)
แหล่ง: ตับพรหมาสตร์ (บทคอนเสิร์ต, สมเด็จฯ กรมพระยานริศรานุวัดติวงศ์ — สาธารณสมบัติ) ตามฉบับราชบัณฑิตยสถาน (2550ข: 115–119) อ้างใน คฑาวุธ พรหมลิ (2567) น. 158 · https://art.tsu.ac.th/upload/menu/doc_20250326_160524.pdf

**[ปี่พาทย์ทำเพลงวา — โหมโรง]** *(ดูไฟล์ 00)*

**พากย์ (พากย์เมือง / พากย์พลับพลา)** — กาพย์ฉบัง ๑๖
> เมื่อนั้นทศพักตร์ยักษี / ออกมุขมนตรี / แลตรัสประภาษราชการ  
> สารันต์ทูตทูลบมินาน / สมเด็จพระเจ้าหลาน / ไปรณรงค์รามา  
> เสียรถเสียทศโยธา / เสียเทพศาตรา / พระองค์ก็เสียชีวัน  
> ฟังข่าวผ่าวเพียงเพลิงกัลป์ / เจ็บใจจาบัลย์ / แล้วนิ่งคะนึงในใจ  

*[สูจิบัตร 2552 ตามบล็อก: พิมพ์ "เสียเทพศาสตรา" และบันทึกเพียง 3 บทแรก (ถึง "พระองค์ก็เสียชีวัน") — ประเภทพากย์ "พากย์ (เมือง)" ระบุโดยบล็อก https://www.bloggang.com/m/viewdiary.php?id=bookkii&month=06-2009&date=23&group=12&gblog=67]*

**เจรจา** — ร่าย (เจรจาแบบกระทู้/เดินทำนอง)
> ไทท้าวเจ้าอสุรี / มีพระราชบัญชา / สั่งเสนากาลสูร ให้ไปทูลอินทรชิต  
> ว่าแสงอาทิตย์สิ้นชีวัน / มังกรกัณฐ์เสียชีวาตม์ ศึกองอาจฮึกฮัก จะหนักมาพระนคร  
> เร่งชุบศรพรหมาสตร์ / ยกไปพิฆาตไพรี / อย่าช้าทีชิงชัย / รีบไปบอกลูกรัก กูบัดนี้  

*[สูจิบัตร 2552 ตามบล็อก ใช้ "เร่งชุบศรพรหมาศ" — นอกนั้นตรงกัน]*

**ร้องเพลงกราวใน** — กลอนบทละคร
> บัดนั้น / กาลสูรเสนีมีศักดิ์  
> รับสั่งบังคมทศพักตร์ / ขุนยักษ์รีบเหาะระเห็จไป  

**[ปี่พาทย์ทำเพลงเชิด]** *(กาลสูรเหาะไปโรงพิธี — 2552 ใช้สลิงยกตัวนักแสดง; ทำนองหลักใน TSU มีทั้งเชิดสองชั้นและชั้นเดียว)*

## ตัวบทต้นฉบับ ร.2 เทียบ (เหตุการณ์เดียวกัน)
ผู้ประพันธ์: ร.2 · กลอนบทละคร · แหล่ง: https://vajirayana.org/บทลคร-เรื่อง-รามเกียรติ์/เล่ม-๑
*ข้อสังเกต: บทกราวในของตับดัดแปลงจากบทที่ ๑๒๐๑ ของ ร.2 ("กาลสูรเสนีมีศักดิ / รับสั่งบังคมทศภักตร์ / แล้วขุนยักษ์รีบเหาะรเห็จมา")*

> บัดนั้น / ทั้งสองสารัณทูตยักษี  
> เห็นกุมภัณฑ์พ่ายแพ้แก่ไพรี / ก็นำข่าวคดีไปลงกา  
> *(บทที่ ๑๑๙๘ · ฯ ๒ คำ ฯ กราว)*

**[ปี่พาทย์ทำเพลงกราว]**

> ครั้นถึงจึ่งเข้าไปกราบทูล / ท้าวราพนาสูรยักษา  
> แสงอาทิตย์เสียทัพอัปรา / สิ้นชีวาอาสัญบรรไลย  
> *(บทที่ ๑๑๙๙ · ฯ ๒ คำ ฯ)*

> เมื่อนั้น / ทศเศียรสท้อนถอนใจใหญ่  
> ชิชะมนุษย์นี้สุดใจ / ทำไฉนจึงจะล้างมันวางวาย  
> จะใช้ใครไปรบก็แพ้ฤทธิ์ / เห็นจะคิดองอาจประมาทหมาย  
> ยิ่งกลุ่มกลัดขัดใจไม่สบาย / แสนเสียดายนัดดายาใจ  
> จำจะให้อินทรชิตฤทธิรุตม์ / ไปสังหารผลาญมนุษย์เสียให้ได้  
> ดำริห์พลางทางสั่งเสนาใน / จงรีบตามออกไปโรงพิธี  
> บอกองค์อินทรชิตฤทธิรอน / ให้เร่งชุบแสงศรเรืองศรี  
> แล้วยกไปสังหารผลาญไพรี / อย่าช้าทีข้าศึกจะฮึกฮัก  
> *(บทที่ ๑๒๐๐ · ฯ ๘ คำ ฯ)*

> บัดนั้น / กาลสูรเสนีมีศักดิ  
> รับสั่งบังคมทศภักตร์ / แล้วขุนยักษ์รีบเหาะรเห็จมา  
> *(บทที่ ๑๒๐๑ · ฯ ๒ คำ ฯ เชิด)*

**[ปี่พาทย์ทำเพลงเชิด]**

## บทพากย์ที่เกี่ยวข้อง — "พากย์ทศกัณฐ์ บอกข่าวมังกรกัณฐ์ล้ม" (กาพย์ฉบัง ๑๖; บทพากย์หนังใหญ่ ไม่ปรากฏนามผู้แต่ง)
ไม่ยืนยันว่าใช้ในฉบับใด แต่คำกำกับท้ายบท "เจรจา อินทรชิตเสียพิธี" ตรงกับชื่อฉากที่ 5 ของปี 2558 · แหล่ง: https://vajirayana.org/ประชุมคำพากย์รามเกียรติ์-เล่ม-๑/ประชุมคำพากย์รามเกียรติ์-ภาค-๑/พากย์ทศกัณฐ์-บอกข่าวมังกรกัณฐ์ล้ม

**พากย์**
> ครั้นรุ่งจำรัสฟ้าธาตรี / แซ่เสียงสกุณี / สนั่นพิภพเมืองมาร  
> ดุริยางค์ย่ำรุ่งแข่งขาน / เสียงสังข์กังวาน / วิเวกจังหวัดเวียงวัง  
> สนั่นพิณพาทย์ฆ้องประโคมดัง / เสนาะในบัลลังก์ / ประโลมพระทัยพันทวี  
> เรื่อยเรื่อยจำเรียงเสียงศรี / จึงจอมอสุรี / รำพึงด้วยภพลงกา  
> โอ้แสนเสียดายวงศา / ล้วนทรงศักดา / สำแดงจะปล้นปลอมสวรรค์  
> สามโลกฦๅสะดุ้งแดยัน / ใครห่อนมาขัน / เคี่ยวเขี้ยวณรงค์ราญรอน  
> ครั้งนี้ลักษณ์รามพานร / แข่งข้ามสาคร / มาขันพิฆาฏคุมภัย  
> ศักดาจริงยิ่งฤทธิแดนไตร / เปรียบฤทธิภูวไนย / นารายณ์ฤๅแปลงปลอมมา  
> คิดฉันใดดีนะอกอา / จักล้างชีวา / ให้แหลกทั้งทัพพานรินทร์  
> สุดคิดคั่งแค้นแสนถวิล / รุ่มร้อนกายิน / จนอัสสุชลคลอคลอง  
> ตรึกไตรไม่ลุโดยปอง / เสด็จสู่โรงทอง / ให้ชุมพระญาติโยธี ฯ  

*ฯ เจรจา อินทรชิตเสียพิธี สั่งเสนาไปจักรวาฬ ฯ* → **เจรจา**

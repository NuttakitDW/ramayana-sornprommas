# 06 — ฉากที่ 6 (ช่วงแรก) "ศรพรหมาศ"

> **รูปแบบ:** " / " = แบ่งวรรค · 1 บรรทัด = 1 บาท (กลอน) หรือ 1 บท (กาพย์) · `**[ปี่พาทย์ทำเพลง …]**` = เพลงหน้าพาทย์/บรรเลง · `**ร้อง…**` = เพลงร้อง · ข้อความในวงเล็บเหลี่ยม [ ] และตัวเอียงเป็นหมายเหตุของผู้เรียบเรียง ไม่ใช่ตัวบท

**ฉบับที่มีฉากนี้:** ทุกฉบับ (2552 = องก์หลัง หลังพักครึ่ง; 2558 = ฉากที่ 6 ในองก์ที่ 2)
**ฉาก:** สนามรบ–ท้องฟ้า; ช้างเอราวัณ (2558: ประติมากรรมกลไกสูง > 3.5 ม. 3 เศียรขยับได้)
**ตัวละคร:** อินทรชิตแปลง (พระอินทร์), การุณราช (เอราวัณ), โลทัน (เทพบุตรควาญ), เทวดา–นางฟ้าแปลง, นักสิทธิ์; พระลักษมณ์, หนุมาน, สุครีพ, องคต, พลวานร
**ลำดับที่ยืนยัน 2552 (https://www.bloggang.com/m/viewdiary.php?id=bookkii&month=06-2009&date=23&group=12&gblog=68):** วงเครื่องประโคม–เครื่องสูงเข้าประจำ → ร้องทะแยกลองโยน → พากย์ชมโฉม (พากย์เอราวัณ เต็มบท) → ทัพพระลักษมณ์เคลื่อนพลออก → ร้องกระบอก → ระบำ → (บทกล่อม) → ร้อง "เชิดร่าย" [= ร่ายรุด] → ร้องลิงโลด → รบ คอช้างหัก → ร้องกราวรำพม่า

## ตัวบทการแสดง
แหล่งหลัก: ตับพรหมาสตร์ (บทคอนเสิร์ต, สมเด็จฯ กรมพระยานริศรานุวัดติวงศ์ — สาธารณสมบัติ) ตามฉบับราชบัณฑิตยสถาน (2550ข: 115–119) อ้างใน คฑาวุธ พรหมลิ (2567) น. 159–161 · https://art.tsu.ac.th/upload/menu/doc_20250326_160524.pdf

**ร้องกราวนอก** — กลอนบทละคร *(ตับจัดเป็นเพลงหน้าพาทย์ประเภทร้อง)*
> ขึ้นทรงคอคชาเอราวัณ / ทหารแห่โห่สนั่นหวั่นไหว  
> ขยายยกโยธาคลาไคล / ลอยฟ้ามาในโพยมมาน  

**ร้องเพลงทะแยกลองโยน** — กลอน (วรรคสั้นราว 6–7 พยางค์ ตามทำนองทะแย) · ยืนยันในสูจิบัตร 2552 ("บทชมกระบวนทัพ -ร้องทะแยกลองโยน-")
> ช้างเอยช้างนิมิตร / เหมือนไม่ผิดช้างมัฆวาน  
> เริงแรงกำแหงหาญ / ชาญศึกสู้รู้ท่วงที  
> ผูกเครื่องเรืองทองทอ / กระวิลทองหล่อทอแสงศรี  
> ห้อยหูพู่จามรี / ปกตระพองทองพรรณราย  
> เครื่องสูงเรียงสามแถว / ลายกาบแก้วแสงแพรวพราย  
> อภิรุมสับชุมสาย / บังแทรกอยู่เป็นคู่เคียง  
> กลองชนะประโคมคึก / มโหระทึกกึกก้องเสียง  
> แตรสังข์ส่งสำเนียง / นางจำเรียงเคียงช้างทรง  
> สาวสุรางค์นางรำฟ้อน / ดังกินนรแน่งนวลระหง  
> นักสิทธิฤทธิรงค์ / ถือทวนธงลิ่วลอยมา  

*[ต้นฉบับ PDF พิมพ์ "แ" เป็น "เเ" (สระเอสองตัว) — ปรับเป็น "แ" เพื่อให้ค้นหาได้ ไม่เปลี่ยนคำ]*

**พากย์ (พากย์ชมโฉม / พากย์บรรยาย) — "พากย์เอราวัณ"** — กาพย์ฉบัง ๑๖ · พระราชนิพนธ์ ร.2 · ยืนยันว่าใช้ในปี 2552 ("ขอแปะบทพากย์ชมโฉมแบบเต็มๆ") — ตำแหน่งตามบล็อกคือหลังทะแยกลองโยน **[ต้องตรวจสอบ]**
แหล่งตัวบท: https://vajirayana.org/ประชุมคำพากย์รามเกียรติ์-เล่ม-๑/ประชุมคำพากย์รามเกียรติ์-ภาค-๑/พากย์เอราวัณ

> อินทรชิตบิดเบือนกายิน / เหมือนองค์อมรินทร์ / ทรงคชเอราวัณ  
> ช้างนิรมิตฤทธิแรงแข็งขัน / เผือกผ่องผิวพรรณ / สีสังข์สะอาดโอฬาร์  
> สามสิบสามเศียรโสภา / เศียรหนึ่งเจ็ดงา / ดังเพชรรัตน์รูจี  
> งาหนึ่งเจ็ดโบกขรณี / สระหนึ่งย่อมมี / เจ็ดกออุบลบันดาล  
> กอหนึ่งเจ็ดดอกดวงมาลย์ / ดอกหนึ่งแบ่งบาน / มีกลีบได้เจ็ดกลีบผกา  
> กลีบหนึ่งมีเทพธิดา / เจ็ดองค์โสภา / แน่งน้อยลำเพานงพาล  
> นางหนึ่งย่อมมีบริวาร / อีกเจ็ดเยาวมาลย์ / ล้วนรูปนิรมิตมารยา  
> จับระบำรำร่ายส่ายหา / ชำเลืองหางตา / ทำทีดังเทพอัปสร  
> มีวิมานแก้วงามบวร / ทุกเกศกุญชร / ดังเวไชยันต์อมรินทร์  
> เครื่องประดับเก้าแก้วโกมิน / ซองหางกระวิน / สร้อยสายชนักถักทอง  
> ตาข่ายเพชรรัตน์ร้อยกรอง / ผ้าทิพย์ปกตระพอง / ห้อยพู่ทุกหูคชสาร  
> โลทันสารถีขุนมาร / เปนเทพบุตรควาญ / ขับท้ายที่นั่งช้างทรง  
> บรรดาโยธาจัตุรงค์ / เปลี่ยนแปลงกายคง / เปนเทพไทเทวัญ  
> ทัพหน้าอารักษ์ไพรสัณฑ์ / ทัพหลังสุบรรณ / กินรนาคนาคา  
> ปีกซ้ายฤๅสิทธ์วิทยา / คนธรรพ์ปีกขวา / ตั้งตามตำรับทัพไชย  
> ล้วนถืออาวุธเกรียงไกร / โตมรศรไชย / พระขรรค์คทาถ้วนตน  
> ลอยฟ้ามาในเวหน / รีบเร่งรี้พล / มาถึงสมรภูมิไชย ฯ  

*ฯ เจรจา ฯ* → **เจรจา**

*[สูจิบัตร 2552 (ตามบล็อก https://www.bloggang.com/m/viewdiary.php?id=bookkii&month=06-2009&date=23&group=12&gblog=68) ใช้อักขรวิธีปัจจุบัน และมีคำต่าง: "ทัพหน้าอารักขไพรสัณฑ์", "กินนรนาคนาคา", "ปีกซ้ายฤาษิตวิทยา" (วชิรญาณ: "ฤๅสิทธ์วิทยา"), "ตั้งตามตำรับทัพชัย", "โตมรศรชัย", "มาถึงสมรภูมิชัย"; ตำราเรียนบางฉบับพิมพ์ "ช้างนิมิต"]*

**[ปี่พาทย์ทำเพลงเชิด]** *(TSU พิมพ์ "ปี่พาทย์ทเพลงเชิด"; 2552: ทัพพระลักษมณ์เคลื่อนพลออกสนามรบ)*

**ร้องเพลงกระบอก** — กลอนบทละคร (ยืนยันในสูจิบัตร 2552)
> ครั้นถึงที่ประจัญบานราญรอน / เห็นวานรนับแสนแน่นหนา  
> กับทั้งองค์พระลักษมณ์ศักดา / ยืนรถรัตนาอยู่กลางพล  
> จึงหยุดช้างทรงองอาจ / ลอยเลื่อนเกลื่อนกลาดกลางเวหน  
> ให้กุมภัณฑ์บรรดาลจำแลงตน / ใส่กลขับรำระบำบรรพ์  

*[บล็อก 2552: "ลอยเลื่อนเกลื่อนกลาดกลาวเวหน", "ให้กุมภัณฑ์บรรดาจำแลงตน"]*

**ร้องเพลงแขกอาหวัง** (ชั้นเดียว) — กลอนบทละคร
> บัดนั้น / รูปนิมิตฤทธิแรงแข็งขัน  
> สาวสุรางค์นางฟ้าเทวัญ / บังคมคัลคำนับรับบัญชา  

**[ปี่พาทย์ทำเพลงสร้อยสน — รำออก "ระบำพรหมาสตร์" / ระบำหน้าช้าง]** (แหล่งนาฏศิลป์: https://nin18.blogspot.com/2019/02/blog-post_27.html)

**ร้องเพลงสร้อยสน** — กลอนบทละคร (บทระบำพรหมาสตร์ 4 คำกลอน)
> ต่างจับระบำรำฟ้อน / ทอดกรกรีดกรายซ้ายขวา  
> ร่ายเรียงเคียงคมประสมตา / เลี้ยวไล่ไขว่คว้าเป็นท่าทาง  
> ซ้อนจังหวะประเท้าเข้าคล่อง / เลี้ยงลอดสอดคล้องไปตามหว่าง  
> วงเวียนเหียนหันกั้นกาง / เป็นคู่คู่อยู่กลางอัมพร  

*[ฉบับระบำพรหมาสตร์ (https://nin18.blogspot.com/2019/02/blog-post_27.html) และ ร.2 ใช้ "ประเท้าเคล่าคล่อง" และ "เลี้ยวลอด" — ร.2 มีบาทเพิ่มอีก 2 บาท (ดูตัวบท ร.2 ด้านล่าง บทที่ ๑๒๑๔)]*

**[ปี่พาทย์ทำเพลงเร็ว – ลา — รำเข้า]** *(TSU ให้ทำนอง "สองไม้แขกมัดตีนหมู – เร็วแขกมัดตีนหมู – ลา"; แหล่งนาฏศิลป์ให้ "ต้นบรเทศ – แขกบรเทศ" [ต้องตรวจสอบ])*

**ร้องเพลงกล่อม** (แนวช้ามาก) — กาพย์ยานี ๑๑ · บาทที่ 3–4 ยืนยันในสูจิบัตร 2552 (บล็อกยกมา: "หมายว่าสุรินทร สุรอัปสรเธอหรรษา พระเพลินเจริญตา ทั้งพลสวาวานรไพร")
> เมื่อนั้นพระลักษมณ์ / ผู้ทรงศักดิ์แลทรงศร  
> ทั้งพวกพลากร / ดูรำฟ้อนบนเมฆา  
> หมายว่าสุรินทร / สุรอัปสรเธอหรรษา  
> พระเพลินเจริญตา / ทั้งพลสวาวานรไพร  

**[ปี่พาทย์ทำเพลงพัดชา]**

**ร้องเพลงกระบอกทอง** — กลอนบทละคร
> เมื่อนั้น / อินทรชิตยินดีจะมีไหน  
> เห็นข้าศึกเสียเชิงระเริงใจ / จึงจับศรชัยขึ้นบูชา  

**ร้องเพลง(เห่)เชิดฉิ่ง** — กลอนบทละคร
> พาดสายหมายเขม้นเข่นเขี้ยว / น้าวเหนี่ยวด้วยกำลังอังสา  
> สังเกตตรงองค์พระลักษมณ์อนุชา / อสุราก็ลั่นไปทันใด  

**[ปี่พาทย์ทำเพลงเชิดกลอง]** *(แผลงศร)*

**ร้องร่ายรุด** — กลอนบทละคร (ยืนยันในสูจิบัตร 2552 — บล็อกจดชื่อว่า "ร้องเชิดร่าย")
> ลูกศรกระจายดังสายฝน / ตกถูกลิงพลไม่ทนได้  
> แล้วต้องพระอนุชาเสนาใน / สลบไปไม่เป็นสมประดี  

**[ปี่พาทย์ทำเพลงโอด]** *(ทำนองหลักใน TSU มีเพลงโอดคั่นก่อนลิงโลด; ร.2 กำกับ "โอด" ที่บทเดียวกัน)*

**ร้องเพลงลิงโลด** — กลอนบทละคร (ยืนยันในสูจิบัตร 2552)
> บัดนั้น / หนุมานไม่ต้องศรศรี  
> ยืนทะยานดาลโกรธดังอัคคี / ชี้หน้าว่าเหวยสหัสนัยน์  
> เหตุใดไปเข้าข้างพวกยักษ์ / มาแผลงผลาญพระลักษมณ์ให้ตักษัย  
> กูจะล้างชีวันให้บรรลัย / ให้สาใจอินทราที่อาธรรม์  
> ว่าพลางเผ่นโผนโจนทะยาน / ขึ้นตีควาญท้ายคชาอาสัญ  
> ง้างหักคอพญาเอราวัณ / ชิงคันศรศักดิ์มัฆวาน  

*[2552: หนุมานเหาะด้วยสลิง ตีลังกา 2 ตลบ เหยียบงาช้างเอราวัณรบกับพระอินทร์แปลง]*

**ร้องเพลงลิงลาน** — กลอนบทละคร
> เมื่อนั้น / อินทรชิตฤทธิไกรใจหาญ  
> ไม่หลีกหลบขบฟันประจัญบาน / รอนราญผัดผันทันท่วงที  
> หันเหียนเปลี่ยนท่าง่าศรจ้อง / ตีต้องหนุมานชาญชัยศรี  
> ตกกระเด็นไปกับเศียรกรี / สลบพับอยู่กับที่ยุทธนา  

**[ปี่พาทย์ทำเพลงโอดแหบ]** *(2552: คอช้างหักลงมาจริง ปล่อยไอน้ำแข็งแห้ง ฉากฟ้ายกขึ้น ตัวช้างลดระดับ พระอินทร์แปลงลอยด้วยสลิง)*

**ร้องกราวรำพม่า** — กลอนบทละคร (ยืนยันในสูจิบัตร 2552)
> ดีใจไพรีพินาศสิ้น / อสุรินสรวลสันต์หรรษา  
> ทั้งโยธีสมคะเนเฮฮา / คืนเข้าลงกาธานี  

**[ปี่พาทย์ทำเพลงเชิด]** *(ทำนองหลักใน TSU ปิดตับด้วยเชิดสองชั้น–ชั้นเดียว; บทคอนเสิร์ตจบที่นี่)*

## บทพากย์ทางเลือก — ต่อจากพากย์เอราวัณ (กาพย์ฉบัง ๑๖, พระราชนิพนธ์ ร.2 ตามที่วชิรญาณจัดไว้ใต้ "พากย์เอราวัณ")
ครอบคลุม: รุ่งเช้าพระลักษมณ์ตื่นบรรทม → **พากย์รถพระลักษมณ์** ("เสด็จทรงรถแก้วโกษีย์") → พระลักษมณ์ถามสุครีพเหตุใดพระอินทร์มา สุครีพเตือนอย่าไว้ใจ → อินทรชิตสั่งให้จับระบำ → แผลงศรพรหมาสตร์ พระลักษมณ์กลิ้งกลางพล → "เจรจา อินทรชิตกลับทัพ" — ไม่ยืนยันว่าใช้ในโขนพระราชทาน (อาจเหมาะกับคิว "ทัพพระลักษมณ์ออก") · แหล่ง: https://vajirayana.org/ประชุมคำพากย์รามเกียรติ์-เล่ม-๑/ประชุมคำพากย์รามเกียรติ์-ภาค-๑/พากย์เอราวัณ

**พากย์**
> เมื่อนั้นจึงพระจักรี / พอพระสุริย์ศรี / อรุณเรืองเมฆา  
> ลมหวนอวลกลิ่นมาลา / เฟื่องฟุ้งวนา / นิวาสแถวแนวดง  
> ผึ้งภู่หมู่คณาเหมหงส์ / ร่อนราถาลง / แทรกไซ้ในสร้อยสุมาลี  
> ดุเหว่าเร้าเร่งพระสุริย์ศรี / ไก่ขันปีกตี / กู่ก้องในท้องดงดาน  
> ปักษาตื่นตาขันขาน / หาคู่เคียงประสาน / สำเนียงเสนาะในไพร  
> เดือนดาวดับเศร้าแสงใส / สร่างแสงอโณทัย / ก็ผ่านพยับรองเรือง  
> จับฟ้าอากาศแลเหลือง / ธิบดินทร์เธอบรรเทือง / บรรทมฟื้นจากไสยา ฯ  

*ฯ เจรจา ฯ* → **เจรจา**

> เสด็จทรงรถแก้วโกษีย์ / ไพโรจน์รูจี / จะแข่งซึ่งแสงสุริย์ใส  
> เทียมสินธพอาชาไนย / เริงร้องถวายไชย / ชันหูระเหิดหฤหรรษ์  
> มาตลีสารถีเทวัญ / กรกุมพระขรรค์ / ขับรถมากลางจัตุรงค์  
> เพลารอยพลอยประดับดุมวง / กึกก้องกำกง / กระทบกระทั่งธรณี  
> มยุรฉัตรชุมสายพรายศรี / พัดโบกพัชนี / กระบี่ระบายโบกลม  
> อึงอินทเภรีตีระงม / แตรสังข์เสียงประสม / ประสานเสนาะในไพร  
> เสียงพลโห่ร้องเอาไชย / เลื่อนลั่นสนั่นใน / พิภพเพียงทำลาย  
> สัตภัณฑ์บรรพตทั้งหลาย / อ่อนเอียงเพียงปลาย / ประนอมประนมชมไชย  
> พสุธาอากาศหวาดไหว / เนื้อนกตกใจ / ซุกซ่อนประหวั่นขวัญหนี  
> ลูกครุฑพลัดตกฉิมพลี / หัสดินอินทรี / คาบช้างก็วางไอยรา  
> วานรสำแดงเดชา / หักถอนพฤกษา / ถือต่างอาวุธยุทธยง  
> ไม้ไหล้ยูงยางกลางดง / แหลกหลู้ล้มลง / ละเอียดด้วยฤทธิโยธี  
> อากาศบดบังสุริย์ศรี / เทวัญจันทรี / ทุกชั้นอำนวยอวยไชย  
> บ้างเปิดแกลแก้วแววไว / โปรยทิพย์มาลัย / ซ้องสาธุการบูชา  
> ชักรถรี่เรื่อยเฉื่อยมา / พุ่มบุษป์มาลา / กงรถไม่จดธรณิน  
> เร่งพลโยธาพานรินทร์ / เร่งรัดหัสดิน / วานรให้เร่งรีบมา ฯ  

*ฯ เจรจา หยุดทัพ ฯ* → **เจรจา**

> เมื่อนั้นพระศรีอนุชา / เอื้อนอรรถวัจนา / ตรัสถามสุครีพขุนพล  
> เหตุไฉนสหัสนัยน์เสด็จดล / สมรภูมิไพรสณฑ์ / เธอมาด้วยกลอันใด  
> สุครีพทูลทัดเฉลยไข / ทุกทีสหัสนัยน์ / เสด็จด้วยหมู่เทวา  
> อวยไชยถวายทิพย์มาลา / บัดนี้เธอมา / เห็นวิปริตดูฉงน  
> ทรงเครื่องศัสตราแย่งยล / ฤๅจะกลับเปนกล / ไปเข้าด้วยราพณ์อาธรรม์  
> พระผู้เรืองฤทธิแข็งขัน / คอยดูสำคัญ / อย่าไว้พระทัยไพรี ฯ  
> เมื่อนั้นอินทรชิตยักษี / ตรัสสั่งเสนี / ให้จับระบำรำถวาย  
> ให้องค์อนุชานารายณ์ / เคลิบเคลิ้มวรกาย / จะแผลงซึ่งศัสตรศรพล ฯ  

*ฯ เจรจา ฯ* → **เจรจา**

> อินทรชิตสถิตเหนือเอรา / วัณทอดทัศนา / เห็นองค์พระลักษณ์ฤทธิรงค์  
> เคลิบเคลิ้มหฤทัยใหลหลง / จึงจับศรทรง / พรหมาสตร์อันเรืองเดชา  
> ทูนเหนือเศียรเกล้ายักษา / หมายองค์พระอนุชา / ก็แผลงสำแดงฤทธิรณ  
> อากาศก้องโกลาหล / โลกลั่นอึงอล / อำนาจสะท้านธรณี  
> ศรเต็มไปทั่วราศี / ต้ององค์อินทรีย์ / พระลักษณ์ก็กลิ้งกลางพล ฯ  

*ฯ เจรจา อินทรชิตกลับทัพ ฯ* → **เจรจา**

## ตัวบทต้นฉบับ ร.2 เทียบ (บทละคร เล่ม 1 บทที่ ๑๒๑๐–๑๒๒๔)
แหล่ง: https://vajirayana.org/บทลคร-เรื่อง-รามเกียรติ์/เล่ม-๑ · *ข้อสังเกต: ตับของกรมพระยานริศฯ ย่อ–แก้จากบทเหล่านี้ เช่น บท "โทน" ช้างเอยช้างนิมิตร (๑๒๑๑) ถูกแต่งใหม่เป็นทะแยกลองโยน; "ศรเปนประกายไปหลายลูก" (๑๒๑๗) → "ลูกศรกระจายดังสายฝน"; บท ๑๒๑๘–๑๒๑๙ ถูกรวมเป็นลิงโลด; ร.2 ให้ร้อง "พระทอง" สำหรับระบำ (ตับใช้สร้อยสน)*

> ขึ้นทรงฅอคชาเอราวรรณ / ทหารแห่โห่สนั่นหวั่นไหว  
> ขยายยกโยธาคลาไคล / ลอยฟ้ามาในโพยมมาล  
> *(บทที่ ๑๒๑๐ · ฯ ๒ คำ ฯ กลองโยน)*

**[ปี่พาทย์ทำเพลงกลองโยน]**

**ร้องโทน** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> ช้างเอยช้างนิมิตร / เรืองฤทธิ์เรี่ยวแรงกำแหงหาญ  
> ประดับเครื่องเรืองรัตน์ชัชวาลย์ / ล้วนแล้วแก้วประพาฬพรรณราย  
> ห้อยหูภู่จามรีรอง / ปกตระพองรัดงาตาข่าย  
> เครื่องสูงสามแถวแพรวพราย / อภิรุมชุมสายเปนคู่เคียง  
> กลองชนะประโคมโครมครึก / มโหรธึกสังข์แตรแซ่เสียง  
> พิณพาทย์ดุริยางค์นางจำเรียง / ประคองเคียงสองข้างช้างทรง  
> สาวสุรางค์นางรบำรำฟ้อน / ดังกินรแน่งน้อยนวลหง  
> สุรารักษ์นักสิทธิ์ฤทธิรงค์ / ถือทวนธงเปนทิวลิ่วลอยมา  
> *(บทที่ ๑๒๑๑ · ฯ ๘ คำ ฯ เชิด)*

**[ปี่พาทย์ทำเพลงเชิด]**

**ร้องร่าย** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> ครั้นถึงที่ประจัญบานราญรอน / เห็นวานรนับแสนแน่นหนา  
> กับทั้งองค์พระลักษณ์ศักดา / ยืนรถรัตนาอยู่กลางพล  
> จึ่งยั้งหยุดช้างทรงองอาจ / ลอยเลื่อนเกลื่อนกลาดเวหน  
> ให้กุมภัณฑ์บรรดาจำแลงตน / ใส่กลขับรำรบำบรรพ์  
> *(บทที่ ๑๒๑๒ · ฯ ๔ คำ ฯ)*

> บัดนั้น / รูปนิมิตรฤทธิแรงแขงขัน  
> สาวสุรางค์นางฟ้าเทวัญ / บังคมคัลคำนับรับบัญชา  
> *(บทที่ ๑๒๑๓ · ฯ ๒ คำ ฯ)*

**ร้องพระทอง** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> ต่างจับรบำรำฟ้อน / ทอดกรกรีดกรายซ้ายขวา  
> ร่ายเรียงเคียงคมประสมตา / เลี้ยวไล่ไขว่คว้าเปนแยบคาย  
> แล้วทวนทบตระหลบหลีกเลี่ยง / เคล้าคลอรอเรียงเมียงม่าย  
> หันเหียนเปลี่ยนแทรกมาข้างซ้าย / แล้วย้ายมาขวาทำท่าทาง  
> ซ้อนจังหวะประเท้าเคล่าคล่อง / เลี้ยวลอดสอดคล้องไปตามหว่าง  
> วงเวียนเหียนหันกั้นกาง / เปนคู่คู่อยู่กลางอัมพร  
> *(บทที่ ๑๒๑๔ · ฯ ๖ คำ ฯ เพลง)*

**[ปี่พาทย์ทำเพลงเพลง]**

**ร้องร่าย** *(คำกำกับทางร้องในต้นฉบับ ร.๒)*

> เมื่อนั้น / พระลักษณ์สุริวงษ์ทรงศร  
> ทั้งพวกพลโยธาวานร / ดูรบำรำฟ้อนบนเมฆา  
> สำคัญว่าโกสีย์ตรีเนตร / กับเทเวศร์นางสวรรค์หรรษา  
> พระพินิจพิศเพลินจำเริญตา / ทั้งพวกพลสวาวานรไพร  
> *(บทที่ ๑๒๑๕ · ฯ ๔ คำ ฯ)*

> เมื่อนั้น / อินทรชิตยินดีจะมีไหน  
> เห็นข้าศึกเสียเชิงละเลิงใจ / จึ่งจับศรไชยขึ้นบูชา  
> แล้วพาดสายหมายเขม้นเข่นเขี้ยว / น้าวเหนี่ยวด้วยกำลังตึงอังษา  
> สังเกตตรงองค์พระลักษณ์อนุชา / อสุราก็ลั่นไปทันใด  
> *(บทที่ ๑๒๑๖ · ฯ ๔ คำ ฯ เชิดฉิ่ง)*

**[ปี่พาทย์ทำเพลงเชิดฉิ่ง]**

> ศรเปนประกายไปหลายลูก / ตกถูกลิงพลไม่ทนได้  
> แล้วต้องพระอนุชาเสนาใน / สลบไปไม่เปนสมประดี  
> *(บทที่ ๑๒๑๗ · ฯ ๒ คำ ฯ โอด)*

**[ปี่พาทย์ทำเพลงโอด]**

> แลเขม้นเห็นแต่หณุมาน / ยืนทยานอยู่ตรงภักตร์ยักษี  
> สรวลพลางตบหัดถ์อสุรี / ทั้งโยธีสมคเนเฮฮา  
> *(บทที่ ๑๒๑๘ · ฯ ๒ คำ ฯ กราวรำ)*

**[ปี่พาทย์ทำเพลงกราวรำ]**

> บัดนั้น / คำแหงหณุมานหาญกล้า  
> กระทืบบาทกราดเกรี้ยวโกรธา / แล้วชี้หน้าว่าเหวยสหัสไนย  
> เหตุใดไปเข้าข้างพวกยักษ์ / มาแผลงผลาญพระลักษณ์ตักไษย  
> กูจะล้างชีวันให้บรรไลย / จงสาใจอินทราที่อาธรรม์  
> ว่าพลางเผ่นโผนโจนทยาน / ขึ้นตีควาญท้ายคชาอาสัญ  
> ง้างหักฅอพระยาเอราวรรณ / ชิงคันศรศักดิมัฆวาน  
> *(บทที่ ๑๒๑๙ · ฯ ๖ คำ ฯ)*

> เมื่อนั้น / อินทรชิตฤทธิไกรใจหาญ  
> ไม่หลีกหลบขบฟันประจัญบาน / รอนราญรับรองว่องไว  
> หันเหียนเปลี่ยนท่าง่าเงื้อศร / ไสกุญชรติดพันกระชั้นไล่  
> ตีต้องหณุมานชาญไชย / กระเด็นไปกับเศียรไอยรา  
> *(บทที่ ๑๒๒๐ · ฯ ๔ คำ ฯ โอด)*

**[ปี่พาทย์ทำเพลงโอด]**

> เห็นวานรแน่นิ่งไม่ติงกาย / คิดว่าวายชีวังสังขาร์  
> พอจวนแสงสุริยนสนธยา / จึ่งสั่งสารัณทูตทันใด  
> แม้นพระรามตามน้องมาที่รบ / จะกอดศพร่ำรักจนตักไษย  
> เองรีบเข้าไปแถลงให้แจ้งใจ / กูจะได้มาประหารผลาญชีวา  
> แล้วสั่งให้เลิกทัพกลับพล / ต่างตนบรรเทิงเริงร่า  
> รูปกายกลายเปนอสุรา / คืนเข้าลงกาธานี  
> *(บทที่ ๑๒๒๑ · ฯ ๖ คำ ฯ เชิด)*

**[ปี่พาทย์ทำเพลงเชิด]**

> ครั้นถึงนัคเรศนิเวศน์วัง / เข้ายังพระโรงทองผ่องศรี  
> บังคมบาทบิตุรงค์ทรงฤทธี / แล้วทูลความตามที่มีไชย  
> *(บทที่ ๑๒๒๒ · ฯ ๒ คำ ฯ เจรจา)*

**เจรจา** *(ต้นฉบับกำกับให้เจรจา — ไม่มีตัวบทเจรจาในต้นฉบับ)*

> เมื่อนั้น / ทศกรรฐ์ยินดีจะมีไหน  
> ประคององค์โอรสยศไกร / กอดจูบลูกไล้แล้วชมเชย  
> ฤทธิรณกลศึกก็ฦกซึ้ง / เปนที่พึ่งพ่อแล้วลูกแก้วเอ๋ย  
> เจ้าเหนื่อยมาอย่านั่งนานนักเลย / ไปเสวยสว่ำให้สำราญ  
> *(บทที่ ๑๒๒๓ · ฯ ๔ คำ ฯ)*

> เมื่อนั้น / อินทรชิตคำนับรับบรรหาร  
> ออกจากพระโรงรัตน์ชัชวาลย์ / ไปสถานที่อยู่อสุรา  
> *(บทที่ ๑๒๒๔ · ฯ ๒ คำ ฯ พราหมณ์เข้า)*

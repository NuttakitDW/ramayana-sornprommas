# 07 — ฉากที่ 6 (ช่วงหลัง) "แก้ศรพรหมาศ" — พระรามตามมาสนามรบ ถึงพระลักษมณ์ฟื้น

> **รูปแบบ:** " / " = แบ่งวรรค · 1 บรรทัด = 1 บาท (กลอน) หรือ 1 บท (กาพย์) · `**[ปี่พาทย์ทำเพลง …]**` = เพลงหน้าพาทย์/บรรเลง · `**ร้อง…**` = เพลงร้อง · ข้อความในวงเล็บเหลี่ยม [ ] และตัวเอียงเป็นหมายเหตุของผู้เรียบเรียง ไม่ใช่ตัวบท

**ฉบับที่มีช่วงนี้:** โขนพระราชทาน 2552 และ 2558 (บทคอนเสิร์ตไม่มี — โขนพระราชทานเติมเพื่อไม่ให้จบแบบ "พระล้ม"), สายกรมศิลปากร
**ฉาก:** สนามรบยามพลบค่ำ (ไฟหรี่ เปลี่ยนฉากหลัง พระลักษมณ์นอนมีศรปักอกกลางเวที) → ภูผาอาวุธ → สนามรบ; 2558 ปิดด้วยพระจันทร์นูนต่ำส่องเขาสรรพยา
**ตัวละคร:** พระราม, พระลักษมณ์ (สลบ), หนุมาน, พิเภก, พลวานร; (ร.2: พระอินทร์, เทวดารักษาภูผา)
**ลำดับที่ยืนยัน 2552 (https://www.bloggang.com/m/viewdiary.php?id=bookkii&month=06-2009&date=23&group=12&gblog=68):** พากย์ → พากย์โอ้ → พระพายพัด หนุมานฟื้น ทูลเหตุ → พระรามตรัสถาม พิเภกทูลวิธีแก้ → หนุมานไปเอายาที่ภูเขาอาวุธ ก่อนพระอาทิตย์ขึ้น → ร้องแขกบรเทศ → จบ
**ตัดออก (2552):** สีดา–ตรีชฎานั่งบุษบกมาดูศพ (ร.2 บทที่ ๑๒๓๕–๑๒๕๑; ร.1) และบทวานรคร่ำครวญ (ร.2 ๑๒๓๒)

## ก. พระรามถึงสนามรบ — พากย์ / พากย์โอ้ "พรหมาสตร์"
ฉันทลักษณ์: กาพย์ฉบัง ๑๖ สอดรับด้วยกาพย์ยานี ๑๑ · ผู้แต่ง: บทพากย์โขนสายกรมมหรสพ–กรมศิลปากร ไม่ปรากฏนาม **[ต้องตรวจสอบผู้แต่ง/สถานะลิขสิทธิ์]**
ทำนอง: วรรคต้นพากย์เดินทำนอง; วรรคท้ายลงทำนอง "โอ้ปี่ใน" แล้วปี่พาทย์รับเพลงโอ้ปี่ใน ต่อด้วยเพลงโอด ตะโพนตีท้า กลองทัดรับ 2 ครั้ง ผู้พากย์รับ "เพ้ย"

**ฉบับตำราพากย์กรมศิลปากร** — แหล่ง: ธีรภัทร์ ทองนิ่ม และคณะ, "การพากย์และเจรจาที่ใช้ในการแสดงโขน" (ตัวอย่าง "พากย์โอ้ พรหมาสตร์") · https://so02.tci-thaijo.org/index.php/jica/article/download/18879/16650

**พากย์ (เดินทำนอง)**
> ครั้นถึงสนามราวี / แลเห็นกระบี่ / พินาศดาดพื้นพสุธา  
> ทั้งองค์พระลักษณ์อนุชา / ศรศักดิ์ปักอุรา / พระเข้าฉุดชักศรชัย  

**พากย์โอ้**
> (โอ้) ไม่เขยื้อนและเลื่อนหลุด / เกรงน้องนุชจะบรรลัย  
> กรตระกองพระน้องไว้ / ชลนัยไหลลงทรงโศกา  

**[ปี่พาทย์รับเพลงโอ้ปี่ใน – ต่อเพลงโอด]**

**ฉบับสูจิบัตร 2552** (ตามบล็อก https://www.bloggang.com/m/viewdiary.php?id=bookkii&month=06-2009&date=23&group=12&gblog=68) — คำต่าง: "เห็นพลกระบี่", "พินาศดาษพื้นพสุธา", "ไม่เขยื้อนแลเลื่อนหลุด", "ชลนัยไหลลงโศกา"
> **พากย์** ครั้นถึงสนามราวี / เห็นพลกระบี่ / พินาศดาษพื้นพสุธา  
> ทั้งองค์พระลักษณ์อนุชา / ศรศักดิ์ปักอุรา / พระเข้าฉุดชักศรชัย  
> **พากย์โอ้** ไม่เขยื้อนแลเลื่อนหลุด / เกรงน้องนุชจะบรรลัย  
> กรตระกองพระน้องไว้ / ชลนัยไหลลงโศกา

**พากย์ / พากย์โอ้** *(ต้นฉบับกำกับ "โอด" ท้ายตอนร่ำไห้)*
> เมื่อนั้นองค์พระจักรี / เสด็จออกยังศรี / สุวรรณราชพลับพลา

> หนึ่งทักขิณเนตรจักรี / เกิดลางกาลี / กระเหม่นนิมิตผิดผัน

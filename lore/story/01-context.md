# 01 — บริบท: ตอน "พรหมาศ" อยู่ตรงไหนในรามเกียรติ์ (Story Context)

> **สรุปสั้นสำหรับทีมเกม:** "พรหมาศ" (หรือ "พรหมาสตร์" ในบทละคร ร.๑) คือ **ศึกครั้งที่ ๓ ระหว่างอินทรชิตกับพระลักษมณ์** ในสงครามกรุงลงกา เกิดหลังศึกกุมภกรรณ และต่อจากศึก "นาคบาศ" โดยตรง อินทรชิตไปทำพิธีชุบศรพรหมาสตร์ที่พระอิศวรประทาน แล้ว **แปลงกายเป็นพระอินทร์ทรงช้างเอราวัณ** นำยักษ์ที่แปลงเป็นเทวดา-นางฟ้ามาร่ายรำลวงตา แผลงศรต้องพระลักษมณ์และกองทัพวานรล้มทั้งหมด หนุมานต้องไปยก **เขาอาวุธ** (ภูผาอาวุธ) ที่มีสรรพยามาแก้ภายในคืนเดียว
>
> ชื่อตอน: โขนนิยมสะกด **"พรหมาศ"** (บทละคร ร.๒ สะกด "พรหมมาศ"); บทละคร ร.๑ และคำพากย์สะกด **"พรหมาสตร์"** (จาก สันสกฤต *Brahmāstra*)

## 2. เหตุการณ์ก่อนหน้าโดยตรง: ศึกนาคบาศ (ร.๑ สรุป)

- หลังกุมภกรรณสิ้น อินทรชิตไปทำพิธีชุบศรนาคบาศ ทศกัณฐ์ส่ง **มังกรกัณฐ์** (บุตรพญาขร) ขัดตาทัพ มังกรกัณฐ์ถูกพระรามสังหาร
- **ชามพูวราช** ไปทำลายพิธีของอินทรชิต (ร.๑ บรรยายว่า "สัตว์ร้ายทำลายพิธีกรรม์"; วิกิพีเดียระบุว่าแปลงเป็นหมีใหญ่)
- อินทรชิตแผลงนาคบาศ ศรกลายเป็นนาคมัดพระลักษมณ์และวานร พิเภกทูลวิธีแก้ พระรามแผลงศรเป็นพญาครุฑมาไล่นาค ทุกคนฟื้น
- อินทรชิตแค้นว่า "เหตุเพราะพิเภกทรชน / บอกกลให้แก้ศรศรี" → เป็นแรงจูงใจตรงของตอนพรหมาศ

> **ความต่าง ร.๒:** ในบทละคร ร.๒ เหตุการณ์ **มังกรกัณฐ์** และ **แสงอาทิตย์** (สองพี่น้อง บุตรพญาขร) ถูกย้ายมาเกิด **ระหว่างพิธีชุบศรพรหมาศ** — ขณะที่ใน ร.๑ มังกรกัณฐ์ตายช่วงนาคบาศ และแสงอาทิตย์ปรากฏภายหลังอินทรชิตสิ้นแล้ว (สมุดไทยเล่มที่ ๖๒–๖๓) โขนพระราชทาน ๒๕๕๘ เดินตาม ร.๒ (มีฉาก "ขัดตาทัพ กรุงโรมคัล")

## 3. เหตุการณ์ในตอน (ย่อมาก — ดูรายละเอียดใน `02-synopsis.md`)

1. อินทรชิตขอไปชุบศรพรหมาสตร์ ๓ วัน **ห้ามส่งข่าวตายไปที่โรงพิธี**
2. ฝ่ายลงกาส่งทัพขัดตาทัพ (ร.๑ กำปั่น / ร.๒ มังกรกัณฐ์→แสงอาทิตย์) ถูกฆ่า
3. ทศกัณฐ์เผลอส่งข่าวตายไป → **เสียพิธี** → อินทรชิตพลีเลือดให้ศรสูบกินแก้ลาง
4. อินทรชิตแปลงเป็นพระอินทร์ การุณราชแปลงเป็นช้างเอราวัณ ๓๓ เศียร ยักษ์แปลงเป็นเทวดา-นางฟ้า
5. ระบำลวงตา → พระลักษมณ์และวานรเพลิน → แผลงศรพรหมาสตร์ ล้มทั้งกองทัพ
6. หนุมานหักคอเอราวัณ ถูกคันศรตีสลบ
7. พระรามตามหา พบศพ สลบเพราะโศก / (ร.๑ ร.๒) นางสีดาถูกพามาดูด้วยบุษบก
8. หนุมานฟื้น (ร.๑ พิเภกเป่ามนตร์ / ร.๒ พระอินทร์องค์จริงบันดาลฝน-ลม / โขน ลมพระพาย)
9. ยาอยู่ที่ **เขาอาวุธ** ต้องยกทั้งเขามาให้ทันก่อนรุ่ง
10. พระลักษมณ์และวานรฟื้น ลงกาได้ยินเสียงโห่ ปูไปสู่กลสุขาจาร/กุมภนิยา

## 4. หลังตอนนี้: การรักษากองทัพ และจุดจบของอินทรชิต

### 4.1 การแก้ศรพรหมาสตร์ — **ไม่ใช่ "สังกรณีตรีชวา"**
คำถามที่พบบ่อย: ตอนพรหมาศใช้ "ยาสังกรณีตรีชวา" หรือไม่? — **ตรวจแล้วไม่ใช่**
- บทละคร ร.๑ (สมุดไทยเล่มที่ ๕๕): ยาอยู่ที่ **"เขาอาวุธ / ในบุพพวิเท่ห์ทวีปใหญ่"** หนุมานยกทั้งภูเขามา ไม่มีการเอ่ยชื่อสมุนไพรเฉพาะ
- บทละคร ร.๒ (บทที่ ๑๒๕๘–๑๒๖๙): **"ภูผาอาวุธ"** ยกทั้งเขามาแล้ว "เคาะยาให้หล่น"
- คำ **"สังกรณีตรีชวา"** ปรากฏใน ร.๒ เล่ม ๑ บริเวณตอนศึกกุมภกรรณ/หอกโมกขศักดิ์ (และ ร.๑ สมุดไทยเล่มที่ ๔๘) — เป็นยาของ **ตอนโมกขศักดิ์** ไม่ใช่ตอนพรหมาศ ทีมเกมไม่ควรนำมาปนกัน
- พระรามเองรำพันถึงการแก้อาวุธ ๓ ครั้งที่ต่างกัน: โมกขศักดิ์ (หนุมานไปขอยาจากพระพรต มาบดทา), นาคบาศ (ครุฑ), พรหมาสตร์ (ครั้งนี้)

> ๏ ไฉนหนอพ่อจึ่งประมาทนัก &emsp; ให้ต้องอาวุธยักษ์ถึงสามหน  
> เมื่อครั้งโมกขศักดิ์ฤทธิรณ &emsp; ก็เจียนจักเสียชนม์ชีวัน  
> พี่ให้หนุมานผู้เรืองเดช &emsp; ไปแจ้งเหตุพระพรตรังสรรค์  
> ได้โอสถมาบดประสมกัน &emsp; ทาทันจึ่งฟื้นคืนมา  
> ครั้งเมื่อเจ้าต้องนาคบาศ &emsp; ศรสาตร์อินทรชิตยักษา  
> หากได้สุบรรณอันศักดา &emsp; มาโฉบฉาบนาคาหนีไป  
> ตัวเจ้าจึ่งรอดชีวี &emsp; ครั้งนี้ฝ่ายพี่จะทำไฉน  
> เมื่อศรสิทธิ์ของมันเกรียงไกร &emsp; ใครจะช่วยเจ้าได้นะน้องรัก  
>
> — ร.๑ บทละครเรื่องรามเกียรติ์ สมุดไทยเล่มที่ ๕๔ (vajirayana.org) [ตัดตอน]

### 4.2 ความสำคัญของพิเภก
- ใน ร.๑ พิเภก **ไม่อยู่** ในวันที่อินทรชิตแปลงมา (ไปหาผลไม้ให้วานรที่อดอยาก) — เป็นเหตุผลเชิงโครงเรื่องว่าทำไมไม่มีใครจับกลได้
- เมื่อกลับมา พิเภกทั้งชุบหนุมาน บอกความจริงเรื่องพระอินทร์ปลอม และ (ร.๒) บอกที่อยู่ยา
- ฝ่ายลงกาโทษพิเภกทุกครั้ง: อินทรชิต "ชะรอยพิเภกขุนยักษ์ / ทรลักษณ์มันบอกให้แก้กัน" (ร.๑); ทศกัณฐ์ "มันซื่อสัตย์ต่อมนุษย์สุดใจ / แก้ไขรอดตายไปหลายครั้ง" (ร.๒)

### 4.3 จุดจบของอินทรชิต (ร.๑ สมุดไทยเล่มที่ ๕๘)
พิเภกทูลว่าต้องให้ **องคต** — "ผู้ร่วมมารดาอสุรี" (องคตกับอินทรชิตเป็นพี่น้องร่วมมารดาคือนางมณโฑ) — ขึ้นไปขอ **พานแว่นฟ้า** จากพระพรหมมารับเศียร มิฉะนั้นเศียรตกดินจะเกิดไฟบรรลัยกัลป์ แล้วพระลักษมณ์จึงแผลงศรพรหมาสตร์ (ศรของพระลักษมณ์เองก็ชื่อนี้)

> ๏ สำเนียงดั่งเสียงลมกรด &emsp; ถึงชั้นโสฬสก็หวาดไหว  
> ต้องกรอินทรชิตฤทธิไกร &emsp; ซ้ายขวาขาดไปด้วยศักดา  
> แล้วศรพรหมาสตร์ไปสังหาร &emsp; ตัดเศียรขุนมารยักษา  
> กายตกยังพื้นพสุธา &emsp; ก็สุดสิ้นชีวาทันที  
> *ฯฯ ๔ คำ ฯ โอด*
>
> — ร.๑ บทละครเรื่องรามเกียรติ์ สมุดไทยเล่มที่ ๕๘ (vajirayana.org)

> ๏ บัดนั้น  
> องคตหลานท้าวโกสีย์ &emsp; เห็นเศียรอินทรชิตอสุรี  
> ขาดจากอินทรีย์กระเด็นไป &emsp; จึ่งเอาพานแว่นฟ้าพรหเมศ  
> เข้ารองรับเกศไว้ได้ &emsp; ก็พาลงมาด้วยว่องไว  
> ยังในพ่างพื้นพสุธา  
> *ฯฯ ๔ คำ ฯ เชิด*
>
> — ร.๑ บทละครเรื่องรามเกียรติ์ สมุดไทยเล่มที่ ๕๘ (vajirayana.org)

| ชื่อ | Indrajit / Meghanāda | อินทรชิต / รณพักตร์ |
| พิธีก่อนใช้พรหมาสตร์ | ทำยัชญะบูชาไฟ แล้ว "invoked the missile presided over by Brahma" (6.73) | พิธี "ชุบศร" ที่ยุคุนธร/สัตภัณฑ์ มีกำหนด ๓ วัน และมีข้อห้ามข่าวตาย |
| ผู้ประทานพรหมาสตร์ | เชื่อมโยงกับพระพรหม | **พระอิศวร** ("พระสยมภูวนาถประสาทศรพรหมาสตร์" — พระพรหมประทานนาคบาศแทน) |
| กลอุบาย | **ล่องหน** อยู่บนฟ้าพร้อมรถศึก (6.73.29) | **แปลงเป็นพระอินทร์ทรงเอราวัณ** + กองทัพเทวดานางฟ้าปลอมร่ายรำ — ไม่มีในวาลมีกิ |
| ผู้ล้ม | **พระรามและพระลักษมณ์** กับวานร ๖๗ โกฏิ (6.74.1) | ร.๑/ร.๒: **พระลักษมณ์** กับวานร ต้องศร; พระรามสลบเพราะความโศก (ไม่ได้ต้องศร) |
| ผู้รอด | หนุมานกับวิภีษณะ ถือคบไฟหาผู้รอด พบชามพวาน | หนุมานไม่ต้องศรแต่ถูกคันศรตีสลบ; พิเภกไม่อยู่ |
| ผู้บอกวิธีแก้ | **ชามพวาน** (หมี) | ร.๑ **ชมพูพาน** (วานรที่เคยรับใช้พระอิศวร ตรวจสรรพยา); ร.๒ **พิเภก** |
| ยา | ๔ ชนิดบน **เขาฤษภะ** ระหว่างเขาไกลาสกับฤษภะ ในหิมาลัย: มฤตสัญชีวนี วิศัลยกรณี สุวรรณกรณี สันธานี (6.74) | "สรรพยา" บน **เขาอาวุธ/ภูผาอาวุธ** ไม่ระบุชื่อยา |
| วิธีนำมา | หนุมานถอนทั้งภูเขามา กลิ่นยาชุบทุกคน (6.74.74) | ยกทั้งภูเขาเหมือนกัน แต่ ร.๑ ให้ลอยไว้ทิศอุดรให้ลมพากลิ่น / ร.๒ เคาะยาให้หล่นเพราะกลิ่นจะชุบศพยักษ์ด้วย |
| ความตายของอินทรชิต | พระลักษมณ์ใช้ **ไอนทราสตร์** ตัดเศียร หลังทำลายพิธีนิกุมภิลา | พระลักษมณ์ใช้ **ศรพรหมาสตร์** ตัดกรและเศียร องคตรับเศียรด้วยพานของพระพรหม (พิธีที่ถูกทำลายชื่อ "กุมภนิยา") |
| สีดาปลอม | มี (มายาสีดา ถูกฆ่าต่อหน้าหนุมาน) | มี — ยักษ์ **สุขาจาร** แปลงเป็นสีดา (ตอนถัดไป) |

> **ข้อสรุปเชิงดีไซน์:** องค์ประกอบที่ "เป็นไทย" ที่สุดของตอนนี้ — และควรเป็นหัวใจของเกม — คือ **ขบวนพระอินทร์ปลอมบนช้างเอราวัณ ๓๓ เศียร พร้อมระบำนางฟ้าลวงตา** ซึ่งไม่มีในฉบับวาลมีกิ และเป็นฉากที่โขนใช้เป็นจุดขายเชิงภาพ (ประติมากรรมช้างเอราวัณสูงกว่า ๓.๕ เมตร ขยับได้ ในโขน ๒๕๕๘)

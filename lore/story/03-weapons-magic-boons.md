# 03 — อาวุธ เวทมนตร์ และพร (Weapons, Magic & Boons)

> เฉพาะข้อเท็จจริงที่ตรวจกับต้นฉบับแล้ว สิ่งที่ยังไม่ยืนยันติดป้าย **[ต้องตรวจสอบ]**
> ส่วน "Game hook" เป็นข้อเสนอเชิงดีไซน์ ไม่ใช่ข้อเท็จจริงจากวรรณคดี

## 1. ศรพรหมาสตร์ / ศรพรหมาศ (Phrommat / Brahmastra Arrow)

| หัวข้อ | ข้อมูล | แหล่ง |

| ตัวแก้ | สรรพยาบน **เขาอาวุธ / ภูผาอาวุธ** ที่พระอิศวรตั้งไว้เพื่อพวกพระนารายณ์ | ร.๑ ส.๕๕; ร.๒ ๑๒๕๘ |

### 1.1 พิธีชุบศร (The Consecration Rite) — ลำดับขั้น

> **Game hook:** พิธีชุบศรเหมาะเป็น **"channel/ritual meter"** ที่ฝ่ายผู้เล่น (หรือ NPC) ต้องขัดขวาง — ถ้าข่าวตายไปถึงโรงพิธี = "เสียพิธี" แต่อินทรชิตยังแก้ได้ด้วยการพลีเลือด (ทำให้ศรแรงกว่า/อันตรายกว่า?) — ตัวเลือกดีไซน์ ไม่ได้มาจากวรรณคดี

### 1.2 วิธีแผลงศร (Firing Protocol)
- **ร.๑:** "จึ่งจับพรหมาสตร์ขึ้นพาดสาย / หมายองค์พระลักษมณ์รังสรรค์ / หน่วงน้าวเหนือคอเอราวัณ" → ศรเต็มแผ่นดิน
- **คำพากย์:** "จึงจับศรทรง / พรหมาสตร์อันเรืองเดชา / ทูนเหนือเศียรเกล้ายักษา / หมายองค์พระอนุชา / ก็แผลงสำแดงฤทธิรณ" — มีท่า **ทูนศรเหนือเศียร** ก่อนแผลง (ท่าบูชาอาวุธ)
- **ร.๒:** "จึ่งจับศรไชยขึ้นบูชา / แล้วพาดสายหมายเขม้นเข่นเขี้ยว" — **บูชาศรก่อน** เช่นกัน
- **เงื่อนไขเชิงยุทธวิธี:** แผลงเมื่อเป้าหมาย "เคลิ้ม/ประมาท" เท่านั้น (ร.๑: "เห็นพระลักษมณ์กับหมู่โยธี / สิ้นสมประดีไปทั้งนั้น"; ร.๒: "เห็นข้าศึกเสียเชิงละเลิงใจ")

> **Game hook:** "Charm → Execute" combo: ต้องทำให้เป้าหมายติดสถานะ *Entranced* จากระบำก่อน จึงยิงพรหมาสตร์ได้เต็มผล; ท่า "ทูนศรเหนือเศียร" เป็น telegraph animation ให้ผู้เล่นอ่านได้

### 1.3 ศรชื่อเดียวกันของฝ่ายพระราม
ต้นฉบับไม่ได้ผูกชื่อ "พรหมาสตร์" ไว้กับอินทรชิตคนเดียว:
- ร.๒ บทที่ ๑๑๓๙: **พระราม** "จึ่งเสี่ยงศรพรหมมาศมหิมา" ไปสังหารมังกรกัณฐ์ที่ซ่อนในเมฆ
- ร.๑ สมุดไทยเล่มที่ ๕๘: **พระลักษมณ์** "จึ่งชักพรหมาสตร์แสงศร" ตัดเศียรอินทรชิต
- ร.๑ ส.๕๓: พระราม "พระกรจับพรหมาสตร์ศรชัย" ขณะออกว่าราชการ

> **ข้อควรระวังด้านการตั้งชื่อในเกม:** ถ้าตั้ง item ชื่อ "Brahmastra" ให้อินทรชิตคนเดียว จะขัดกับต้นฉบับ แนะนำให้เรียกของอินทรชิตว่า "ศรพรหมาสตร์ (ของพระอิศวร)" / *Indrajit's Brahmastra* และระบุว่าพระราม-พระลักษมณ์ก็มีศรชื่อเดียวกัน [การเป็นศรเล่มเดียวกันหรือคนละเล่ม — ต้นฉบับไม่ได้อธิบาย **ต้องตรวจสอบ**]

## 3. พรของพระพรหม: ความตายบนอากาศและไฟบรรลัยกัลป์

พรที่พระพรหมให้พร้อมนาคบาศ (ร.๑ ส.๘): ถ้าจะตาย **ให้ตายบนอากาศ** ถ้าเศียรขาดตกดินจะกลายเป็น **ไฟกัลป์ไหม้โลก** เว้นแต่มี **พานแก้วทิพมาศของพระพรหม** มารองรับ — เป็นเงื่อนไขที่ใช้ในตอนอินทรชิตล้ม (องคตถือพานแว่นฟ้า)

> **Game hook:** แม้ไม่ได้อยู่ในตอนพรหมาศ แต่ควรปลูกเรื่องไว้ (foreshadow) — เช่น เมื่อผู้เล่นทำให้อินทรชิตบาดเจ็บ เขาจะ "เหาะหนีขึ้นเมฆ" ไม่ตกถึงดิน

## 4. เวทแปลงกายเป็นพระอินทร์ (Indra Disguise)

- ได้มาจากพระอิศวรพร้อมศรพรหมาสตร์ (ร.๑ ส.๘: "ทั้งพระเวทแปลงเพศกายา / เป็นองค์อินทราสำหรับไป")
- ใช้ **หลัง** พิธีชุบศรเสร็จ และ **พร้อมกันทั้งกองทัพ** (ไม่ใช่แปลงคนเดียว)
- รูปลักษณ์พระอินทร์ปลอม (คำพากย์ "พากย์พรหมาสตร์"): "งามพักตร์ผิวพรรณ / ดังมรกตเขียวขจี" ทรงเครื่องต้นเต็มยศ ชฎา/มงกุฎ กรรเจียกจร ถือศร
- ร.๑: แต่งเหมือน "สมเด็จสหัสนัยน์ / ลงมาจากตรัยตรึงศา" ธำมรงค์เรือนครุฑ มหามงกุฎ "พระหัตถ์จับพรหมาสตร์แสงศร"
- **ข้อจำกัด:** ภาพลวงทำให้พระลักษมณ์ "สำคัญว่าโกสีย์ตรีเนตร" แต่ **หนุมาน (ร.๑) และสุครีพ (คำพากย์) สังเกตเห็นความผิดปกติ** — พระอินทร์ตัวจริงไม่เคยมาพร้อมอาวุธ
- **การคลายมนตร์:** "รูปนั้นกลับเป็นอสุรา / ลงมาจากพื้นอัมพร" (ร.๑) / "รูปกายกลายเปนอสุรา / คืนเข้าลงกาธานี" (ร.๒) — กลายร่างคืนเมื่อพลบค่ำและกลับเมือง

> ๏ เมื่อนั้นอินทรชิตฤทธิไกร &emsp; ฟังเสนาใน &emsp; ก็โสมนัสเปรมปรีดิ์  
> ๏ จึ่งนิรมิตบิดเบือนอินทรีย์ &emsp; เหมือนองค์โกษีย์ &emsp; เปนเจ้าพิภพสรวงสวรรค์  
> ๏ ทรงโฉมเฉลิมโลกลาวัณย์ &emsp; งามพักตร์ผิวพรรณ &emsp; ดังมรกตเขียวขจี  
> ๏ เสด็จเข้าที่สรงวารี &emsp; สำอางอินทรีย์ &emsp; แล้วทรงสุคนธ์ปนทอง  
> ๏ สอดสนับเพลางามเรืองรอง &emsp; ภูษาพื้นตอง &emsp; กรวยเชิงเปนช่อพรรณราย  
> ๏ สอดทรงพาหุรัดเฉิดฉาย &emsp; ผ้าทิพย์จีบชาย &emsp; เครือแครงสะบัดบรรจง  
> ๏ ทองกรพาหุรัดธำมรงค์ &emsp; เพชรพลอยแต่ละวง &emsp; ควรค่าพิภพเมืองมาร  
> ๏ ตาบประดับทับทรวงสังวาล &emsp; สร้อยสะอิ้งโอฬาร &emsp; ล้วนมรกตรจนา  
> ๏ กรรเจียกจรห้อยมาลา &emsp; แล้วทรงชฎา &emsp; กาบแล้วกระจังรังราย  
> ๏ ดังอินทร์จากฟากฟ้าผันผาย &emsp; สะพักศรกรกราย &emsp; เสด็จมาทรงไอยรา  
>

## 5. ช้างเอราวัณนิมิต (The Conjured Erawan)

### 5.1 ใครแปลงเป็นเอราวัณ? — **การุณราช** (ยืนยันแล้ว)
- **ร.๑ (ส.๕๔):** อินทรชิตสั่งรุทกาล "อันการุณราชผู้ร่วมคิด / จงนิมิตเป็นเอราวัณ" → "ให้การุณราชกุมภัณฑ์ / เป็นเอราวัณตัวกล้า"
- **ร.๒ (บทที่ ๑๒๐๕, ๑๒๐๗):** "จงให้การุณราชอสุรี / แปลงอินทรีย์เปนคชาเอราวรรณ" → "การุณราชมารชาญฉกรรจ์ / เปนช้างเอราวรรณแกล้วกล้า"
- **โขน ๒๕๕๒ (บทร้องตามบันทึกผู้ชม):** "จงให้การุณราชอสุรี / แปลงอินทรีย์เป็นคชาเอราวัณ"
- **กาลสูร ไม่ใช่ผู้แปลงเป็นเอราวัณ** — ใน ร.๒ และโขน "กาลสูร" คือ **เสนาผู้นำข่าวไปโรงพิธี** (ร.๑ ใช้ชื่อ "ไวยกาสูร" ในบทบาทนี้); ใน ร.๒ ยังมี "กาลสูร" อีกบทบาทหนึ่งคือนายทัพหน้าของแสงอาทิตย์ที่ถูกหนุมานฆ่า (บทที่ ๑๑๗๖–๑๑๘๓) — ชื่อซ้ำกัน **[ต้องตรวจสอบ]** ว่าเป็นตัวเดียวกันหรือไม่
- คำพากย์เรียกว่า "ช้างนิรมิต" และพิเภกเรียก "ช้างนิมิต / ขององค์อินทรชิตใจหาญ"

> ๏ กอหนึ่งเจ็ดดอกดวงมาลย์ &emsp; ดอกหนึ่งแบ่งบาน &emsp; มีกลีบได้เจ็ดกลีบผกา  
> ๏ กลีบหนึ่งมีเทพธิดา &emsp; เจ็ดองค์โสภา &emsp; แน่งน้อยลำเพานงพาล

> ๏ ตาข่ายเพชรรัตน์ร้อยกรอง &emsp; ผ้าทิพย์ปกตระพอง &emsp; ห้อยพู่ทุกหูคชสาร  
> ๏ โลทันสารถีขุนมาร &emsp; เปนเทพบุตรควาญ &emsp; ขับท้ายที่นั่งช้างทรง

> — คำพากย์ "พากย์เอราวัณ" ประชุมคำพากย์รามเกียรติ์ ภาค ๑ (vajirayana.org)

> **หมายเหตุการแสดง:** โขน ๒๕๕๘ ใช้ประติมากรรมช้างเอราวัณ "ความสูงกว่า 3.5 เมตร" ซึ่ง "สามารถขยับในอิริยาบทต่างๆ ไม่ว่าจะเป็น การชูงวง การขยับคอ ได้ทั้ง 3 เศียร การทรุดตัวหมอบ" (MGR Online) — โขนย่อ ๓๓ เศียรเหลือ **๓ เศียร**; ในเกม (3D) สามารถทำ ๓๓ เศียรตามต้นฉบับวรรณคดี หรือ ๓ เศียรตามขนบโขน/ภาพจิตรกรรม — **ให้ทีมศิลป์ตัดสินใจโดยรู้ว่าต้นฉบับวรรณคดีระบุ ๓๓**

### 5.3 ความเปราะบาง
หนุมาน "กรซ้ายหักคอเอราวัณ" ได้ — เพราะเป็นยักษ์แปลง ไม่ใช่ช้างทิพย์จริง; เมื่อช้างคอหัก หนุมาน "นอนทับเศียรเอราวัณ" อยู่กลางสนามรบ (ศพช้างยังคงรูปช้าง — พระรามยังถามว่า "ด้วยเอราวัณหัสดิน / ขององค์อมรินทร์ทรงจักร / เหตุใดจึ่งได้มากับยักษ์")

> **Game hook:** Erawan = **mount-boss** ที่มีจุดอ่อน "คอ"; เศียรช้างที่หักตกลงสนามกลายเป็น landmark/prop ของฉากหลังการต่อสู้

## 6. กองทัพเทวดา-นางฟ้าปลอม (The Disguised Host)

| บทบาทจริง (ยักษ์) | แปลงเป็น | แหล่ง |
|---|---|---|
| พลรบทั้งหมด | คนธรรพ์ วิทยาธร (พิทยาธร) เทวดา สุรารักษ์ นักสิทธิ์ — "ล้วนถือซึ่งสรรพสาตรา / ปืนยากำซาบธนูศร" | ร.๑ ส.๕๔ |
| กองหน้า | "แต่พื้นพวกพิทยาธร" | ร.๑ |
| ขบวนตามตำราทัพ (คำพากย์) | ทัพหน้า "อารักษ์ไพรสัณฑ์", ทัพหลัง "สุบรรณ กินร นาค", ปีกซ้าย "ฤๅสิทธ์วิทยา", ปีกขวา "คนธรรพ์" | พากย์เอราวัณ |
| นักดนตรี (ฆ้อง แตร สังข์ กังสดาล ดุริยางค์) | นางฟ้า/เทพอัปสร รำระบำหน้าช้าง | ร.๑; ร.๒ ๑๒๐๗ |

**ระบำลวงตา:** ดนตรี (รำมะนา ทับ ดีดสีตีเป่า) + ท่ารำเวียนวง "กระหวัดกรเป็นหงส์ลีลา" "ใส่จริตให้หลงงงไป" → ผลคือพระลักษมณ์ "เคลิ้มสติไป" และวานร "ยิ่งดูก็ยิ่งประมาทใจ"

**หลังแผลงศร** ทัพเทวดาปลอม "บ้างยิงบ้างพุ่งสาตรา / เกลื่อนกลาดลงมาแต่อัมพร" ซ้ำวานรที่ล้ม

> **Game hook:** ระบำ = **AoE charm aura** ที่ทำงานผ่าน "การมอง/การฟัง" — ผู้เล่นอาจต้องหลบสายตา ปิดหู หรือมีตัวละคร (หนุมาน) ที่ต้านได้บางส่วน; ดนตรีประกอบเปลี่ยนจากเพลงหวาน (สมิงทอง, พระทอง ตาม ร.๑) เป็นเพลงหน้าพาทย์ "เชิดฉิ่ง" ตอนแผลงศร — ประสานกับทีมดนตรี

## 8. ตัวแก้: เขาอาวุธ / ภูผาอาวุธ (The Cure)

## 9. บุษบก: ที่เสี่ยงทายความเป็นหม้าย (The Puspaka Divination)
- บุษบกของทศกัณฐ์ "มีมาแต่ดึกดำบรรพ์ / ดั่งหนึ่งจักรแก้วฤทธิรงค์ / ขององค์จักรพรรดิ" ลอยในอากาศได้เอง
- **กฎ:** "หญิงอันเป็นหม้ายภัสดา / แม้นขี่ก็ไม่พาจร" — ถ้าสามีตายแล้ว บุษบกไม่ลอย; ตรีชฎายกตัวอย่างนางมณโฑเคยเสี่ยงแล้วลอยได้
- นางสีดาตั้งสัตยาธิษฐาน บุษบกลอยเวียนทักษิณ ๓ รอบ (ร.๑) = พระรามยังไม่สิ้น

> **Game hook:** ฉากทางเลือก/ไขปริศนาที่ผู้เล่นได้ "คำตอบ" ว่าพระรามยังมีชีวิตผ่านการเสี่ยงทาย — ใช้เป็นจุดพักอารมณ์ระหว่างฉากสิ้นหวังกับฉากภารกิจยกเขา (แม้โขนตัดฉากนี้ แต่อยู่ในต้นฉบับทั้ง ร.๑ และ ร.๒)
